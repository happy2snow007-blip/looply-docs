**版本** v1.6 | **日期** 2026-06-24 | **受众** UI 设计师 · 前端开发 · CMS 开发
**依赖** CMS PRD v2.4 · 商品系统 PRD v1.7 · 首页 PRD v1.0 · 类目管理 ER v1.1
**范围** Collection 落地页 · Mobile 端（PC 端 V2）

**v1.5 → v1.6 变更说明**：与后台类目管理 ER v1.1、后台配置原型对齐后修订——①**抽屉筛改为零配置动态生成**：抽屉筛即后台「通用筛选器」，按每个 Collection 的商品集合从全局筛选维度池动态匹配，维度选取/排序/展示样式由筛选维度管理全局统一配置，Collection 内运营不再单独配置（原 §2.7 抽屉筛项配置删除）；②**筛选字段标识统一**：前端不再维护独立的 `attr_key` 枚举，直接使用后台筛选维度英文标识（dimension key）作为前后台通用字段名，零映射；③**特殊筛选 UI 改为按后端展示样式驱动**：price 滑块、color 色块等不再由前端按字段名硬判断，改为读后端返回的展示样式（display_type）渲染；④**价格滑块范围对齐后台口径**：最小固定 $0，最大取商品池最高价向上取整到百位（不足 $100 按 $100）；⑤商品粒度明确为 listing 级（与后台一致，不按 SPU 聚合）；⑥**图文筛项筛选条件升级为多筛选项预置**（从筛选器维度挑选，维度间 AND、同维度多值 OR，不支持 OR 组合，原单条件单枚举值废弃）；⑦**移除系统级「All」项**：图文筛默认无标签激活=展示全集，前台仅展示运营配置的项。

**v1.4 → v1.5 变更说明**：架构精简——移除 Template / UI Variant 两层配置体系，改为扁平的 Collection Content 直接配置；新增前端约束参考章节（title/subtitle 长度、各筛选模块数量限制）；新增前端展示名称映射字典；图文筛新增 `image_enable` 字段；快筛 / 抽屉筛移除 `selection_mode` 和 `group_by`，新增 `value_display_type`；价格筛选 V1 只支持 Slider，移除价格带（Price Band Dictionary 移至 V2）；集内搜索模块删除（搜索 icon 保留，作为全局搜索入口，逻辑 V2）；顶导移除分享按钮和 Logo；筛选候选值联动逻辑改为完全由服务端定义，PRD 不再定义联动公式；筛选状态保存功能移至 V2；Collection 状态新增 draft 草稿态；结果通知栏合并原"结果数量通栏"与"面包屑区"，筛选值展示只展示值名称不展示属性名；Auto-Scroll 补充快筛吸顶和底导消失规则。

## §1 概述

### §1.1 背景与目标

Collection 落地页是 Looply 的「主题货架」页，承接首页 home_collections 坑位和 Shop 页 shop_collections 坑位的跳转。

**目标**：
1. 通过运营配置的视觉素材传递合集氛围，建立品牌信任
2. 提供完整筛选链路（图文筛 + 快筛 + 抽屉筛），帮用户快速锁定目标商品
3. 「零空结果」体验——筛选候选值完全由服务端计算并下发，前端只渲染有值的项
4. 复用首页 Feed 商品卡组件，保持全站视觉一致性

### §1.2 不做什么

| 不做 | 说明 |
|------|------|
| PC 端 | V1 仅 Mobile，PC 端独立规划（V2）|
| 集内搜索 | V1 仅保留搜索入口 icon，搜索逻辑 V2 |
| Collection 内分享 | V1 不做 |
| 底部相关推荐 | V2 规划 |
| 筛选条件保存 | V2 规划 |
| 价格带筛选 | V1 价格只支持 Slider，价格带 V2 |
| 排序项可见性按终端差异化 | V1 全部读后台配置，终端差异 V2 |

### §1.3 用户角色

| 角色 | 说明 |
|------|------|
| 买家（C 端 Mobile 用户）| 浏览合集商品、筛选选品、跳转商品详情页 |

### §1.4 核心场景

| 场景 | 用户动作 | 关键模块 |
|------|------|------|
| 氛围浏览 | 进入页面后滑动浏览 Banner 和商品 | Banner 区域、商品网格 |
| 主题切入 | 点击图文筛项切换子主题 | 图文筛 |
| 快速筛选 | 点击快筛 Chip，展开二级面板，Apply 提交 | 快筛栏 |
| 精细筛选 | 打开抽屉筛，多维度组合，Apply 提交 | 抽屉筛选器 |
| 逐项移除条件 | 已选条件区点 ✕ 拆除单条件 | 结果通知栏 |
| 点击商品 | 跳转商品详情页 | 商品网格 |

### §1.5 全局页面流转

```
首页 home_collections 坑位 ──→ Collection 落地页
Shop 页 shop_collections 坑位 ──→ Collection 落地页
Collection 落地页 ──→ 商品详情页（点击商品卡）
```

### §1.6 术语说明

| 术语 | 定义 |
|------|------|
| Collection | CMS 合集实体，对应 URL `/collections/{slug}` |
| 图文筛 | 运营配置的图文标签列表，用户点击切换子主题商品池 |
| 快筛 | 横排滚动 Chip 栏，点击展开二级筛选面板。维度由运营在 Collection 内从全局维度池挑选 |
| 工具栏 | 包含排序（左）和抽屉筛入口（右）的固定栏 |
| 抽屉筛 | 从左侧滑出的全量属性筛选面板。等同后台「通用筛选器」，零配置——按当前 Collection 商品集合从全局维度池动态匹配，维度/排序/样式全局统一 |
| Collection 全集 | 该 Collection 下所有 `listing_status = active` 的商品，不附加任何筛选条件 |
| 物理隐藏 | 候选值不在后端返回列表中时前端不渲染，从 DOM 移除 |
| View All | 快筛二级面板 / 抽屉筛属性节内候选项超过上限时出现的展开控件 |

## §2 配置结构

### §2.1 配置总览

Collection 页面配置分为两层，由不同角色维护：

| 层级 | 配置主体 | 职责 |
|------|------|------|
| Collection 内容 | 运营 | 配置页面展示什么（Banner 图、图文筛项、快筛维度挑选与排序、排序项、商品池等；抽屉筛为零配置）|
| 字典 | 产品 / 运营 | 配置颜色映射（Color Dictionary）和前端展示名称映射 |

页面展示样式、交互规则（Chip 样式、滑块、展示数量等）统一由 UI 设计规范定义，后台无需配置。

---

### §2.2 基础信息

| 字段 | 中文名称 | 示例 | 枚举 / 来源 | 说明 | 备注 |
|------|------|------|------|------|------|
| `status` | 状态 | `active` | `draft` / `active` / `inactive` | 控制 Collection 是否上线 | draft 允许保存不完整配置；active 必须完成全部上线所需配置；inactive 保留配置、不参与前台展示 |
| `collection_id` | Collection ID | `10001` | 系统生成 | 唯一标识 | 不可编辑 |
| `title` | 页面标题 | `Luxury Bags` | 文本 | 前台页面标题，前端从此字段取值 | 最大长度见 §2.3 |
| `subtitle` | 页面副标题 | `Timeless Pieces` | 文本 | Banner 副标题 | 选填，最大长度见 §2.3 |
| `market_id` | 市场 | `US` | 市场配置中心 | 控制商品池范围 | MVP 默认 US，结构预留 |
| `channel_id` | 渠道 | — | 渠道配置中心 | 控制商品池范围 | MVP 默认线上官网，结构预留 |
| `collection_url` | 落地页链接 | — | 系统生成 | 供下游跳转调用 | 不可编辑 |

**状态流转**：`draft → active → inactive`。禁止 draft 直接跳 inactive。

**上线校验**（status 变更为 active 时必须通过）：
- 基础信息完整（title 必填）
- 商品池配置完整，且可正常返回商品
- 筛选模块配置满足 §2.3 最小数量要求（若模块已启用）
- 排序存在至少一个 `is_default = TRUE` 的项

**草稿态弱校验**：仅校验 title 非空，其余配置项可为空。

---

### §2.3 前端约束参考

> 以下约束值由 UI 规范定义，当前硬编码在校验逻辑中。后续从 UI 配置中心读取。

| 约束项 | 说明 | 当前值 |
|------|------|------|
| `title_max_length` | 标题最大字符数 | 30 |
| `subtitle_max_length` | 副标题最大字符数 | 60 |
| `visual_filter_min_count` | 图文筛最少 active 项数 | 4 |
| `visual_filter_max_count` | 图文筛最多 active 项数 | 8 |
| `quick_filter_min_count` | 快筛最少 active 项数 | 1 |
| `quick_filter_max_count` | 快筛最多 active 项数 | 8 |
| 图片尺寸 / 格式 | Banner、图文筛图片 | 由 UI 规范定义（待补充）|

> 抽屉筛为零配置动态生成（见 §2.7），其维度数量由当前商品池实际匹配结果决定，不设 Collection 级 active 数量上下限校验。

上线强校验：active 项数不满足上限 / 下限时禁止上线。草稿态弱校验：不校验数量，仅展示提示。

### §2.5 图文筛配置

**模块配置**：

| 字段 | 说明 |
|------|------|
| `module_enabled` | FALSE 时不校验图文筛内容，前台不展示图文筛行 |
| `image_enable` | TRUE = 图片+文字样式；FALSE = 纯文字样式（适用于整个模块，所有项统一）|

**图文筛项配置（每项）**：

| 字段 | 中文名称 | 示例 | 说明 | 备注 |
|------|------|------|------|------|
| `status` | 是否展示 | `active` / `inactive` | 临时隐藏单项 | — |
| `label_text` | 展示文案 | `Chanel Classic` | 用户可见文案 | 长度限制见 §2.3 |
| `image_url` | 图片 | — | 图片上传 | `image_enable = FALSE` 时无需上传 |
| `filter_condition` | 筛选条件 | `Brand ∈ {Chanel} AND Price < $1,000` | 从筛选器维度挑选并预置一组筛选项：维度间 AND、同维度多枚举值 OR，不支持 OR 组合；基于当前 Collection 商品池生效 | — |
| `sort_order` | 排序 | 正整数 | 展示顺序，支持拖拽排序 | — |

数量限制见 §2.3（仅 module_enabled = TRUE 时生效）。前台仅展示运营配置的 active 图文筛项，无系统级「All」项。

### §2.6 快筛配置

**模块配置**：

| 字段 | 说明 |
|------|------|
| `module_enabled` | FALSE 时不校验快筛配置，前台不展示快筛栏 |

**快筛项配置（每项）**：

| 字段 | 中文名称 | 示例 | 说明 | 备注 |
|------|------|------|------|------|
| `dimension_key` | 筛选维度 | `brand` | 后台筛选维度英文标识，从全局维度池挑选，枚举见 §7.1 | 必填 |
| `enabled` | 是否展示 | `TRUE` | 临时隐藏单个筛选项 | — |
| `sort_order` | 排序 | 正整数 | 从左到右展示顺序，分 Collection 配置 | — |

> 快筛是运营在 Collection 内从全局维度池挑选的热门筛选项，「挑哪些」「排序」均分 Collection 配置。每项的展示样式（slider / color / text_chip / collapse）由后台维度的全局配置决定（见 §2.10.3），前端按后端返回的 `display_type` 渲染，运营不在快筛项上单独配置样式。

数量限制见 §2.3。

### §2.7 抽屉筛配置

抽屉筛即后台「通用筛选器」，**零配置、动态生成**：按当前 Collection 商品集合从全局筛选维度池自动匹配出可用维度，无需在 Collection 内逐项配置。

**模块配置**：

| 字段 | 说明 |
|------|------|
| `module_enabled` | FALSE 时前台不展示抽屉筛入口 |

**生成与展示规则**：
- 展示哪些维度：由当前 Collection 全集 ∩ 图文筛 ∩ 搜索词范围内有 ≥2 个不同值的维度自动决定（§4.9.7），运营不挑选、不隐藏单维度
- 维度顺序：由筛选维度管理的**全局统一排序**决定，所有 Collection 一致
- 每个维度的展示样式（slider / color / text_chip / collapse）：由后台维度全局配置决定（见 §2.10.3），前端按后端返回的 `display_type` 渲染
- 运营若需调整抽屉筛的维度范围/顺序/样式，统一在「筛选维度管理」全局修改，不在单个 Collection 内配置

> 与快筛的区别：快筛是 Collection 内从池中**挑选**的热门项（选项和排序分 Collection）；抽屉筛是**全量动态**呈现（维度/排序/样式全局统一）。

---

### §2.8 排序配置

**模块配置**：

| 字段 | 说明 |
|------|------|
| `module_enabled` | FALSE 时不展示排序 |

**排序项配置（每项）**：

| 字段 | 中文名称 | 示例 | 说明 | 备注 |
|------|------|------|------|------|
| `sort_key` | 排序字段 | `recommended` | 枚举见 §7.2 | 客户端只消费字段，不维护排序逻辑 |
| `enabled` | 是否展示 | `TRUE` | 控制该排序项是否展示给用户 | — |
| `sort_order` | 展示顺序 | 正整数 | 决定排序项在列表中的顺序 | — |
| `is_default` | 默认排序 | `TRUE` | 默认选中项，全局唯一 | — |

前端**不硬编码**排序项，全部读取后台配置。排序文案由后台配置决定，前端直接读取。

**兜底策略**：若 Collection 未配置排序，展示全部排序项，默认 `recommended`。

---

### §2.9 商品池配置

定义当前 Collection 商品池的筛选条件。图文筛、快筛、抽屉筛、排序均在此商品池基础上生效。

商品池构建方式支持：
- **手工选品（Manual）**：逐个选定商品加入商品池
- **规则选品（Rule-based）**：配置属性条件（AND/OR 逻辑），自动匹配符合条件的商品，规则变更后商品池自动更新

> 商品粒度为 **listing 级**（渠道挂牌记录），与后台库存/商品系统一致，不按 SPU 聚合。商品池展示规则由前端决定，后台无需配置排列样式。

### §2.10 字典配置

#### §2.10.1 Color Dictionary（商品系统维护）

颜色码到展示名称、色值、色系的映射。由商品系统维护，Collection 后台只读取，不维护。

| 字段 | 示例 | 说明 |
|------|------|------|
| `color_code` | `black` | 商品颜色值，与商品系统对应 |
| `display_name` | `Black` | 前台展示名称 |
| `color_hex` | `#000000` | 色值，用于色块渲染 |
| `color_family` | `Black` | 色系分组 |

#### §2.10.2 前端展示名称映射（Collection 后台维护）

后端字段名到前台展示文案的映射，用于快筛 / 抽屉筛的维度名称和枚举值展示。所有筛选项及枚举值的前台展示文案均由后端返回，前端直接读取，不在前端代码中硬编码。

| 字段 | 示例 | 说明 |
|------|------|------|
| 后端字段 | `category_l2` | 商品属性字段名 |
| 字段中文名 | 二级类目 | 内部参考 |
| 前台展示名称 | `Category` | 前台展示，可按 Collection 覆盖 |
| 枚举值映射 | `shirt → Top` | 枚举值的展示文案 |

#### §2.10.3 筛选展示样式（display_type）

筛选维度的展示样式由后台「筛选维度管理」**全局配置**（同一维度所有 Collection 一致），前端按后端返回的 `display_type` 渲染，不在前端按字段名硬编码判断。

| display_type | 说明 | 适用维度 |
|------|------|------|
| `slider` | 价格滑块，仅价格维度 | price（固定）|
| `color_chip` | 色块圆形矩阵，读 Color Dictionary | color（固定）|
| `text_chip` | 枚举值摊平为 Chip，超上限显示 View All | 一般维度 |
| `collapse` | 多层折叠，末端为筛选值；类目按商品池匹配到的层级展示 | category 等层级维度 |

> 前端识别"走滑块/色块/折叠"等特殊渲染，一律依据后端返回的 `display_type`，不再依据字段名。

## §3 数据逻辑层

### §3.1 Collection 全集定义

**Collection 全集** = 该 Collection 下所有 `listing_status = active` 的商品，不附加任何用户筛选条件。

全集是筛选候选值计算的基准锚点，不随用户操作改变。

---

### §3.2 筛选候选值规则

筛选候选值完全由服务端计算并下发，前端不做本地计算，不做本地过滤。

**候选值来源**：快筛和抽屉筛的可选项，基于以下范围计算：

```
候选值范围 = Collection 全集 ∩ 当前图文筛项范围 ∩ 搜索词过滤结果
```

**关键规则**：
- 快筛和抽屉筛的可选项**互不影响**：在快筛中选了某个品牌，不会缩减抽屉筛中其他维度的可选范围，反之亦然。避免「越筛越少」
- 图文筛选中状态变化后，快筛和抽屉筛的候选值随之更新（服务端重新计算）
- 后端不下发的属性值，前端物理隐藏，不渲染、不占位
- 后端返回候选值时，同步返回每个值的商品数量

快筛与抽屉筛共享同一套筛选状态：快筛选中的值在抽屉筛中同步展示为选中态，抽屉筛 Apply 后快筛 Chip 角标同步更新（详见 §4.9.8）。

---

### §3.3 筛选状态重置规则

| 触发动作 | 重置范围 |
|------|------|
| 切换图文筛项（含再次点击取消激活、回到全集）| 清空所有快筛条件 + 抽屉筛条件 |
| 提交新搜索词 | 清空所有快筛条件 + 抽屉筛条件 |
| 清空搜索词（点 ✕）| **不重置**，恢复搜索前商品列表 |

---

### §3.4 空态与降级规则

以下穷举所有可能的空态场景，具体交互处理方式由 UI 设计确定：

| 状态 | 触发条件 | 建议处理 |
|------|------|------|
| Collection 不可用 | `status ≠ active` 或 slug 无效 | 友好提示页 + 跳转引导 |
| 合集内商品全部下架 | 商品池为空，无筛选条件 | 空内容提示 + 浏览其他合集入口 |
| 筛选后 0 件商品 | 有激活条件但交集为空 | 空结果提示 + 清空筛选入口 |
| 图文筛无 active 项 | `module_enabled=TRUE` 但无 active 项 | 图文筛行整行隐藏，不占位 |
| 某筛选维度无候选值 | 当前范围内该维度无值 | 该 Chip 物理隐藏 |
| Banner 图片加载失败 | 图片请求失败 | **不展示 Banner 区域**（整区隐藏，不占位）|
| 网络异常 | 接口报错 | 错误提示 + 重试入口 + 骨架屏保持 |
| 加载中 | 首次进入 / 刷新 | 双列骨架屏占位 |

## §4 页面与交互

### §4.1 页面整体布局与吸顶

以默认页面结构为例：

```
┌─────────────────────────────┐
│  顶导栏（44px）              │  ★ 始终固定
├─────────────────────────────┤
│  Banner 区域                 │  随流滚动
├─────────────────────────────┤
│  图文筛                      │  随流滚动
╠═════════════════════════════╣
│  快筛栏                      │  ★ 吸顶
╠═════════════════════════════╣
│  工具栏                      │  ★ 吸顶（快筛栏下方）
╠═════════════════════════════╣
│  结果通知栏                  │  随流滚动（禁止吸顶）
├─────────────────────────────┤
│  商品网格                    │  随流滚动
└─────────────────────────────┘
```

**吸顶触发条件**：
- 页面向上滚动越过图文筛底部时，快筛栏锁定吸顶
- 工具栏紧贴快筛栏下方一起吸顶
- 吸顶样式：白色背景 + 底部分割线
- 用户主动向上滑动回到页面顶部时，Banner 和图文筛区域重新展开，吸顶解除

**底导消失规则**：向下滚动进入商品网格区域一定距离后，底部导航栏消失；向上滑动一定距离后底导重新出现。具体触发距离由 UI 确定（见 §8）。

---

### §4.2 顶导栏

顶导栏始终固定在页面顶部。

**从左到右**：

| 位置 | 元素 | 说明 |
|------|------|------|
| 左侧 | ← 返回图标 | 返回上一页 |
| 中间 | Collection 标题 | 读取 `title` 字段，居中展示 |
| 右侧 | 搜索图标 | 全局搜索入口，V1 仅保留图标，点击逻辑 V2 |
| 右侧 | 购物车图标 | 跳转购物车 |

V1 不展示分享按钮和品牌 Logo。

**背景状态**：

| 场景 | 背景 | 图标色 |
|------|------|------|
| 未滚过 Banner | 透明 | 白色 |
| 已滚过 Banner 高度 | 白色 + 底部分割线 | 深色 |

透明→白色渐变：从滚动距离 = Banner 高度 × 70% 开始线性渐入，至 100% 完全白色。

---

### §4.3 Banner 区域

Banner 区域展示头图、标题和副标题，随页面滚动。

**展示元素**：
- 头图（`banner_image_url`）
- 标题（`title` 字段）
- 副标题（`subtitle` 字段，若有）

**图片加载失败时**：整个 Banner 区域不展示，不占位。页面直接从图文筛行开始。

**具体样式**（文字位置、渐变遮罩、字号等）由 UI 设计规范定义。

---

### §4.4 图文筛

图文筛行横向滚动，随页面滚动，不吸顶。

**展示形式**：
- 图文筛（`image_enable = TRUE`）：图片 + 文字标签
- 纯文字筛（`image_enable = FALSE`）：仅文字标签

**交互规则**：
- 图文筛为**单选**：同一时刻最多一个标签激活
- 默认无标签激活，展示 Collection 全集
- 点击标签 → 触发 Auto-Scroll（§4.10） → 清空所有快筛和抽屉筛条件（§3.3）→ 后端按新标签范围刷新商品列表
- 再次点击已激活标签 → 取消激活，回到 Collection 全集
- 无系统级「All」项；所有项 `status = inactive` 或 `module_enabled = FALSE` 时，整行隐藏，不占位

向下滚动时，图文筛区域折叠（与 Banner 一起）；向上滑动回到顶部时，Banner 和图文筛重新展开（详见 §4.1）。

---

### §4.5 快筛栏

快筛栏横向滚动，滚动越过图文筛底部后吸顶。

#### §4.5.1 整体布局

- 横向可滚动，按 `sort_order` 从左到右渲染 `enabled = TRUE` 的筛选维度 Chip
- 某维度在当前 Collection 全集 ∩ 图文筛 ∩ 搜索词范围内有 ≥2 个不同值时才渲染该 Chip；否则物理隐藏

#### §4.5.2 快筛交互规则

- 点击快筛 Chip → 快筛栏立即吸顶 → 二级筛选面板从快筛栏下缘向下打开
- 面板底部固定两个按钮：
  - **Clear**：清空当前维度所有已选项，面板保持打开
  - **Apply**：提交当前选中项，关闭面板，触发 Auto-Scroll，刷新商品列表
- 未做任何改动时 Apply 等同关闭，不触发刷新
- Clear 后直接关闭（非 Apply）：不提交，恢复打开前状态

**Chip 状态**：

| 状态 | 样式说明 |
|------|------|
| 无选中值 | 默认样式，展示维度名称 |
| 有选中值 | 高亮样式，右侧显示已选数量角标 |

#### §4.5.3 View All 规则

| 条件 | 行为 |
|------|------|
| 当前维度候选项总数 ≤ 8 | 全部展示，不显示 View All |
| 当前维度候选项总数 > 8 | 默认展示前 8 项 + View All 入口 |
| 点击 View All | 面板展开为可滚动区域，展示全部候选项，View All 入口隐藏 |

若当前维度存在分组（如 Size 按 Category 分组），View All 的 8 个阈值按所有分组内选项**总数**统一计算，不是每组各计 8。

#### §4.5.4 价格（`display_type = slider`）二级面板

V1 只支持 Slider（滑块），不支持价格带。

- 范围：最小固定 **$0**，最大取当前 Collection 商品池最高价**向上取整到百位**（不足 $100 按 $100），无小数/十位/个位
- 滑块上方实时显示当前区间，格式「$200 — $1,000」
- 初始状态：区间为 $0 ～ 最大值
- 重置：拖回两端 = 无价格筛选条件
- 范围由后端按当前商品池动态返回，不入库，前端不本地计算
- 不适用 View All

#### §4.5.5 颜色（`display_type = color_chip`）二级面板

- 展示形式：色块圆形矩阵，每个色块旁展示色系名称
- 颜色枚举与展示：从 Color Dictionary 读取 `color_code → display_name + color_hex`
- 不适用 View All
- 多选

#### §4.5.6 其他维度二级面板

- `display_type = text_chip`：候选值摊平展示为 Chip，多选，适用 View All（§4.5.3）
- `display_type = collapse`：多层折叠展示，多选，展开层级由当前商品池匹配结果决定

类目（category）使用 collapse 时，折叠层级按当前商品池能匹配到的所有层级展示（有几级展示几级）。具体样式由 UI 设计确定。

---

### §4.6 工具栏

工具栏固定在快筛栏下方，吸顶时紧贴快筛栏下缘。包含排序（左侧）和抽屉筛入口（右侧）。

#### §4.6.1 排序（左侧）

- 点击排序 Chip → 弹出排序列表
- 排序列表为单选，选中后立即生效，面板关闭
- 排序 Chip 默认展示当前排序方式名称，切换后更新为新排序名称
- 可选项和展示文案全部从后台配置读取，前端不硬编码

#### §4.6.2 抽屉筛入口（右侧）

- 图标 + 文字，有抽屉筛已选条件时图标带角标提示
- 点击 → 打开抽屉筛（§4.9）

---

### §4.7 结果通知栏

结果通知栏随页面滚动，**禁止吸顶**。包含商品数量展示和已选条件标签两部分。

#### §4.7.1 商品数量

- 实时展示当前筛选条件下的商品件数，千分位格式
- 加载中显示占位符

#### §4.7.2 已选条件标签

有任意激活条件（图文筛 ≠ All、任意快筛 / 抽屉筛有值）时显示；无条件时整区域隐藏，不占位。

**展示规则**：
- 只展示已选**值的名称**，不展示属性名称前缀
- 颜色：展示色系名称（不展示色卡图标）
- 价格：展示当前区间，如「$200 — $1,000」
- 示例：已选 Brand=Chanel 时，展示「Chanel」而非「Brand: Chanel」

**单个标签操作**：
- 点击标签上的 ✕ → 立即取消该条件 → 商品列表即时刷新 → **不触发 Auto-Scroll**
- 取消后所有条件为空 → 标签区域隐藏

**Clear All**：
- 清空所有快筛和抽屉筛条件，刷新商品列表
- 不清空图文筛选中状态和搜索词

---

### §4.8 商品网格

- 双列网格，列数不可配置（V1 固定双列）
- 商品卡复用首页 Feed 商品卡组件
- 商品排列顺序完全由后端决定，前端不做干预
- 加载中：同比例骨架屏占位
- 无限滚动分页，触底前预加载下一页
- 点击商品卡 → 跳转商品详情页

---

### §4.9 抽屉筛选器

由工具栏右侧抽屉筛入口触发，从左侧滑出。

#### §4.9.1 整体结构

```
┌────────────────────────────┬───────────┐
│  ✕  筛选            Reset  │           │
├────────────────────────────┤  右侧露出  │
│  品牌                   ▼  │  区域      │
├────────────────────────────┤（无遮罩） │
│  系列                   ▼  │           │
├────────────────────────────┤           │
│  类目                   ▼  │           │
├────────────────────────────┤           │
│  颜色                   ▼  │           │
├────────────────────────────┤           │
│  ...                       │           │
├────────────────────────────┤           │
│  [ Apply · N items ]       │           │
└────────────────────────────┴───────────┘
```

- 宽度：屏幕左侧约 2/3，右侧约 1/3 露出底层内容（无遮罩）
- 具体样式（尺寸、动效）由 UI 设计确定
- 各维度顺序与是否展示由后台筛选维度管理的**全局配置**决定（抽屉筛零配置，见 §2.7），并按当前商品池动态过滤（§4.9.7）

#### §4.9.2 抽屉筛内部展示规则

抽屉筛内各维度的展示形式与快筛**完全一致**（`display_type`、View All 规则、颜色矩阵、价格 Slider 等均相同）。

唯一区别：抽屉筛的一级维度列表**纵向排列**，快筛的维度 Chip **横向滚动**。

#### §4.9.3 开关路径

| 路径 | 触发方式 | 是否应用变更 |
|------|------|------|
| 打开 | 点击工具栏抽屉筛入口 | — |
| 关闭 A | 点击抽屉内 ✕ | 否（取消）|
| 关闭 B | 点击右侧露出区域 | 否（取消）|
| 关闭 C | 向右滑动关闭手势 | 否（取消）|
| 提交 | 点击底部 Apply | 是 |

#### §4.9.4 Apply 按钮

- 文案：「Apply · N items」，N = 当前抽屉条件 × 快筛条件 × 搜索词的预计算交集数量
- N = 0 时：按钮置灰，文案「No items match」
- 点击：关闭抽屉 → 应用条件 → 更新快筛 Chip 角标 → 更新已选条件标签 → 触发 Auto-Scroll → 刷新商品列表

#### §4.9.5 Reset 按钮

- 清空抽屉内部当前选中状态，**不影响快筛条件**
- Reset 后 Apply 按钮预计数量更新为当前快筛 + 搜索词范围内的商品数
- 与工具栏「Clear All」区别：Reset 不关闭抽屉，也不清快筛

#### §4.9.6 向右滑动关闭手势

- 在抽屉区域内向右水平滑动
- 未达阈值 → 弹回；超过阈值或释放速度超出阈值 → 关闭
- 关闭效果同路径 A（不应用变更）
- 具体阈值由 UI / 前端确定

#### §4.9.7 筛选维度显示规则

某维度在当前 Collection 全集 ∩ 图文筛 ∩ 搜索词范围内有 ≥2 个不同值时才渲染该维度节；否则整节物理隐藏，不占位。

#### §4.9.8 快筛与抽屉双向状态同步

- 快筛对某属性已选值 → 打开抽屉时，该属性节对应项显示为选中态
- 抽屉内修改 → Apply 后，对应快筛 Chip 角标更新
- 抽屉 Reset → 不清快筛
- 已选条件区 Clear All → 同时清快筛和抽屉内部状态

---

### §4.10 Auto-Scroll 行为

#### §4.10.1 触发事件

| 触发动作 | 行为 |
|------|------|
| 点击图文筛项 | 平滑滚动至快筛栏吸顶位置 |
| 点击快筛 Chip | 快筛栏立即吸顶，二级面板向下展开 |
| 快筛 Apply | 关闭面板后，若快筛栏未在顶部则平滑滚动至吸顶位置 |
| 抽屉 Apply | 先关闭抽屉，再平滑滚动至吸顶位置 |
| 已选条件 ✕ 逐项移除 | **不触发** Auto-Scroll |
| Clear All | **不触发** Auto-Scroll |

#### §4.10.2 吸顶定义

lock point = 快筛栏顶边紧贴顶导栏底部。

#### §4.10.3 底导消失逻辑

以下为可行方案（最终由 UI 确认）：

- 向下滚动进入商品网格区域，快筛和工具栏吸顶的同时，底导消失（两者同时发生）
- 向上滑动一定距离 → 底导重新出现
- 滑动至页面顶部 → Banner 和图文筛重新展开，吸顶解除，底导恢复

具体触发距离见 §8。
