**v0.17 → v0.18 变更（增补·操作日志）**：补充**后台操作日志（审计）**规范,记录粒度定为**字段级 diff**（每个变更字段记「变更前 → 变更后」）。①**对象与触发**：对 Collection、筛选维度的创建/编辑/状态变更/删除留痕;编辑保存时逐字段比对、只记实际变化字段,无变化不产生日志。②**选品规则 diff 口径**：记条件的增/删/改 + 值变化 + AND/OR 逻辑变化(如「品牌 属于:Chanel,Hermès → +Louis Vuitton」),**不记「条件数 4→5」这类无信息量计数**。③**入口与展示**：两类**编辑页**页头「操作日志」按钮(新建态不提供)→右侧抽屉,时间倒序时间线 + 按操作类型筛选,diff 旧值删除线/新值高亮;日志**只读**不可编辑删除。④**留存与可见性**:≥180 天、有权限运营可读、无导出/删除入口。⑤**数据模型新增 `audit_log` 表**(object_type/object_id/action/summary/changes(JSON)/operator/created_at)。⑥**本期不做全量快照与版本回滚**。扩写 §7.2(新增 7.2.1/7.2.2/7.2.3)、§8.6 新增 audit_log 表、新增 R-43。原型 v0.19 同步:新增共用 OpLogDrawer(抽屉+时间线),挂到详情编辑页与维度编辑页。其余沿用。

**v0.17 → v0.18 变更（增补·size_grid）**：调整「尺码通用样式（size_grid）」规则并**重命名**。①**重命名**：全文「尺寸通用样式」→「**尺码通用样式**」（内部 key `size_grid` 不变）。②**放宽可选条件**：由「仅关联属性为 size/ring_size/shoe_size 时可选」放宽为「**数据源=属性即可选**，不限具体属性、由运营判定」——因尺码属性可能由业务用「枚举类型」自定义创建（非 input type=size），系统无法可靠识别，按 input type 限制会导致这类 size 属性选不到该样式。③**与作用域分组组合**：开启「按作用域分组」时，展示样式**不再固定为「分组」**，可在**「分组 / 尺码通用样式」间二选一**（各筛选模块分别配置）；两者同一套分组数据结构，差异仅组内呈现（分组=竖排、size_grid=一行多列平铺）。未开分组 + 选 size_grid = 枚举值打平后整表平铺。App + PC 均适用。同步 §2.5（行 417 说明、行 450 矩阵、行 459/547 开关联动、行 461 专项约定重写）、§3.12.2、§8.4、R-20/R-26/R-34、§8.6 数据字典注。其余沿用。

**v0.17 → v0.18 变更**：**重构「按作用域分组」枚举值排序模型**——由「逐组固定位置微调」改为**「全局排序表拖拽 + 组内只读预览」**，对齐后台原型 **v0.19-antd**。①**唯一编辑面 = 全局排序表**：分组态下运营不再逐组配置，改为在维度编辑页「分组预览」区的「调整枚举值排序」抽屉里维护**一张全局有序列表**（拖拽即定序）；各作用域组**只读预览、不参与排序**，按全局绝对序渲染本组拥有的值、缺值跳过，某值移动一次所有含该值的组同步生效、相对先后一致。取消组内「固定位置」输入框与排序策略下拉。②**新增「体系顺序」（仅尺码属性）**：一个组同时命中多套尺码体系时，组内先按「体系顺序」分段、段内按该体系全局序；「体系顺序」全站统一，抽屉内拖拽体系卡片决定段落先后；普通枚举属性/单体系不显示该卡片。③**联动单位不变**：普通枚举属性全属性共用一张全局表（复用 attribute_option 序）、尺码属性按体系各一张（复用 size_value 序，同体系联动跨体系互不影响）。④**存储调整**：`value_order_grouped` 由「固定位置 map」`{值:位次}` 改为「有序值列表」（普通属性 `[值,...]`、尺码属性 `{system_id:[值,...]}`）；新增 `system_order` 字段存尺码体系顺序 `[system_id,...]`。打平态（策略 + 固定位置 `value_pins`）与分组态两套存储仍独立互斥。⑤**入口位置微调**：「调整枚举值排序」按钮从分组预览标题行右上角**下移到搜索行右侧、紧贴「展开全部」**，离预览数据更近、业务易发现。同步 §2.5（行 548/549 组内排序整块重写、行 532 去除分组态固定位置提及）、R-26、R-39、§8.6 数据字典（value_order_grouped 语义 + 新增 system_order）、流程图。**组间排序、组标题拼接、异步生成/刷新/平铺兜底、多语言取数、tree 数据结构等均不变**。其余逻辑沿用 v0.17。
