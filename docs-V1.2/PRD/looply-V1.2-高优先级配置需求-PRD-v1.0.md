# Looply V1.2 高优先级配置需求 PRD

版本：v1.0（开发交付版）  
日期：2026-09-24  
优先级：P0  
范围：Shop 横向大图、首页多语言整图、PC 导航推荐图

## 1. 本批次目标

本批次先完成三项直接影响内容上线和导航展示的后台能力：

1. Shop 导航增加“横向大图”卡片样式。
2. 首页 Banner 支持多语言整图，并在每个语言图片下提供可选文字配置。
3. PC 导航展开面板增加推荐图配置。

## 2. Shop 新增横向大图样式

### 2.1 用户端展示

1. 现有 Shop 图文卡片样式命名为「方形图卡」，展示规则保持不变。
2. Shop 右侧内容区新增「横向大图」样式。图片采用横版比例，商品卡片按单列自上而下排列。
3. 每个一级导航只使用一种展示样式，其下末级导航不混用方形图卡和横向大图。
4. 两级导航下，二级导航为末级导航；三级导航下，二级导航为分组标题，三级导航为末级导航。
5. 横向大图不叠加独立标题、说明或按钮文案；图片中的展示文字由运营按语言制作在图片内。末级导航名称仍作为导航结构字段保留，用于导航菜单和配置识别。
6. 点击横向大图后，按该末级导航配置的目标类型和目标值进入 Collection 或自定义 URL。
7. 横向大图前台展示尺寸为 `238×93px`。

### 2.2 运营后台配置

**修改位置**：CMS > Shop页 > 导航配置。

1. 一级导航新建、编辑表单增加「卡片样式」，可选「方形图卡」或「横向大图」。
2. 两级模式在二级导航配置图片；三级模式在三级导航配置图片。
3. 每个末级导航必须上传与所属一级导航展示样式对应的图片；缺少图片时不允许保存该末级导航。
4. 图片上传区根据所属一级导航的展示样式显示建议尺寸；本期不对 Shop 横向大图执行格式、尺寸或比例校验，不因图片规格不符合而拦截上传或保存。
5. 名称、目标类型、关联 Collection 或自定义 URL 沿用现有字段及校验规则；目标类型为 `Collection` 时只校验关联 Collection，目标类型为 `自定义 URL` 时只校验目标 URL。

| 卡片样式 | 上传区尺寸要求 |
|---|---|
| 方形图卡 | `130×130px（2×）` |
| 横向大图 | `476×186px（2×）` |


## 3. 首页 Banner 改为多语言整图配置

### 3.1 用户端展示

1. Banner 展示当前终端、当前语言对应的完整图片。
2. 图片可包含内嵌文字；每个语言图片下配置标题、副标题、标题颜色、副标题颜色、按钮文案。文案按语言保存，有配置值时以前台配置为准。标题、副标题和按钮文案均为空时为纯图片模式，整张图片可点击；任一叠加文案或按钮文案有值时为图文模式，图片和按钮分别可点击，按钮点击不触发图片点击。
3. 整张 Banner 图片为同一个点击区域，点击任意位置均进入该 Banner 配置的跳转目标。
4. 首页 Banner 最多展示 4 个，现有排序及轮播规则保持不变。
5. PC 与 Mobile 分别使用对应终端图片：

| 终端 | UI 1×展示基准 | 上传尺寸 |
|---|---:|---:|
| PC | `1920×747px` | `3840×1494px（2×）` |
| Mobile | `440×322px` | `880×644px（2×）` |

### 3.2 运营后台配置

**修改位置**：CMS > 首页配置 > 首页 Banner。

1. 每个语言图片块下配置标题、副标题、标题颜色、副标题颜色、按钮文案；图片 Alt 仍按语言配置。
2. 文案按语言保存；有配置值时以前台配置为准。图片配置跟随顶部所选终端：选择 PC 时配置 PC 图片，选择 Mobile（App）时配置 Mobile 图片。当前国家全部已启用语言的上传位从上到下直接展示，每种语言一张图，可直接上传或替换。
3. 同一 Banner 的各语言图片共用目标类型、目标配置、排序和上线状态。目标类型可选 `Collection` 或 `自定义 URL`；选择 `Collection` 时必填关联 Collection，选择 `自定义 URL` 时必填目标 URL。
4. 图片未齐可保存下线草稿；当前终端配置上线或保存上线状态时，校验该终端全部已启用语言图片，缺图则保留编辑内容并阻止上线，提示见 3.3。
5. 当前国家新增语言时，启用该语言前必须补齐所有已上线 Banner 对应的 PC、Mobile 图片；存在缺图时不允许启用该语言。

6. 右侧预览使用横向语言页签，选中语言显示紫色文字与下划线；绿点表示当前终端该语言已上传图片，红点表示缺图。切换页签后预览对应图片；缺图时显示空态。
7. 保留现有配置列表、新增、编辑、排序、上下线、关联 Collection 和落地页操作。

#### 3.2.1 配置字段

| 字段 | 类型 | 规则 |
|---|---|---|
| 配置名称 | 文本 | 运营内部备注，可选 |
| Banner 图片 | 多语言上传 | 当前终端每种支持语言一张 |
| 图片 Alt | 文本 | 按语言维护；支持自动填充后手动修改 |
| 目标类型 | Select | Collection / 自定义 URL |
| 关联 Collection | Select | 目标类型为 Collection 时必填 |
| 目标 URL | Input | 目标类型为自定义 URL 时必填 |
| 状态 | Switch | 生效中 / 已暂停 |

### 3.3 校验提示

| 场景 | 提示文案 |
|---|---|
| 当前语言缺少图片 | `请上传{语言}的{终端} Banner 图片` |
| 当前终端上线时多个语言缺图 | `请先上传以下语言的{终端} Banner 图片：{语言列表}` |
| 启用新语言时存在已上线 Banner 缺图 | `请先补齐以下 Banner 的{语言}图片：{Banner列表}` |

### 3.4 数据与埋点调整

1. 客户端公共参数新增 `locale_code`，由当前实际生效的站点语言上下文提供，并由统一客户端埋点 SDK 自动附加到全部客户端事件。
2. `locale_code` 使用产品实际生效的稳定 Locale Code，例如 `en-US`、`es-US`；不得从浏览器语言、IP 或 URL 推断。语言上下文尚未取得时允许不传，不使用默认语言补值。
3. Banner 切换继续使用现有 `ui_interaction`：
   - 点击轮播圆点：`interaction_name=home_banner`、`action=change`、`element_id=banner_dot`；
   - 手势滑动：`interaction_name=home_banner`、`action=change`、`element_id=banner_swipe`。
4. 纯图片模式的图片点击记录 `interaction_name=home_banner`、`action=select`、`element_id=banner_image`、`target_id=目标 page_id`。
5. 图文模式的图片点击记录 `element_id=banner_image`；按钮点击记录 `element_id=banner_cta`、`target_id=目标 page_id`，按钮点击不得同时发送图片点击；标题和副标题不产生独立点击事件。
6. Banner 切换与图片、按钮点击均增加 `position_id`，取值为当前 Banner 在首页轮播中的实际展示位置 `1–4`。排序调整后按事件发生时的位置上报，不使用 `0` 或空位序号。
7. 本期使用 `position_id` 分析第 1–4 个 Banner 展示位的使用情况，不将其解释为稳定 Banner 身份；运营替换图片或调整排序后，同一 `position_id` 可以对应不同素材。
8. 不上报图片 URL、图片中文字、按钮文案或其他素材内容。

## 4. PC 导航展开面板推荐位

1. PC Web 顶部导航展开面板增加图文推荐位；每个推荐位由图片、标题文案、说明文案、目标类型和目标配置组成，整个推荐位均可点击。
2. PC 导航内容按列优先排列：按配置顺序从第一列自上而下填充，每列最多展示 7 行；第一列填满后，从第二列第一行继续排列，依次类推。系统按当前启用导航项数量计算列数：0 项为 0 列，1–7 项为 1 列，8–14 项为 2 列，此后每增加 7 项增加 1 列。
3. 系统按上述实际列数自动决定推荐位数量：0 列不配置；1 列 3 张；2 列 2 张；3–4 列 1 张；5 列及以上不配置。
4. 0 列及 5 列以上时，后台不生成推荐位配置区，前台不展示推荐位。
4. 推荐位在对应一级导航的二/三级导航钻取页配置；图片、标题文案、说明文案、目标类型和对应目标配置均为必填。目标类型可选 `Collection` 或 `自定义 URL`；推荐图前台展示尺寸为 340 × 210 px；上传区提示“建议上传 2 倍及以上图片，推荐尺寸不低于 680 × 420 px（展示比例 34:21）”。该提示不作为保存校验条件，系统不限制固定倍数或固定像素尺寸。
5. 后台在现有二/三级导航钻取页的导航列表下增加「导航推荐图」配置区；推荐位 1、2、3 按顺序单列向下排列，右侧 PCPreview 按前台实际布局实时预览。
6. 配置区展示系统识别的文字导航列数和应配置的推荐位数量；列数变化后立即刷新配置卡片。当前应生成的任一推荐位配置不完整时，不允许保存。
7. 每个推荐位包含图片、标题文案、说明文案、目标类型和对应目标配置；上传、替换、删除图片或修改文案、目标配置后，保存前实时同步到右侧预览。
9. 推荐图只配置一张图片，以及一份英语标题文案和英语说明文案；图片和英语源文案在各语言间共用，其他语言由多语言系统自动提供翻译，不在推荐图配置中逐语言维护。
10. 完整后台交互、校验和边界规则以《Looply Shop PC 导航栏配置 PRD v1.4》第 4.8 节为准。
11. 推荐位曝光和点击必须同时携带所属一级导航稳定 ID、推荐位稳定 ID、当前位置 `1–3` 和目标 Collection 稳定 ID，支持按“一级导航入口 > 具体推荐位”统计曝光、点击和 CTR。
12. 一方曝光新增 `ui_impression`；点击复用 `ui_interaction`。GA4 使用 `view_promotion` 和 `select_promotion`，两端使用同一组稳定标识。
