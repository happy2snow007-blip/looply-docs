# Looply V1.2 产品需求 PRD

版本：v1.1
日期：2026-10-14
范围：C2 用户端与 C2 统一 CMS 后台

## 1. 交付基线

本文件是 C2 V1.2 的单一开发入口。展示和交互以 [C2 统一 CMS Demo v80](../../../outputs/looply-CMS统一配置入口-antd-原型-v80.html) 为准；业务规则补充引用：首页配置 PRD v1.4、Shop/PC 导航 PRD v1.7、Collection PRD v1.6、Footer PRD v0.7。历史版本仅用于追溯，不作为实现依据。

## 2. 国家与语言上下文

- 首页、Shop、PC 导航、Collection、Footer 均按国家隔离配置；后台每个入口独立保存当前国家筛选值，切换只刷新当前入口。
- Market 不作为运营选择项，由系统根据国家内部推导；渠道和终端是国家上下文下的筛选维度。
- C 端先确定当前国家和语言，再读取对应国家、渠道、终端的内容。入口路径按当前 locale 拼接；用户手动选择和子目录国家优先于 IP 推断，无法识别时默认美国。
- 内容不存在时使用该模块定义的默认清单或空态，不把其他国家的已配置内容误展示到当前国家。

## 3. C2 前台规则

### 3.1 首页

- Banner、首页 Collection 按国家、终端和语言读取；同一 Banner 的目标类型、目标配置、排序和启停状态共用，图片按启用语言分别上传。每个语言图片下可配置落地页（只读自动生成）、标题、副标题、标题颜色、副标题颜色和按钮文案；有配置值时以前台配置文案为准，留空时保留图片内文字且不叠加该字段。
- 目标类型为 Collection 或自定义 URL；前者必须有关联 Collection，后者必须是合法 URL。
- 图片未齐允许保存下线草稿；上线时校验当前终端全部启用语言图片，缺图阻止上线。
- Deals 仅在当前国家和渠道下可售且带 `save` tag 的商品达到 20 个时展示；不足 20 个隐藏。

### 3.2 Shop 与 PC 导航

- Shop 一级导航选择两级或三级、方形图卡或横向大图；所有层级支持拖拽排序、启停，停用后才可删除。
- 方形图卡：二级、三级均配置 Name 和按国家启用语言上传的 1:1 图片；横向大图：按层级规则将名称制作在图片或配置为分组标题。
- PC 导航支持直达、两级、三级；直达项不可钻取，其余可进入下级管理页。L1/L2/L3 支持排序、启停和停用后删除。
- PC 推荐图数量由实际导航列数自动计算；推荐图配置图片、标题、说明和目标类型，缺字段不能保存。

### 3.3 Footer 与 Contact Us

- Footer Shop、Sell、Support 按国家读取，入口名称由翻译系统提供，站内 URL 自动补齐国家和语言路径。
- Sell 入口、Seller FAQ、Seller Agreement 受国家 Sell 状态控制。
- Contact Us 页面保留；Selling Inquiries 及出售邮箱按当前国家 C2 与 Sell 状态联动，其他三类咨询不受 Sell 开关影响。分类、邮箱及服务端分发校验统一见[Contact Us PRD v0.3](../../docs-Contact-Us/PRD/looply-Contact-Us-PRD-v0.3.md)第三至五章。
- 法律文件按国家和法务语言维护，不走自动翻译；FAQ 按国家维护英语原文，进入翻译系统。

## 4. C2 CMS 页面与交互

### 4.1 首页配置

提供 Banner、首页 Collection、SEO 三个入口。列表展示配置数、生效中、已暂停；支持新增、编辑、拖拽、启停；仅已暂停项显示删除。右侧预览跟随国家、终端和当前编辑内容实时更新。

### 4.2 Shop 配置

一级列表展示排序、名称、层级、卡片样式、启用导航数、状态和操作。点击可钻取下级；新增/编辑抽屉展示国家、渠道、终端只读上下文，并根据卡片样式和层级动态显示 Name、图片、目标类型、Collection/URL、状态字段。图片按语言上传，上传失败不得覆盖已有图片。

### 4.3 PC 导航配置

一级列表和二三级钻取页均支持拖拽、启停、停用后删除；直达项名称不可点击。二三级页提供新增/编辑抽屉、推荐图配置和右侧实时预览。保存前校验目标类型、链接、推荐图必填字段。

### 4.4 Collection 管理

按国家管理 Collection 基础信息、商品池、筛选模块、排序和状态；上线时执行标题、商品池、筛选数量和默认排序校验。前台按当前国家读取，商品卡点击进入商详页。

### 4.5 Footer 管理

Footer 后台包含法律文件、FAQ 和社媒账号三个页签。法律文件类型由开发预置，线上数据库中的当前版本是唯一事实来源。运营可下载当前版本，并通过上传法务确认的 `.docx`、`.html` 或 `.rtf` 富文本发布新版本；系统自动生成版本号，新版本发布后直接成为当前版本，原版本进入历史记录。发布时校验文件来源版本，来源落后则阻止覆盖。法律文件按当前国家和法务语言读取，缺少匹配语言时仅回退当前国家英语版本，不跨国家回退。后台不提供在线修改正文，并保留版本号、发布时间和操作人等审计信息；支持 HTTPS、站内相对路径和同页锚点。FAQ 上传英语富文本后解析为问题列表，覆盖导入按稳定标识保留既有启停、首页精选和排序，追加导入拒绝重复标识；新条目默认启用且不设首页精选。FAQ 的排序、启停、删除和首页精选由页面顶部统一保存；启用项需先停用再确认删除。无启用 FAQ 时独立页显示空状态，无启用且首页精选 FAQ 时隐藏首页模块。社媒账号的平台名称和图标由开发预置，运营按国家配置 Facebook、TikTok、Instagram、YouTube 的账号 URL；URL 有效时前台展示，URL 为空时隐藏，不跨国家回退。

## 5. 通用异常与验收

- 保存、上传、排序、启停失败时保留用户输入，不显示为成功。
- 启用项删除按钮置灰；停用后删除需二次确认；级联删除明确提示影响范围。
- 国家切换后不得残留上一国家的列表、预览或编辑数据。
- 目标链接、图片比例、语言缺图和富文本危险协议均在保存/上线前阻止并定位错误。
