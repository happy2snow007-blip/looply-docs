## 跨制品一致性

| 检查项 | PRD | 原型／设计稿 | 结论 |
| --- | --- | --- | --- |
| 支付方式顺序 | Payment Card → PayPal → Apple Pay → Klarna → Afterpay → Affirm | 原型同序 | 一致 |
| Afterpay 金额 | 1–4,000 USD | 原型 1–4,000 USD | 一致 |
| Affirm 金额 | 35–30,000 USD | 原型 35–30,000 USD | 一致 |
| 不满足门槛 | 隐藏方式，其他方式不重排 | 原型按金额隐藏 | 一致 |
| 卡支付字段 | 卡号、有效期、安全码、持卡人姓名 | 原型字段齐全 | 一致 |
| Billing Address | 可复用收货地址或填写账单地址 | 原型可勾选并隐藏重复填写 | 一致 |
| 失败／取消 | 恢复支付方式 | 原型已验证 | 一致 |
| Payment confirming | 隐藏方式与付款按钮 | 原型已验证 | 一致 |
