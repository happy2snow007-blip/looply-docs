# 订单支付 V1.4 → V1.5 核心差异汇总

> 日期：2026-09-22｜用途：开发评审与改造范围确认

## 一、这版解决什么

新增香港站后，订单支付只新增四个核心能力：订单固定属于哪个站、整条交易使用哪个币种、香港能展示哪些已验证的支付方式、退款能否按原支付记录退回。美国站原有流程保持不变。

## 二、开发改动

| 范围 | V1.4 | V1.5 |
|---|---|---|
| 交易归属 | 默认按美国站理解 | 结算创建时冻结 Market、国家／地区、渠道和币种；父订单、子订单、支付单继承 |
| 币种 | USD | 美国 USD；中国香港 HKD；同一交易只允许一个币种，不换汇 |
| 支付方式 | 固定展示既有方式 | 支付方式主数据绑定通道与商户账号；收单路由只决定各 Market 可用方式；未完成香港全链路验证的不启用 |
| 回调 | 按既有支付单处理 | 增加金额、币种一致性校验；不一致不确认到账 |
| 退款 | 按原支付链路退款 | 明确使用原币种、原通道和原商户账号；支付方式关闭后历史订单仍可退款 |
| 切站 | 未定义 | 只影响新结算；既有订单、回调、退款不随用户当前站点变化 |
| 后台 | 无 Market 维度 | 交易列表增加 Market 筛选与列，Market 放在主单号之后；不单列币种，金额字段自行携带币种；新增收单配置页面 |
| 历史数据 | 无多站字段 | 香港开站前正常生产交易标记为 US／USD，不改金额、不触发交易动作 |

## 三、未改动

- 结算页和订单成功页布局不变。
- 库存锁定、父订单待付款、支付成功后拆子订单、Webhook 状态机不变。
- 不新增支付渠道、支付方式枚举、实时换汇或混合币种订单。
- 地址、物流、税费和优惠计算由对应模块提供，订单只校验结果币种并冻结快照。

## 四、上线门槛

1. 香港 Market 可创建新结算，商品有 HKD 报价。
2. 香港地址与配送结果可用，金额币种为 HKD。
3. 至少一种支付方式完成 HKD 收款、回调、查单、部分退款、全额退款和对账验证。
4. 美国站 USD 全链路回归通过。
5. 关闭香港新结算后，历史香港订单仍可查单、履约和退款。

## 六、开发阅读顺序

1. 先读 V1.5 迭代 PRD，确定本期改动。
2. 用完整 PRD v1.5 查既有业务规则和跨章节口径。
3. 用增量 ER 与增量流程核对字段继承和异常分支。
4. 按香港站支付渠道增量对接要求完成真实商户账号联调；能力清单未通过前不要开放该支付方式。
