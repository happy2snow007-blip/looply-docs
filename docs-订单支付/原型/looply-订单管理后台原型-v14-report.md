| 验证 | 结果 |
|---|---|
| `check_runtime.py`（逐页注入 error 捕获 + Chrome dump-dom） | **8 个页面全部无运行时错误**（abandoned-cart / abandoned-detail / order-detail / order-list / payment-order-list / payment-txn-list / reconciliation / refund-order-list）。全绿即证明 Babel 编译通过——编译失败会让所有页面同时报错 |
| 整页截图 · 订单列表（1440×1600） | 204KB，筛选区两行、搜索类型下拉、订单号链接、导出按钮均正常渲染 |
| 整页截图 · 订单详情（1440×2600） | 365KB，品牌两行 / 复制地址按钮 / 优惠码列 / United States 四处改动**目视逐项确认** |

## 四、形态证据（不判对错，需人工过）

- **操作列按钮数**：最多 3 个（查看详情 / 发货 / 发起退款），未触发 A.1.1 的 >4 收纳阈值。
- **`<a>` 与 antd Button 混用**：订单号列用原生 `<a>`（需保留等宽药丸样式），查看详情用 `<Button href>`。两者都渲染为 `<a>`，四种浏览器原生打开行为一致；样式差异是刻意的（一个是数据、一个是操作）。
- **`openDetail` 的 preventDefault**：仅拦截无修饰键左键，用于**原型内可点**；代码注释已写明「生产环境不要 preventDefault」。
