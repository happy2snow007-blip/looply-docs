1Header & 库存二次校验核心▾
简化 Header
Checkout 使用简化导航栏：隐藏分类/搜索/心愿单/购物车，仅保留居中 logo。
库存二次校验
进入 Checkout 时校验
后端实时校验所有结算商品库存。售罄商品弹 Modal："Back to Cart" / "Continue Without"。
Pay Now 时再次校验
创建订单前最后一道库存锁定。
2地址 Delivery核心▾
组件架构
地址区域是独立可复用组件，Checkout 加载。组件内部管理 7 种视图状态。
7 种视图状态
A. 默认态
单张灰底地址卡片 + 右上 "Change"。
B. 空地址态
"No delivery address on file." + 紫色 "+ Add Delivery Address"。
C. 选择列表
Radio 单选 + 每行 Edit + "Add New Address"。右上变 "Cancel"。
D. 新增地址（Modal 弹窗）
点击 "+ Add New Address" 弹出居中 Modal。字段：First/Last name、Street、Apt、City/State/ZIP、Phone（🇺🇸 +1）。点击遮罩层或 × 或 Cancel 关闭。
E. 编辑地址（Modal 弹窗）
点击 "Edit" 弹出同一 Modal，字段预填已有数据，按钮 "Save Changes"。
F. 地址不合规
粉色 Banner + 红色边框卡片 + "Edit address"。
G. 配送限制
PO Box 警告 + "Change Address" / "Browse Other Products"。Pay Now 禁用。
3物流 Shipping核心▾
当前仅一档
Standard FedEx Shipping，Est. 5–10 business days，Free。单选 Radio 预选中（唯一选项）。
扩展预留
模块结构支持后续新增多档物流（如 Express 2-Day）。Radio 列表自动扩展，无需改结构。
地址联动
切换收货地址后，物流选项和价格可能变化（如偏远地区无 Express）。当前单档 Free 不受影响，预留接口。
支付
4支付 Payment核心▾
支付选择
三种 Radio 单选：Credit/Debit Card（默认，内联表单）、PayPal（跳转）、Klarna（先买后付，跳转）。
信用卡表单
Card Number、Expiration、Security code、Name on Card。通过 Airwallex 处理。
Billing Address
默认同 Shipping
勾选框 "My billing address is the same as my shipping address"，默认勾选。取消勾选展开独立账单地址表单。
Billing 表单
字段：First/Last name、Street、Apt、City、State、ZIP。无 Phone（账单地址不需要电话）。用于信用卡 AVS 验证。
所有支付方式通用
Billing Address 对 Credit Card、PayPal、Klarna 均显示。PayPal/Klarna 跳转前也需收集账单地址用于风控和对账。
5订单摘要 & 下单核心▾
Sticky 侧边栏
商品行含缩略图 + 名称 + 成色标签 + 单价（PC 端不再单独设 Review Items 步骤）。Subtotal + Shipping (Free) = Total。本期不含 Estimated Tax。
Pay Now
按钮变 "Processing..."。禁用条件：未选地址 / 未选支付 / CC 未填完 / 配送限制。
