1
Checkout Header
Nav ▼
Back Button
Tap < back arrow returns to Shopping Cart page. If entered from PDP single-item checkout, returns to PDP.
Secure Badge
Green "Secure" badge with lock icon signals SSL-encrypted checkout. Simplified header without search/cart icons to reduce distractions.
2
Shipping Address
Core ▼
Address Selection
Tap any saved address to select it. Active address shows purple border + check mark. Default address is pre-selected on page load.
Add New Address
Tap "+ Add New Address" expands inline form with fields: First/Last Name, Street, Apt, City, State, ZIP, Phone. "Manage" link navigates to address management page.
US Format
Address format follows US standard: Street + City + State abbreviation + ZIP code. State uses dropdown picker on mobile. Phone follows (xxx) xxx-xxxx pattern.
No Saved Address
If user has no saved addresses, the form expands automatically. "Place Order" is disabled until a valid address is saved.
3
Review Items
Info ▼
Read-Only Display
Items shown in compact read-only format with image, brand, name, condition badge, and price. No quantity selector (secondhand items are unique, qty=1).
Edit Cart
Tap "Edit Cart" returns to Shopping Cart. Changes in cart are reflected when user returns to checkout.
4
Payment Method
Core ▼
Method Selection
Radio-style selection between Credit Card (inline form), PayPal (redirect), and Klarna (redirect). Credit Card is pre-selected by default.
Credit Card Form
Inline form shows when CC is selected: Card Number, Expiry (MM/YY), CVV, Name on Card. Card icons (Visa/MC/Amex/Discover) shown above inputs. Input fields stack vertically for mobile.
Redirect Notice
Selecting PayPal or Klarna shows redirect notice below the option: "You'll be redirected to [provider]..." CC form hides when other method is selected.
Payment Providers
CC processed via Airwallex. PayPal via PayPal SDK. Klarna via Klarna Payments API. All PCI-compliant, card data never touches our server.
5
Order Summary & Place Order
Core ▼
Price Breakdown
Shows Subtotal (N items), Shipping (Free for most orders), Estimated Tax (~4% simplified rate), and Total. Tax calculated based on shipping address state.
Place Order
Tap "Place Order" submits the order. For CC: processes payment immediately. For PayPal/Klarna: redirects to provider. Button shows "Processing..." state during submission.
Terms Agreement
Text below button: "By placing your order, you agree to..." with links to Terms of Service and Privacy Policy. Implied consent model (standard in US e-commerce).
Payment Failure
If payment fails, inline error message appears above the button: "Payment failed. Please check your card details." Order is not created. User can retry.
6
Entry Points & Navigation
Nav ▼
From Cart
Cart Checkout button brings selected items into checkout. Back button returns to cart.
From PDP
PDP "Buy Now" button brings single item directly to checkout. Back button returns to PDP. Cart is not affected.
Login Required
Checkout requires authentication. If user is guest, redirect to Login first, then return to Checkout after successful auth. Cart contents preserved via local storage.
