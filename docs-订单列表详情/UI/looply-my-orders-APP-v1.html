1
Header & Search
Nav ▼
Back Button
Tap < back returns to My Account page. Entry from tab bar: back goes to previous tab.
Search Icon
Tap search icon expands inline search bar below header. Searches by order number or item name. Results filter order list in real-time.
2
Status Tabs
Core ▼
Tab Switch
Horizontal scrollable tabs: All, Confirmed, On its way, Cancelled. Active tab shows purple underline. Each tab shows count badge.
Filter Behavior
Switching tab filters order list instantly. Count badges update when orders change status. "All" shows all orders in reverse chronological order.
Horizontal Scroll
When tabs overflow screen width, user can scroll horizontally. Active tab auto-scrolls into view on page load.
3
Order Cards
Core ▼
Card Structure
Each card: Header (order ID + date + status badge) → Items (image/brand/name/condition/price) → Footer (total + actions). Cards separated by 8px gray gap.
Status Badges
Color-coded: Confirmed (blue), On its way (orange), Cancelled (red). Each with matching dot indicator.
Multi-Item Orders
Orders with multiple items show each item stacked vertically. Max 3 items displayed inline; if more, shows "+N more items" link.
Item Tap
Tapping an item image or name navigates to PDP (product detail page). Tapping anywhere else on the card navigates to Order Detail page.
4
Order Actions
Action ▼
View Details
Primary action on every order. Navigates to Order Detail page with full timeline, items, tracking info, and support options.
Track Package
Shown only for On its way orders. Opens tracking page with carrier info (USPS/FedEx/UPS) and real-time tracking updates.
Buy Again
Shown for completed orders. For secondhand items: if still available, adds to cart. If sold, shows "Item no longer available" toast with "Similar Items" link.
Cancelled Orders
Shows "Refunded" label next to total. Only "View Details" action available. Detail page shows cancellation reason and refund status.
5
Empty & Loading States
Edge ▼
Empty State
When no orders exist (or filtered tab is empty): shows shopping bag icon + "No orders yet" / "No [status] orders" + "Start Shopping" CTA button.
Pull to Refresh
Pull-to-refresh gesture reloads order list from server. Spinner shows during loading. Skeleton cards shown on initial page load.
Infinite Scroll
Orders load in pages of 10. Reaching bottom triggers next page load with spinner. No explicit pagination controls on mobile.
