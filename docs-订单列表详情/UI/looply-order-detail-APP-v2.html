Order Detail - APP v2

Shipped status view with compact progress stepper + tracking
1 Header & Navigation
Back Button
TapReturns to My Orders list page. Preserves the active tab filter.
More Menu
TapBottom sheet: Download Invoice, Share Order, Report Issue.
Order Number
GestureLong press copies order number with haptic feedback and toast.
2 Order Status (Compact Stepper)
Horizontal Progress
State5-step horizontal stepper replacing vertical timeline. Green check = done, green pulse = current, gray = pending. Progress bar fills proportionally to current step.
Status Summary Card
StateBelow stepper, green card shows current status with icon + one-line description + estimated delivery date. Adapts per status:
• Processing: truck icon, "Items being prepared for shipment"
• Shipped: truck icon, "Your package is on the way" + delivery estimate
• Delivered: check icon, "Delivered on Jun 10" + signed-by info
V1 vs V2 Comparison
StateV1 used full vertical 5-step timeline (~180px height). V2 compact stepper takes ~100px. 65% space saved, same information density.
3 Tracking & Logistics
Tracking Card Visibility
StateOnly visible when status = Shipped or Delivered. Hidden for Processing/Placed/Cancelled.
Carrier & Tracking Number
TapHeader shows carrier name + tracking number. Tap tracking number copies to clipboard with toast. Long press opens carrier website in in-app browser.
Latest Event
StateHighlighted with green dot. Shows event description + timestamp + location. Auto-updates via push notification.
Previous Events
StateShows 2 most recent previous events in compact single-line format. Provides quick context without full history.
View Full Tracking History
TapOpens full-screen tracking detail page with complete event timeline, map view (if supported), and carrier link.
4 Items & Shipping Details
Item Card
TapNavigates to PDP. Shows brand, name (single line ellipsis), condition badge, price.
Shipping Address
StateRead-only. Full US format. Cannot be changed after order placed.
5 Payment Summary
Price Breakdown
StateSubtotal + Shipping + Tax = Total. Matches checkout/success pages.
Refund Scenario
Edge CaseCancelled/refunded orders show Refund line below total with amount + status (Pending/Completed).
6 Actions by Order Status
Processing
TapCancel Order (red outline) + Contact Support (purple outline).
Shipped (Current View)
TapTrack Package (primary purple fill) opens carrier tracking in in-app browser. Contact Support remains. Cancel Order hidden.
Delivered
StateBuy Again (primary) + Request Refund (outline) + Contact Support.
Cancelled
StateBuy Again (primary). Refund status banner at top. Cancel/Track hidden.
7 Edge Cases & Navigation
Entry Points
Tap3 paths: My Orders list, Order Success page, push notification.
Pull to Refresh
GesturePull-down refreshes order status + tracking events.
Network Error
Edge CaseShows retry screen with cached data fallback if available.
Multi-package Orders
Edge CaseIf order splits into multiple shipments, tracking card shows tabs per package (Package 1 of 2, Package 2 of 2), each with independent tracking info.
