### 新增表定义

**`operation_log`（配置类操作审计）**
```
id (PK)
entity_type     实体类型(currency_pair_config / spread_rule / exchange_rate_source / alert_threshold / ...)
entity_id       实体ID
operation_type  切换为自动模式 / 切换为固定模式 / 设置固定汇率 / 点差调整 / 数据源编辑 / 阈值编辑 / 币种停用 / 主备切换
before_value    变更前(JSON/文本)
after_value     变更后
change_reason   变更原因
operator        操作人
created_at      操作时间
```
分工：`rate_change_log` = 汇率值变动（仅定时/手动发布）；`operation_log` = 配置类变更，各功能页底部 OpLog 按 entity 过滤展示。

**`alert_threshold_config`（告警阈值）**
```
id (PK)
threshold_pct   当前阈值(>0, ≤50, 1位小数)
effective_from  生效时间
updated_by      更新人
updated_at      更新时间
```
修改历史走 `operation_log`（entity_type=alert_threshold）；`exchange_rate_alert.threshold_pct` 仍保留为触发时快照。
