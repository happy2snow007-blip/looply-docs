# 文件配置原型说明

更新日期：2026-10-20。对应[文件配置 PRD v1.0](../PRD/looply-文件配置-PRD-v1.0.md)和[当前 Demo](./looply-Footer-多国家配置-迭代Demo-v1.0.html#/footer)。本轮按用户“全部修完”修复预评审中的文档和原型问题，未发布文档中心。

## 一、依据与组件

- 沿用 CMS v80 及本轮已经确认的国家范围、整批回滚、FAQ 两种文件来源规则。用户确认暂无更新的正式 UI；本轮浏览器检查仅验证 Demo 的可用性与布局，不代替正式 UI 对齐。
- React 18.3.1、antd 6.4.3、Babel 7.28.4，表格、抽屉、确认框、上传、开关、表单均使用现有 antd 组件。保留统一配置入口中其他模块的页面。
- 美国样例按首页 PRD v1.10 使用英语与西语；英国、加拿大、澳大利亚只是测试国家样例，不代表已开通市场或实际语言配置。

## 二、本次修复

- 法律列表、上传和回滚使用同一市场语言配置；补齐更新时间、统一文件名称、明确解析失败状态。普通上传和历史文件带入均有自动正文预览。
- 历史按完整发布批次展示，标识当前版，仅历史版可回滚。二次确认后带入对应语言，新增语言补齐、移除语言排除；发布前检查版本及语言集合，生成新批次并保留来源、补充语言及全部文件。
- FAQ 接受下载后修改与自行制作的 HTML。保留富文本、稳定标识及锚点，校验外壳、标题结构、链接、重复或未知标识、来源国家和版本；无来源文件及空国家也记录打开时的版本并在保存前检查。
- FAQ 提供完整正文预览，保留跨题锚点；导入后可实际下载包含稳定标识和来源版本的 HTML。无标识条目生成新标识并默认不精选；已有条目保留精选，源文变化递增源版本。翻译平台关联仍需真实服务实现。
- FAQ 拖拽排序、精选和删除进入草稿，点击保存后生效。列表保存重查版本及完整锚点，避免删除目标后形成断链。
- FAQ 与社媒的草稿和已保存内容分开；国家、页签及菜单切换时支持继续编辑或放弃，放弃实际恢复已保存内容。
- 社媒支持空值，非空校验 HTTPS 地址，错误显示在字段附近；隔离国家保存。

## 三、PRD 冲突与缺口

原先的单语言回滚、丢失答案 HTML、放弃后不恢复、下载／拖拽占位和完整网页接受范围不一致已修复。FAQ 翻译资源及前端消费按用户确认沿用已有能力和其他需求，原型不另行定义；其来源与引用维护记录统一见[技术依赖 Checklist](../PRD/looply-文件配置-技术依赖Checklist.md)。

## 四、运行边界

数据仅保存在当前页面内存，刷新恢复样例。下载内容是本地保存的正文；初始化法律文件为明确的演示文本，不是现行法律内容。浏览器解析与清洗不等于生产服务安全验收。

没有接入真实市场主数据、版本存储、翻译平台、权限或邮件服务。本轮冲突验证通过测试夹具改变内存版本／语言集合，验证的是 Demo 的阻止覆盖行为，不是服务端并发、持久化、权限或失败恢复验收。FAQ 首页摘录后的锚点和前端语言回退由消费需求承接。

## 五、布局与自主修正

采用既有后台布局，法律列表补字段，历史抽屉改按批次展示，FAQ 预览展示完整正文以保留有效锚点。修正过窄的排序列；没有新增业务开关或未确认的用户操作。

在 1440×1000 与 1280×900 视口查看法律列表、FAQ 列表、导入和回滚；截图及交互证据见[修复核对记录](../评审记录/looply-文件配置-预评审修复核对-20261020.md)。

## 六、核验结果

- 静态脚本：12 Pass / 1 Warn / 0 Fail；警告来自未修改的 Shop 组件样式。Babel 编译通过。
- `render_sim.py` 无可自动识别的详情组件，实际跳过；不将它的退出码视为渲染验收。
- 浏览器测试覆盖 17 项解析校验和 11 组交互／布局检查，无页面 JavaScript 异常。已实际验证下载、草稿放弃、排序保存、冲突阻止及回滚语言增减。
- 对本次实际修改段落与引用完成回读；独立 Astra / high 复检结果及剩余依赖以修复核对记录为准。未冻结为完整开发交付基线。
