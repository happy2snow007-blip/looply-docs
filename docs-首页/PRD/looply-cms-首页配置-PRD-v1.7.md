# Looply · CMS 首页配置 PRD

**版本** v1.7 | **日期** 2026-11-25 | **范围** 首页资源位配置（Banner + Collection 坑位 + SEO 配置）

---

## 一、概述

### 1.1 背景与目标

Looply 首页内容需要运营团队高频更新，包括 Banner 大图、Collection 入口等。本模块目标是让运营在不依赖开发的情况下，完成首页两个核心坑位的内容日常管理。

**设计原则：**

- **骨架写死，内容放开**：首页 Section 的上下顺序由产品硬编码，运营只配各 Section 内的内容，不能改页面结构
- **全局上下文常驻**：顶部紫色 Sticky Bar 始终显示当前操作的「市场 · 渠道 · 终端」，避免误操作
- **预览上下文常驻**：配置资源位时，右侧始终展示对应终端（App/PC）的完整页面预览，当前编辑坑位高亮紫色框，其他 Section 灰显占位
- **发布生效**：列表启停确认或配置页保存成功后，前台按启用状态与时间窗读取配置，无需开发部署

### 1.2 本期范围

本文档仅覆盖**首页配置**模块，对应 `ops.looply.com/cms/home` 后台左侧导航「首页」条目。

本期支持坑位：
- 首页 Banner（`home_banner`）
- 首页 Collection（`home_collection`）

本期新增：
- 首页 Banner / Collection 配置复制与定时上下线（§8.6–§8.7）
- 首页 SEO 配置（页面级 Meta Title、Meta Description、OG 分享图）

本期不覆盖：Shop 页、合集管理、全局配置、搜索配置。

### 1.3 用户角色

一期只有一种角色：**运营**，登录即有全部操作权限。

### 1.4 页面入口

```
ops.looply.com/cms/home
└── 主导航（左侧固定）
    └── 首页    ← 直接可点击，进入首页配置编辑器
```

> 「首页」是左侧导航的直接顶级条目，无父级分组，点击后进入首页资源位配置页面。

## 二、核心概念

| 概念 | 说明 |
|------|------|
| 坑位（Zone） | 首页上固定的内容承载区，由产品定义，运营不可新建 |
| 模板（Template） | 坑位支持的视觉样式，由开发实现，运营只选不建 |
| 配置（Config） | 运营在某个坑位用某个模板填充的一条内容记录。每条配置包含素材及跳转目标；Banner 可关联 Collection 或自定义 URL，Collection 坑位关联 Collection |

**配置与前台展示关系：**

同一坑位下多条上线配置，统一以横向平铺+支持左右滑动方式在前台展示：
- **Banner 坑位**（`banner_image`）：多条配置自动轮播，用户也可左右滑动切换
- **Collection 坑位**（卡片/Chip 类）：多条配置横向排列，用户主动左右滑动，不自动轮播

## 三、全局配置 Bar

### 3.1 位置与外观

- 位置：位于顶部 Header 下方，吸顶并始终可见。
- 背景与左侧边框沿用线上样式。
- 内容：「全局筛选 (Global Context)」标签 + 三个下拉选择器（市场、渠道、终端）

### 3.2 三个维度

| 字段 | 当前值 | 交互方式 |
|------|--------|---------|
| 国家（Country） | US（当前已配置国家）| 内容区 Config Bar 的 Select 下拉；配置记录按国家隔离，Market 由系统根据国家推导，仅作用于首页配置入口 |
| 渠道（Channel） | 官方站（唯一选项）| Select 下拉，当前仅官方站 |
| 终端（Terminal） | App / PC | Select 下拉，切换后预览区实时切换为对应终端预览 |

### 3.3 作用范围

全局 Config Bar 选定的市场+渠道+终端，决定：
1. 左侧坑位配置列表中展示哪套数据
2. 右侧预览面板渲染哪个终端的效果（App 手机框架 / PC 浏览器框架）
3. 进入配置编辑器后，基本信息区「市场/渠道/终端」字段置灰只读，展示当前全局值

### 3.4 DimBadge（维度标签）

配置编辑器 Header 区展示一个蓝色胶囊 Badge，内容为 `market · channel · terminal`（如 `US · 官方站 · 📱 App`），用于在编辑态始终提示当前配置归属维度。

## 六、配置字段结构

### 6.1 通用字段（所有模板共用）

| 字段 | 标签 | 类型 | 必填 | 说明 |
|------|------|------|------|------|
| `config_name` | 配置名称 | text | 否 | 运营内部备注，不对外展示 |
| `country_code` | 国家 | readonly | 是 | 由全局 Country Config Bar 锁定，进入编辑器后置灰；系统据此推导 `market_id` |
| `channel` | 渠道 | readonly | 是 | 由全局 Config Bar 锁定，进入编辑器后置灰 |
| `terminal` | 终端 | readonly | 是 | 由全局 Config Bar 锁定，进入编辑器后展示为只读 span |
| `zone_key` | 坑位 | readonly | 是 | 由坑位行选定，进入编辑器后置灰 |
| `target_type` | 目标类型 | select | 是 | Banner 支持 Collection / 自定义 URL；Collection 坑位固定为 Collection |
| `collection_id` | 关联合集 | select | 条件必填 | 目标类型为 Collection 时必填；按 `country_code` 及其推导的 `market_id` 过滤可用合集 |
| `target_url` | 目标 URL | input | 条件必填 | 目标类型为自定义 URL 时必填 |
| `landing_page` | 落地页名称 | readonly | 自动填充 | 从关联合集读取，只读展示，可点击跳转 |
| `landing_page_url` | 落地页链接 | hidden | 自动填充 | 从关联合集读取，后台不直接展示 URL，通过点击 `landing_page` 跳转 |
| `title` | 标题 | text | 否 | 按语言保存；有值时覆盖图片内文字或合集兜底文案 |
| `subtitle` | 副标题 | text | 否 | 按语言保存；有值时覆盖图片内文字或合集兜底文案 |
| `title_color` | 标题颜色 | radio + color | 否 | 白色 `#ffffff` / 黑色 `#070707` / 灰色 `#5F5F5F` / 其他 |
| `subtitle_color` | 副标题颜色 | radio + color | 否 | 白色 `#ffffff` / 黑色 `#070707` / 灰色 `#5F5F5F` / 其他 |
| `button_text` | 按钮文案 | text | 否 | Banner 按语言保存；Collection 仍执行坑位全局 CTA 规则 |
| `alt` | 图片 Alt 文案 | text | 否 | 按语言维护；图片 SEO 描述文案，见 §6.4 |
| `asset_image` | 素材图片 | image | 必填 | Banner 按当前终端、当前国家启用语言分别上传；规格见 §十一 |
| `online` | 上线开关 | switch | — | 启用 / 停用；与当前展示状态区分，见 §7、§8.7；提交时机见 §8.5.5 |
| 开始时间 | 开始时间 | datetime | 否 | 按所属市场基准时区设置展示窗口开始边界，规则见 §8.7 |
| 结束时间 | 结束时间 | datetime | 否 | 按所属市场基准时区设置展示窗口结束边界，规则见 §8.7 |

### 6.2 字符数限制

| 字段 | 限制 | 备注 |
|------|------|------|
| `title` | ≤ 30 字符 | 所有终端统一 |
| `subtitle` | Mobile（App）≤ 30 字符；PC ≤ 100 字符 | 按当前终端动态切换上限 |
| `alt` | ≤ 125 字符 | SEO 推荐上限 |

编辑框显示实时字符计数（`showCount`），达到上限后不可继续输入。

### 6.3 标题/副标题自动填充规则

1. 运营选择「关联合集」时，系统从合集数据中读取 `title` 和 `subtitle`
2. **仅当对应字段当前为空**时自动写入，已有内容不覆盖
3. 自动填入后可手动修改，修改后不再随合集变化
4. 若留空，前台展示时读取合集原始标题/副标题作为 fallback（C 端逻辑，非 CMS 逻辑）。Banner 的标题、副标题和按钮文案均为空时，优先按 §8.5.4 的纯图片模式展示。

### 6.4 图片 Alt 自动填充规则

每条配置的素材图片上传后，编辑器内展示 `alt` 输入区，包含「自动填充」按钮：

1. **自动填充逻辑**：点击后按照 SEO 规范（待 SEO 团队确认后写入此处）自动生成 alt 文案，填入字段
2. **手动编辑**：运营可在自动填充后手动修改文案
3. **恢复自动填充**：字段已手动修改后，再次点击「自动填充」按钮，覆盖为最新自动生成结果
4. **图片更换**：更换图片后自动填充结果同步失效，需重新点击「自动填充」或手动输入
5. **留空处理**：alt 留空时，前台按 SEO 统一兜底逻辑处理（非 CMS 强制填写）

> **SEO 规范占位**：自动填充所用规范由 SEO 团队提供后更新此处，暂定格式参考：`{商品类别} - {品牌} - Looply`

### 6.5 按钮配置

首页 Collection 坑位保留**全局 CTA 按钮**，作用于该坑位所有上线配置。Banner 按钮文案改为每条 Banner、每种语言独立配置，不再读取 Banner 坑位级全局 CTA。

| 字段 | 标签 | 类型 | 必填 | 说明 |
|------|------|------|------|------|
| `button_text` | 按钮文案 | text | 否 | 该坑位所有配置共用；留空时前台不展示按钮 |

- 配置入口：仅选中 Collection 坑位 Tab 时，在配置列表上方展示「坑位全局设置」区；Banner 坑位不展示该区
- 该坑位全局 CTA 规则仅适用于 Collection
- 按钮样式（颜色、字体颜色）由设计在各模块视觉规范中定义，CMS 不提供配置项

## 七、配置状态

| 当前展示状态 | 条件 | 前台行为 |
|---|---|---|
| 生效中 | 已启用且处于开始／结束时间窗内 | 展示 |
| 已暂停 | 未启用，或尚未进入／已经离开时间窗 | 不展示，保留配置 |

开关表示配置是否启用，与当前展示状态区分；时间跨过边界不改写启用状态或清空时间。排期与统计规则见 §8.7。

## 八、页面结构与交互

### 8.1 整体布局

```
┌─────────────────────────────────────────────────────────────────┐
│  顶部 Header（含 Logo、全局导航）                                  │
├─────────────────────────────────────────────────────────────────┤
│  全局 Config Bar（Sticky，紫色底）                                │
│  全局筛选  [🇺🇸 US ▾]  [官方站 ▾]  [📱 App ▾]                   │
├──────────────────────────────────┬──────────────────────────────┤
│  左侧主区域（52% 宽）             │  右侧预览区（flex:1）          │
│  ┌─── KPI 概览 ───────────────┐  │  （手机框架 / 浏览器框架）      │
│  │ 总配置数 · 生效中 · 已暂停   │  │                              │
│  └────────────────────────────┘  │                              │
│  ┌─── 坑位选择行 ─────────────┐  │                              │
│  │ [首页 Banner] [首页Collection] │  │                              │
│  └────────────────────────────┘  │                              │
│  ┌─── 配置列表 / 编辑器 ───────┐  │                              │
│  │ （点击行进入编辑器，原位替换） │  │                              │
│  └────────────────────────────┘  │                              │
└──────────────────────────────────┴──────────────────────────────┘
```

### 8.2 KPI 概览区

展示三个数值卡片（紫色渐变底）：
- 总配置数：当前国家+渠道+终端下所有坑位的配置总数
- 生效中：已启用且当前处于展示时间窗内的配置数
- 已暂停：未启用、尚未开始或已经结束的配置数

### 8.3 坑位选择行（Zone Filter Bar）

- 水平排列的坑位 Chip 按钮，每个按钮显示坑位名称 + 当前生效配置数
- 同一时刻只能选中一个坑位（单选）
- 选中态：紫底白字；未选中：白底灰字带边框
- 选中 Collection 坑位后，下方展示「坑位全局设置」区（`button_text` 配置）和配置列表；选中 Banner 坑位后直接展示配置列表；右侧预览对应坑位高亮紫色框

### 8.4 配置列表视图

每条配置展示：

| 元素 | 说明 |
|------|------|
| 缩略图 | 44×44px，等比裁剪填满；无图时展示灰色占位 |
| 配置名称 | `config_name`，运营内部备注 |
| 模板标签 | `template_key` 对应中文名，灰色小字 |
| 状态 Tag | 「生效中」（绿色）/ 「已暂停」（灰色）|
| 上线开关 | Switch，弹出启用／停用确认框，确认提交成功后更新状态；取消不变更 |
| 复制按钮 | 打开预填内容的编辑页，见 §8.6 |
| 拖拽手柄（⠿）| 拖拽行至目标位置后释放，即完成排序 |
| 删除按钮 | 红色文字按钮；**仅「已暂停」状态显示**；点击弹出确认弹窗 |
| 编辑图标 | `EditOutlined`，点击进入编辑器（原位替换列表面板） |

> **删除约束**：删除前先停用并清空时间窗，提交成功后删除，规则见 §8.7。删除入口与确认方式见上表及 §12。

#### 列表底部操作区

- 「+ 新建配置」按钮
- 展示名额已满仍可新建或复制已暂停配置；上线或设置排期时执行 §8.7 的全时段容量校验。

### 8.5 配置编辑器（左侧原位替换）

点击「新建配置」或列表行编辑图标后，左侧面板切换为编辑器，右侧预览同步联动，见 §10.3。

#### 8.5.1 编辑器 Header

- 左上：DimBadge（`US · 官方站 · 📱 App`）
- 标题输入：`config_name` 内联编辑，无边框 Input
- 右侧：当前状态 Tag + 「取消」按钮 + 「保存」按钮（含 Check 图标）

#### 8.5.2 基本信息区（置灰只读）

四列网格：
1. 国家（Country）：disabled Select；Market 由系统根据国家推导，不作为运营配置项
2. 渠道（Channel）：disabled Select
3. 终端（Terminal）：只读样式的 span（不使用 Select，避免视觉混淆）
4. 坑位：ReadonlyField，展示坑位中文名

#### 8.5.3 模板选择区

- **`home_banner` 坑位**：不展示模板选卡，系统自动应用 `banner_image`，无需运营选择
- **`home_collection` 坑位**：本期只有 `collection_card_slide` 一种模板，不展示模板选卡，系统自动应用，无需运营选择

#### 8.5.4 素材与内容区

**素材图片（非 chip 模板必填）：**

- 已上传：展示缩略图（80px，圆角 6px），右上角 ✕ 清除按钮
- 未上传：虚线上传区（点击/拖拽），显示规格提示
  - Banner 坑位：`JPG/PNG/WebP · 880×644px（Mobile，2×）· 3840×1494px（PC，2×）· 建议 ≤ 500KB`
  - Collection 坑位：`JPG/PNG/WebP · 300×300px · 建议 ≤ 200KB`

Banner 按当前终端展示该国家全部已启用语言的图片块。每个语言块依次配置图片、标题、副标题、标题颜色、副标题颜色、按钮文案和图片 Alt；不在语言块中重复配置落地页。

- 颜色使用单选项：白色 `#ffffff`、黑色 `#070707`、灰色 `#5F5F5F`、其他；选择“其他”后显示颜色选择器。
- 文案按语言保存；字段有值时，前台使用配置值。标题、副标题和按钮文案均为空时，前台按纯图片模式展示。
- 图片未齐允许保存下线草稿。上线时校验当前终端全部已启用语言的 Banner 图片，缺图时保留编辑内容并阻止上线。
- 右侧预览使用语言页签；切换后展示该语言的图片与叠加文案，红点表示缺图，绿点表示已上传。

**跳转目标：**

- 目标类型与条件必填规则见 §6.1。以下关联选择和自动填充仅适用于目标类型为 Collection 的配置；Banner 选择自定义 URL 时填写目标 URL。

- Select 下拉，按当前 `country_code` 及其推导的 `market_id` 过滤可用合集
- 选中后显示「落地页」只读字段（页面名称，可点击预览跳转）
- 选中后若 `title`/`subtitle` 为空，自动填入合集对应值

**标题字段：**

- `maxLength: 30`，`showCount` 显示计数
- `placeholder`：若已关联合集则展示合集标题作为 placeholder 提示

**副标题字段：**

- Mobile：`maxLength: 30`；PC：`maxLength: 100`；`showCount` 显示计数
- `placeholder`：展示合集副标题（若有）

**图片 Alt 文案：**

- 素材图片上传后展示，包含「自动填充」按钮（见 §6.4）
- `maxLength: 125`，`showCount` 显示计数

#### 8.5.5 上线与时间设置

保留线上页面布局、上线开关位置与保存入口；独立新建／编辑表单复用已有开始／结束时间字段，行内编辑在开关之后补齐同组字段。时间区域标明所属市场基准时区，具体规则、状态联动与保存行为统一见 §8.7。旧原型不作为页面重构依据。

### 8.6 复制配置

首页 Banner、首页 Collection 的每条配置支持「复制」。打开预填内容的编辑器，保存成功后生成新的独立配置，取消则不生成记录。

- 列表页以当前线上页面为 UI 基线，仅在每条配置的现有操作区增加「复制」入口；不改动现有列表结构、状态展示、上线开关、编辑／删除入口、拖拽排序和样式。

- 复制到当前相同市场、渠道、终端和坑位，带入素材、已配置的各语言图片、Alt、标题、副标题、颜色、按钮文案及跳转目标（关联合集或自定义 URL）；仅复制该类型实际存在的字段。
- 副本配置名称默认「原配置名称 - 副本」，可编辑，保存采用运营修改后的名称；重复复制依次使用「原配置名称 - 副本 2」「原配置名称 - 副本 3」。原名称为空时使用「未命名配置 - 副本」。素材文件名保持不变。
- 新配置默认停用、显示已暂停，开始／结束时间清空；运营检查、修改后保存。新配置具有独立标识，修改它不改变原配置。
- 复制首页 Collection 配置时仍关联原 Collection，不复制 Collection 本身或其商品；落地页继续从该关联读取。
- 新配置追加至当前坑位配置列表末尾，可通过已有拖拽操作调整顺序；上线后沿用配置排序。
- 保存时重新校验素材与所选跳转目标是否有效；源配置被删除或不可访问时提示无法复制，保留已输入内容供运营处理，不生成不完整记录。

### 8.7 上下线时间窗

**时间与时区**

沿用现有开始／结束时间窗；独立新建／编辑表单复用已有两个时间字段，列表行内编辑在现有上线开关后补齐同一组字段。两种入口使用同一份配置，同条配置所有语言共用时间窗。

| 字段 | 规则 |
|---|---|
| 开始时间 | 选填；启用且留空时不限制开始时刻，填写未来时间时到该时刻才进入展示窗口 |
| 结束时间 | 选填；留空表示无计划结束时间，填写后到该时刻停止展示；同时填写时须晚于开始时间 |
| 时区 | 读取配置所属市场的「基准时区」；录入、回显及冲突提示使用同一时区，不跟随运营电脑时区 |

时间区域标明市场基准时区的标识，具体时间按目标日期显示对应 UTC 偏移。例如市场基准时区实际配置为 `America/New_York` 时才使用美东时间，不能仅凭国家名称推断时区。夏令时不存在的本地时间不可提交；重复时刻须明确对应 UTC 偏移，确保时间唯一。

未填写时，开始框显示「未设置」，结束框显示「持续展示」；旁边提示「仅启用且处于展示时间内时展示」。已有时间按实际值回显，包括已经过去的开始／结束时间。

新设置或修改的未来排期须晚于提交时刻；仅修改名称、素材等内容时保留已有时间，不因原时间已过去拦截保存。已保存时间表示确定的实际时刻；市场基准时区之后变化，仅改变显示换算，不能静默移动既有展示时刻。市场基准时区未配置或无效时，阻止提交时间变更并提示先完善市场配置，不默认回退到美东或电脑时区。

**启用状态与展示状态**

上线开关沿用启用／停用配置的含义。前台仅展示“配置已启用，且当前时刻已到开始时间、未到结束时间”的记录；空开始／结束分别表示无对应边界。开始时刻计入展示，结束时刻不计入。

列表仍保留「生效中／已暂停」两个当前展示状态：满足上述条件为生效中，其余为已暂停；已暂停包含未启用、尚未开始和已经结束。开关表示配置是否启用，不再等同于此刻是否展示；时间自然跨过边界不自动切换存储的启用状态。

| 场景 / 操作 | 结果 |
|---|---|
| 停用配置 | 不展示，时间到达也不会自动恢复 |
| 启用并保存未来开始时间 | 当前不展示；进入时间窗后展示本条，不替换其他配置 |
| 已启用且没有开始限制 | 无已过期结束限制时，提交成功后展示 |
| 到达结束时间 | 停止展示，保留配置、启用状态及开始／结束时间 |
| 提前上线 | 明确移除未来开始限制并保存，保留未来结束时间；有已过期结束限制时须一并调整为有效窗口 |
| 手动停用／取消排期 | 提交停用并清空开始／结束时间；再次使用须重新启用或配置时间窗 |
| 修改／清空未来结束时间 | 改变展示区间，保存前重新执行全时段容量校验 |
| 仅修改已结束配置的名称或素材 | 保留原窗口，继续不展示；再次展示须明确重新设置有效窗口并保存 |

进入或离开时间窗不清空字段，不产生执行任务或任务失败记录。清空未来开始时间会解除开始限制，不能视作暂停；需要取消展示时须同时停用。不能因普通编辑或系统清理历史结束时间使已结束配置重新展示。

列表开关沿用「启用首页配置／停用首页配置」确认框，提交成功后才生效；编辑器内容、开关与时间统一保存。取消或提交失败保留原配置与时间窗，编辑页保留输入。删除仍先停用并清空时间窗，避免剩余配置继续参与展示。

**校验与异常**

- 保存启用的时间窗前检查素材、所选跳转目标和当前终端 Banner 全部启用语言图片；失败保留输入并定位原因。
- 容量按资源类型＋终端＋市场／国家分组，不按渠道拆分；Banner 上限 14 条，Collection 上限 18 条。对已启用配置的整个有效展示时段做重叠校验，停用配置不占名额，无结束时间按持续展示计入。
- 同刻结束与开始不重叠；编辑时用新窗口替代该记录旧窗口。启用、修改窗口、清空结束限制均执行校验，并发提交不能共同造成超限。
- 超限阻止保存，按所属市场基准时区展示冲突时段、上限、预计同时展示数量与冲突配置，原记录不变。
- 编辑期间他人修改了该配置的启用状态或时间窗，阻止旧表单覆盖，提示「状态冲突，配置状态或排期已发生变化，请重新加载后编辑」，保留输入供查看。仅时间自然跨过开始／结束边界不视为记录修改；新填时间在提交前已过去时按时间校验处理。
- 不新增到点执行、到点复验、执行失败时间或失败原因展示。前台按现有时间窗读取规则展示／隐藏；保存失败、权限失效、记录不存在及刷新失败仍反馈实际错误，不把未成功提交的数据显示为已保存。

## 九、SEO 配置

### 9.1 入口与位置

SEO 配置为**首页级别**的页面元数据配置，独立于坑位资源位配置。入口：左侧配置面板顶部 Tab 行最右侧「🔍 SEO 配置」标签，点击后左侧面板切换为 SEO 配置表单；右侧预览面板仍展示当前首页预览（无特定坑位高亮）。

### 9.2 字段说明

| 字段 | 标签 | 类型 | 必填 | 说明 |
|------|------|------|------|------|
| `meta_title` | Meta Title | text | 否 | `≤ 60 字符`，`showCount`；留空自动使用：`Looply \| Authenticated Pre-Owned Luxury Bags, Watches & More` |
| `meta_desc` | Meta Description | textarea | 否 | 建议 120–160 字符，`maxLength: 160`，`showCount`；留空自动生成：`Shop authenticated pre-owned luxury bags, watches, jewelry and accessories from Chanel, Louis Vuitton, Rolex and more. Expertly authenticated and quality assured.` |
| `og_image` | OG 分享图 | image | 否 | 1200×630px，JPG/PNG，≤ 500KB；留空使用系统默认 Looply 品牌图 |

**完整 URL 展示**（只读）：`https://looply.com/`，固定显示，不可修改。

### 9.3 Google 搜索预览

SEO 配置区底部展示实时的 Google 搜索结果预览卡，包含：
- 标题（蓝色超链接样式，使用 `meta_title` 或默认值）
- URL（`https://looply.com`，绿色）
- 描述摘要（`meta_desc` 或默认值）

### 9.4 保存逻辑

- 点击「保存 SEO 配置」按钮后，字段生效并推送到前台 SEO 层（即时生效）
- 成功后按钮旁展示绿色「✓ 已保存」提示

### 9.5 终端与国家维度

**SEO 配置不区分终端**：首页（同一 URL）的 SEO 元数据 PC 和移动端共用同一套。配置规则：

- **PC 终端**：SEO Tab 可编辑，所有字段可填写和保存
- **App 终端**：SEO Tab 展示只读模式，所有字段展示当前值但不可修改；Tab 标签旁展示说明「SEO 配置在 PC 端管理」

> 原因：SEO meta 标签主要影响 PC 端搜索抓取，App 端无独立 URL，无需独立配置。两端共用一份数据，避免维护两套。

多国家扩展：如需支持多语言 Meta，可按 `country_code` 维度存储多套，本期沿用国家配置归属。

## 十七、下个版本修改需求

本节记录已合并进 v1.5 正文的增量需求；如与前文冲突，以前文正式规则为准。

### 17.1 Banner 多语言整图与可选叠加文案

**修改位置**：CMS > 首页配置 > 首页 Banner。

1. 每种语言图片下配置标题、副标题、标题颜色、副标题颜色、按钮文案和图片 Alt，不在语言块中配置落地页。
2. 文案按语言保存；有配置值时以前台配置为准。颜色提供白色、黑色、灰色和其他四个选项。
3. 编辑页只配置顶部所选终端的图片；全部已启用语言的上传位从上到下直接展示，每种语言上传一张当前终端图片。右侧通过横向语言页签预览，红／绿点表示缺图／已上传。
4. 所有语言共用目标类型、关联 Collection 或自定义 URL、排序和上线状态。
5. 标题、副标题和按钮文案均为空时为纯图片模式；任一字段有值时为图文模式。前台点击边界与埋点执行《首页 PRD v1.9》第 5、14 章。
6. 图片未齐可保存下线草稿；Banner 上线或保存上线状态时，只校验当前终端全部已启用语言图片，缺图则保留编辑内容并阻止上线，提示缺少的语言及终端。
7. 新增语言启用前，校验当前市场全部已上线 Banner 是否已补齐该语言的 PC 与 Mobile 图片；存在缺失时不允许启用该语言，并列出需要补图的 Banner。
8. 本需求上线后，现有 Banner 不沿用原图片直接上线。运营人员需按新规则，为全部已启用语言重新上传 PC 与 Mobile 成图；未补齐前不允许重新发布。

### 17.3 首页配置报错文案优化

#### 通用规则

1. 报错文案说明具体错误对象、原因和处理方式，不展示接口字段名、错误码或“响应缺少素材地址”等技术信息。
2. 字段校验错误显示在对应字段下；提交时自动定位到第一个错误字段。
3. 保存、上传或状态切换失败后保留当前已填写内容和已上传素材，不清空表单。
4. 网络或系统异常使用页面级提示，并提供重试操作。

#### 文案要求

| 触发场景 | 修改后文案 |
|---|---|
| Banner 当前语言未上传图片 | `请上传{语言}的{终端} Banner 图片` |
| Banner 上线时存在多个语言缺图 | `请先上传以下语言的{终端} Banner 图片：{语言列表}` |
| Collection 未上传素材图片 | `请上传 Collection 素材图片` |
