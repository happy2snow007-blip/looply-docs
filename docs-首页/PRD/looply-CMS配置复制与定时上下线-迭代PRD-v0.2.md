# CMS 配置复制与定时上下线迭代 PRD

版本：v0.2｜更新：2026-11-25

## 1. 范围与页面改造边界

| 对象 | 本次新增 | 编辑页处理 |
|---|---|---|
| 首页 Banner、首页 Collection 配置 | 列表增加「复制」；支持定时上下线 | 独立表单复用开始／结束时间；行内编辑补齐两个时间字段 |
| 营销页面中的 Landing 模板 | 列表增加「复制」 | 复用现有新建编辑页，预填配置 |

仅 Landing 模板增加页面复制，图文专题保持原操作。首页 Collection 指首页展示配置，复制不会创建 Collection 本体。

以当前线上列表和编辑页为页面基线，保留现有布局、字段、组件、上线开关位置和保存行为。本次只增加上表入口及时间字段；原型仅表达业务逻辑，不作为重构线上页面的依据。

## 2. 首页 Banner / 首页 Collection：复制与定时上下线

### 2.1 复制首页配置

- 两个坑位列表均增加「复制」，打开预填内容的配置编辑页；保存生成独立记录，取消不新增。
- 复制当前市场、渠道、终端和坑位内该类型实际存在的素材、各语言图片、Alt、标题、副标题、颜色、按钮文案及跳转目标（关联合集或自定义 URL）；首页 Collection 继续关联原 Collection，不复制其商品。新记录追加到列表末尾，可拖拽调整顺序。
- 副本配置名称默认「原配置名称 - 副本」，可编辑，保存采用运营修改后的名称；重复复制依次使用「原配置名称 - 副本 2」「原配置名称 - 副本 3」。原名称为空时使用「未命名配置 - 副本」。素材文件名保持不变。
- 副本默认停用、显示已暂停，开始／结束时间清空；修改副本不影响原配置。
- 通过列表现有「编辑」入口进入配置页设置排期，与内容一起保存。
- 保存副本时重新校验素材与所选跳转目标；源配置被删除或不可访问时提示无法复制，保留输入，不生成不完整记录。

### 2.2 时间与时区

沿用现有开始／结束时间窗；独立新建／编辑表单复用已有两个时间字段，列表行内编辑在现有上线开关后补齐同一组字段。两种入口使用同一份配置，同条配置所有语言共用时间窗。

| 字段 | 规则 |
|---|---|
| 开始时间 | 选填；启用且留空时不限制开始时刻，填写未来时间时到该时刻才进入展示窗口 |
| 结束时间 | 选填；留空表示无计划结束时间，填写后到该时刻停止展示；同时填写时须晚于开始时间 |
| 时区 | 读取配置所属市场的「基准时区」；录入、回显及冲突提示使用同一时区，不跟随运营电脑时区 |

时间区域标明市场基准时区的标识，具体时间按目标日期显示对应 UTC 偏移。例如市场基准时区实际配置为 `America/New_York` 时才使用美东时间，不能仅凭国家名称推断时区。夏令时不存在的本地时间不可提交；重复时刻须明确对应 UTC 偏移，确保时间唯一。

未填写时，开始框显示「未设置」，结束框显示「持续展示」；旁边提示「仅启用且处于展示时间内时展示」。已有时间按实际值回显，包括已经过去的开始／结束时间。

新设置或修改的未来排期须晚于提交时刻；仅修改名称、素材等内容时保留已有时间，不因原时间已过去拦截保存。已保存时间表示确定的实际时刻；市场基准时区之后变化，仅改变显示换算，不能静默移动既有展示时刻。市场基准时区未配置或无效时，阻止提交时间变更并提示先完善市场配置，不默认回退到美东或电脑时区。

### 2.3 启用状态与展示状态

上线开关沿用启用／停用配置的含义。前台仅展示“配置已启用，且当前时刻已到开始时间、未到结束时间”的记录；空开始／结束分别表示无对应边界。开始时刻计入展示，结束时刻不计入。

列表仍保留「生效中／已暂停」两个当前展示状态：满足上述条件为生效中，其余为已暂停；已暂停包含未启用、尚未开始和已经结束。开关表示配置是否启用，不再等同于此刻是否展示；时间自然跨过边界不自动切换存储的启用状态。

| 场景 / 操作 | 结果 |
|---|---|
| 停用配置 | 不展示，时间到达也不会自动恢复 |
| 启用并保存未来开始时间 | 当前不展示；进入时间窗后展示本条，不替换其他配置 |
| 已启用且没有开始限制 | 无已过期结束限制时，提交成功后展示 |
| 到达结束时间 | 停止展示，保留配置、启用状态及开始／结束时间 |
| 提前上线 | 明确移除未来开始限制并保存，保留未来结束时间；有已过期结束限制时须一并调整为有效窗口 |
| 手动停用／取消排期 | 提交停用并清空开始／结束时间；再次使用须重新启用或配置时间窗 |
| 修改／清空未来结束时间 | 改变展示区间，保存前重新执行全时段容量校验 |
| 仅修改已结束配置的名称或素材 | 保留原窗口，继续不展示；再次展示须明确重新设置有效窗口并保存 |

进入或离开时间窗不清空字段，不产生执行任务或任务失败记录。清空未来开始时间会解除开始限制，不能视作暂停；需要取消展示时须同时停用。不能因普通编辑或系统清理历史结束时间使已结束配置重新展示。

列表开关沿用「启用首页配置／停用首页配置」确认框，提交成功后才生效；编辑器内容、开关与时间统一保存。取消或提交失败保留原配置与时间窗，编辑页保留输入。删除仍先停用并清空时间窗，避免剩余配置继续参与展示。

### 2.4 校验与异常

- 保存启用的时间窗前检查素材、所选跳转目标和当前终端 Banner 全部启用语言图片；失败保留输入并定位原因。
- 容量按资源类型＋终端＋市场／国家分组，不按渠道拆分；Banner 上限 14 条，Collection 上限 18 条。对已启用配置的整个有效展示时段做重叠校验，停用配置不占名额，无结束时间按持续展示计入。
- 同刻结束与开始不重叠；编辑时用新窗口替代该记录旧窗口。启用、修改窗口、清空结束限制均执行校验，并发提交不能共同造成超限。
- 超限阻止保存，按所属市场基准时区展示冲突时段、上限、预计同时展示数量与冲突配置，原记录不变。
- 编辑期间他人修改了该配置的启用状态或时间窗，阻止旧表单覆盖，提示「状态冲突，配置状态或排期已发生变化，请重新加载后编辑」，保留输入供查看。仅时间自然跨过开始／结束边界不视为记录修改；新填时间在提交前已过去时按时间校验处理。
- 不新增到点执行、到点复验、执行失败时间或失败原因展示。前台按现有时间窗读取规则展示／隐藏；保存失败、权限失效、记录不存在及刷新失败仍反馈实际错误，不把未成功提交的数据显示为已保存。

## 3. Landing 页面复制

- 点击 Landing 记录的「复制」打开预填的新建编辑页，不创建记录、不生效。取消或返回不产生副本。
- 副本带入源页面当前保存生效的所属市场、模板类型、各语言及 PC/H5 图片、共用图片跳转链接、PC/H5 各自的品牌介绍标题、副标题、跳转文案及链接、保障展示选项。包含已保存但当前隐藏的配置，以及该页面已有的各语言文案；内容跳转链接按原值带入，保留查询参数和锚点。
- 「页面名称」和「关联 Collection」默认为空，由运营重新填写和选择。名称最多 100 个字符，支持英文字母、数字、空格和短横线，至少含一个英文字母。地址后缀不带入，系统去除新名称首尾空格、字母转小写、连续空格或短横线合并为一个短横线并去除首尾短横线，生成只读 `/landing/{后缀}`；后缀须有效且全局唯一，首次保存后固定。
- 源页面关联的投放短链及其 UTM 配置记录、页面地址、生效历史、页面标识不继承。副本首次保存成功后生成新标识、地址和第一条生效历史；需要投放链接时，在新页面单独创建。
- 副本配置及页面文案、译文归属新页面，后续编辑任一页面不影响另一页面；Collection 内容继续由重新选择的 Collection 提供。
- 保存时沿用当前 Landing 新建校验：名称必填、地址有效且唯一、Collection 同市场且生效；图片可整体留空，任一端或语言有图则须补齐 PC/H5 与全部启用语言；跳转链接接受 http/https 绝对地址或单斜杠开头的站内路径，去除首尾空格；有图时校验非空图片链接。各端品牌标题非空时，跳转文案与链接须同时为空或同时有效，跳转文案最多 60 字符；无图／空标题的隐藏跳转保留配置并免于对应校验。校验通过后点击「保存」创建副本并立即生效；失败时保留填写内容，不创建不完整记录。同一次保存重复提交或重试只生成一条副本及其首次生效历史。

## 4. 验收要点

- 首页两个坑位新增入口和时间字段一致；副本独立、命名递增、素材文件名不变、默认暂停且无排期；原 Collection 关联保留。
- 手动开关按列表确认／编辑保存成功生效；取消与失败不改变原状态和排期；时间跨过边界不清空窗口；普通内容修改不改变原展示时刻、不使过期配置恢复。
- 覆盖各市场基准时区、适用时区的夏令时、跨设备换算、同刻衔接、14／18 全时段容量、停用、记录冲突与过期编辑；前台按启用状态和时间窗展示。
- 仅 Landing 有复制入口；复制全部端、语言与隐藏内容，保留共用图片链接及 PC/H5 各自品牌字段；名称、地址及 Collection 清空，预览不残留原 Collection 内容。
- Landing 取消无记录；保存后产生独立地址、首条历史且无原投放短链；配置与译文修改不影响原页；重复提交只创建一条，校验失败保留输入。
