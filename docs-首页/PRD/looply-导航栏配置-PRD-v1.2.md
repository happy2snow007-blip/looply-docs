## 1. 背景与目标

Looply Shop 页顶部导航是用户进入品类的主入口，直接影响发现路径与转化。当前 App 与 PC 导航配置糅合在同一后台界面，配置逻辑相互干扰，且 PC 端导航结构（L1→L2→L3 三级 Mega Menu）远比 App 端复杂，需要独立的配置工具。

**目标**：为运营/商品同学提供一套专门面向 PC Web 端的导航栏配置工具，支持：
- 一级导航的增删改排序、启用/停用
- 二级导航的配置
- 三级导航的配置（Mega Menu）
- 实时预览导航效果

---

## 2. 术语

| 术语 | 说明 |
|------|------|
| L1 导航 | 顶部导航栏中的一级入口（如 Bags、Jewelry） |
| L2 导航 | 悬停 L1 后展开的二级菜单项（如 By Type、By Brand） |
| L3 导航 | 悬停 L2 后展开的三级菜单项（如 Shoulder Bags），仅存在于三级结构中 |
| 直跳 | L1 点击后直接跳转目标 URL，无下级菜单 |
| 两级 | L1 展开 L2，L2 全部为直跳叶子节点，无 L3 |
| 三级（Mega Menu） | L1 展开 L2，L2 全部为列头，每个 L2 列头下挂 L3 |
| 列头 | 三级结构中的 L2，作为 Mega Menu 的分组标题，自身有跳转链接，同时下挂 L3 |
| 维度 | Market + Channel 的组合，决定配置作用范围 |

## 4. 功能范围（MVP v1.0）

### 4.1 全局维度筛选

- **市场（Market）**：当前仅 US，后续扩展
- **渠道（Channel）**：当前仅官方站
- **终端**：固定为 Web，本模块专属，不提供切换

维度变化后，所有数据刷新为对应维度配置。

---

### 4.2 一级导航列表

**展示字段**：

| 列名 | 说明 |
|------|------|
| 排序 | 拖拽手柄（⠿），拖拽行调整当前维度内顺序 |
| 名称 | 两级/三级类型点击可钻取进入二级导航配置；直跳类型不可钻取 |
| 层级 | Tag 显示：直跳 / 两级 / 三级 |
| 状态 | Switch：启用 / 停用 |
| 操作 | 编辑、删除（启用状态下不可删除） |

**交互**：
- 悬停表格行 → PC 预览更新高亮对应导航项
- 点击名称（两级/三级）→ 钻取到二级导航配置页

**空态**：  
暂无导航时显示说明文案，无 Toolbar，仅保留「新增一级导航」按钮。

---

### 4.3 新增/编辑一级导航（Drawer 480px）

**表单字段**：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 名称（Name） | Input | ✅ | 显示在顶导的文本，英文为主 |
| 导航层级 | Radio | ✅ | 直跳 / 两级 / 三级（Mega）；**创建后不可修改** |
| 目标类型 | Select | ✅ | Collection / 自定义链接 |
| 关联合集 | Select（搜索） | 目标类型=Collection 时显示 | 选择后自动填充目标 URL，URL 只读 |
| 目标 URL | Input | 目标类型=自定义链接时必填 | 手动输入；选了 Collection 时自动填充且不可修改 |
| 状态 | Switch | ✅ | 启用 / 停用 |

**校验**：
- 名称不能为空
- 同维度下名称不能重复（不区分大小写）
- 目标类型必选
- 目标类型=Collection 时关联合集必选
- 目标类型=自定义链接时目标 URL 必填

**导航层级说明**：
- 直跳：点击 L1 直接跳转，无下级菜单
- 两级：悬停展开下拉列表，L2 全为直跳叶子
- 三级（Mega）：悬停展开 L2 列头列表，每个 L2 列头下挂 L3

> ⚠️ **层级一旦创建不可修改**，请确认后再保存。

---

### 4.4 二级导航配置（钻取页）

钻取入口：点击 L1 名称（两级/三级类型）。

面包屑：`导航配置 / {L1 名称}` + DimBadge

**二级导航表字段**：

| 列名 | 说明 |
|------|------|
| 排序 | 拖拽手柄（⠿），拖拽调整同一 L1 下顺序 |
| 名称 | 三级结构：显示可点击链接，点击钻取进入 L3 配置；两级结构：显示普通文本 |
| 状态 | Switch |
| 操作 | 编辑、删除（启用状态下不可删除） |

删除三级结构的 L2 时，同步删除其下所有 L3。

右侧 sticky PCPreview，实时反映 L2 配置变更。

---

### 4.5 新增/编辑二级导航（Drawer 500px）

**表单字段**：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 所属导航 | Select | ✅ | 所属的 L1 |
| 名称（Name） | Input | ✅ | L2 菜单项文本 |
| 目标类型 | Select | ✅ | Collection / 自定义链接 |
| 关联合集 | Select（搜索） | 目标类型=Collection 时显示 | 选择后自动填充 URL，URL 只读 |
| 目标 URL | Input | 目标类型=自定义链接时必填 | 手动输入 |
| 状态 | Switch | ✅ | - |

> 三级结构的 L2（列头）配置自身跳转链接，同时可在钻取页下挂 L3。

---

### 4.6 三级导航配置（钻取页）

钻取入口：点击三级结构下的 L2 名称。

面包屑：`导航配置 / {L1 名称} / {L2 名称}` + DimBadge

三级导航（L3）均为叶子节点（直跳），不再有下级。

**三级导航表字段**：

| 列名 | 说明 |
|------|------|
| 排序 | 拖拽手柄（⠿） |
| 三级导航名称 | 文本 + 目标 URL |
| 状态 | Switch |
| 操作 | 编辑、删除（启用状态下不可删除） |

右侧 sticky PCPreview，点击对应 L1 可查看 Mega Menu 效果。

---

### 4.7 PC 预览面板（Sticky Right）

- 始终固定在右侧（`position: sticky, top: 24px`），不随配置内容滚动
- 显示 Looply PC 导航栏仿真（560px 宽）
- 顶栏展示所有 enabled L1 导航项
- 点击/悬停 L1 → 展开对应 Dropdown / Mega Menu
- 配置变更实时更新预览
- 悬停配置表格行 → 预览高亮对应 L1（一级列表页）

| created_at | datetime | - |
| updated_at | datetime | - |

### pc_nav_menu_items（二/三级导航）

|------|------|------|

| target_type | enum | collection / custom |
| collection_id | string | target_type=collection 时关联 |

| updated_at | datetime | - |

## 6. 交互规则

### 6.1 排序

所有层级（L1/L2/L3）均使用**拖拽排序**：行左侧显示拖拽手柄（⠿），拖动行至目标位置后释放即完成排序。

- L1：当前维度内排序
- L2：同一 nav_id 下排序
- L3：同一 parent_id 下排序

排序结果即为前台展示顺序，后台无延迟。

### 6.2 启用/停用

- L1 停用 → 前台不展示该导航项及其所有子项
- L2 停用 → 前台该 L2 不展示，其下 L3 不影响存储但不展示
- 停用不触发删除，随时可重新启用

### 6.3 删除

- **启用状态的导航项不可删除**，操作列删除按钮置灰，hover 显示「请先停用再删除」
- 停用后可删除，删除前弹 Popconfirm 二次确认（含级联说明）
- 删除 L1 → 级联删除该 L1 下所有 L2、L3
- 删除三级结构的 L2 → 级联删除其下所有 L3

### 6.4 导航结构规则

三种导航结构在 L1 创建时确定，创建后不可修改，三种结构严格互斥：

| 结构 | L1 | L2 | L3 |
|------|----|----|-----|
| 直跳 | 有跳转，无下级 | — | — |
| 两级 | 有跳转 | 全部直跳（is_leaf=true），必须配置跳转链接 | — |
| 三级（Mega Menu） | 有跳转 | 全部为列头（is_leaf=false），必须配置跳转链接 | 全部直跳，必须配置跳转链接 |

PCPreview 中 Mega Menu 展示样式：L2 列头（紫色加粗）+ 其下 L3 竖向列表。

## 7. 边界情况

| 场景 | 处理 |
|------|------|
| L1 levels=2/3 但无任何 L2 | 前台不展开菜单，仅点击跳转（等同直跳效果），后台预览显示空 |
| 三级结构 L2 列头无 L3 | 前台列头显示但无子项，建议停用或补充 L3 |
| 同名 L1 | 新增/编辑时校验同维度同名，不允许保存 |
| enabled L1 = 0 | 预览面板提示「暂无启用导航」 |
| 尝试删除启用中的导航项 | 删除按钮禁用，提示「请先停用再删除」 |
