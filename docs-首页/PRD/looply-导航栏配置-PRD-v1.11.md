## 1. 背景与目标

Looply Shop 页顶部导航是用户进入品类的主入口，直接影响发现路径与转化。当前 App 与 PC 导航配置糅合在同一后台界面，配置逻辑相互干扰，且 PC 端导航结构（L1→L2→L3 三级 Mega Menu）远比 App 端复杂，需要独立的配置工具。

**目标**：为运营/商品同学提供一套专门面向 PC Web 端的导航栏配置工具，支持：
- 一级导航的增删改排序、启用/停用
- 二级导航的配置
- 三级导航的配置（Mega Menu）
- 导航展开面板推荐位配置
- 实时预览导航效果

---

## 2. 术语

| 术语 | 说明 |
|------|------|
| L1 导航 | 顶部导航栏中的一级入口（如 Bags、Jewelry） |
| L2 导航 | 悬停 L1 后展开的二级菜单项（如 By Type、By Brand） |
| L3 导航 | 悬停 L2 后展开的三级菜单项（如 Shoulder Bags），仅存在于三级结构中 |
| 直跳 | L1 点击后直接跳转目标 URL，无下级菜单 |
| 两级 | L1 展开 L2，L2 全部为直跳叶子节点，无 L3 |
| 三级（Mega Menu） | L1 展开 L2，L2 全部为列头，每个 L2 列头下挂 L3 |
| 列头 | 三级结构中的 L2，作为 Mega Menu 的分组标题，自身有跳转链接，同时下挂 L3 |
| 维度 | Market + Channel 的组合，决定配置作用范围 |

## 4. 功能范围（MVP v1.0）

### 4.1 顶层维度筛选（Dimension Bar）

维度筛选是**页面级组件**，固定显示在导航配置页内容区顶部，不属于全局 Header，不对其他模块生效。每个需要维度感知的配置页面各自携带一套，枚举值可按模块独立定义。

| 筛选项 | 类型 | 说明 |
|--------|------|------|
| 市场（Market） | Select（可切换） | 当前仅 US，后续扩展 |
| 渠道（Channel） | Select（可切换） | 当前仅 official |
| 终端（Terminal） | 只读文本 | 固定为 🖥 PC，本模块专属 |

**行为规则**：
- 维度切换后，页面内所有数据（L1 列表、L2/L3 配置）立即刷新为对应维度的配置，当前钻取层级重置回 L1 列表
- 钻取进入 L2/L3 子页时，Dimension Bar 不再显示，改为面包屑旁的只读 DimBadge（格式：`US · official`），防止在子页意外切换维度导致数据错乱
- 不同维度的配置数据完全独立，互不影响

### 4.2 一级导航列表

**展示字段**：

| 列名 | 说明 |
|------|------|
| 排序 | 拖拽手柄（⠿），拖拽行调整当前维度内顺序 |
| 名称 | 两级/三级类型点击可钻取进入二级导航配置；直跳类型不可钻取 |
| 层级 | Tag 显示：直跳 / 两级 / 三级 |
| 状态 | Switch：启用 / 停用 |
| 操作 | 编辑、删除（启用状态下不可删除） |

**交互**：
- 悬停表格行 → PC 预览更新高亮对应导航项
- 点击名称（两级/三级）→ 钻取到二级导航配置页

**空态**：  
暂无导航时显示说明文案，无 Toolbar，仅保留「新增一级导航」按钮。

### 4.3 新增/编辑一级导航（Drawer）

**表单字段**：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 名称（Name） | Input | ✅ | 显示在顶导的文本，英文为主 |
| 导航层级 | Radio | ✅ | 直跳 / 两级 / 三级（Mega）；**创建后不可修改** |
| 目标类型 | Select | ✅ | Collection / 自定义链接 |
| 关联合集 | Select（搜索） | 目标类型=Collection 时显示 | 选择后自动填充目标 URL，URL 只读 |
| 目标 URL | Input | 目标类型=自定义链接时必填 | 手动输入；选了 Collection 时自动填充且不可修改 |
| 状态 | Switch | ✅ | 启用 / 停用 |

**校验**：
- 名称不能为空
- 同维度下名称不能重复（不区分大小写）
- 目标类型必选
- 目标类型=Collection 时关联合集必选
- 目标类型=自定义链接时目标 URL 必填

**导航层级说明**：
- 直跳：点击 L1 直接跳转，无下级菜单
- 两级：悬停展开下拉列表，L2 全为直跳叶子
- 三级（Mega）：悬停展开 L2 列头列表，每个 L2 列头下挂 L3

> ⚠️ **层级一旦创建不可修改**，请确认后再保存。

### 4.7 PC 预览面板（Sticky Right）

- 始终固定在右侧，不随配置内容滚动

### 4.8 导航展开面板推荐位

推荐位配置放在对应 L1 的二级导航钻取页；三级结构同样从 L2 列表所在页面配置。系统根据当前启用导航内容实际占用的列数，自动决定推荐位数量，运营不能手动修改数量。

| 导航列数 | 推荐位数量 | 后台处理 |
|------|------|------|
| 0 列 | 0 | 不生成推荐位配置区 |
| 1 列 | 3 | 生成 3 个必填推荐位 |
| 2 列 | 2 | 生成 2 个必填推荐位 |
| 3–4 列 | 1 | 生成 1 个必填推荐位 |
| 5 列及以上 | 0 | 不生成推荐位配置区 |

每个推荐位包含：

| 字段 | 必填 | 说明 |
|------|------|------|
| 图片 | 是 | 单张图片；前台展示尺寸 340 × 210 px；上传区提示“建议上传 2 倍及以上图片，推荐尺寸不低于 680 × 420 px（展示比例 34:21）” |
| 英语标题文案 | 是 | 英语源文案；其他语言由多语言系统自动翻译 |
| 英语说明文案 | 是 | 英语源文案；其他语言由多语言系统自动翻译 |
| 目标类型 | 是 | Collection / 自定义 URL |
| 关联合集 | 条件必填 | 目标类型为 Collection 时必填 |
| 自定义 URL | 条件必填 | 目标类型为自定义 URL 时必填 |

展示与交互规则：

1. 推荐位按后台顺序从左到右展示；整个推荐位均可点击。
   后台配置卡片按推荐位 1、2、3 的顺序单列向下排列，右侧 PCPreview 按前台实际布局展示。
2. 当前应生成的推荐位中，任一图片、英语标题、英语说明、目标类型或该类型对应的目标配置缺失时，不允许保存推荐位配置。
3. 后台编辑时，上传、替换或删除图片，以及修改英语文案、目标类型或目标配置，均在保存前实时同步到右侧 PCPreview。
4. 导航列数变化后，后台立即按上表刷新应配置的推荐位数量；前台只展示当前列数对应数量的已完成推荐位。
5. 推荐图只配置一张图片、一份英语标题和一份英语说明。图片和英语源文案在各语言间共用，其他语言由多语言系统自动提供翻译，不在推荐位中逐语言维护。
6. “2 倍及以上”仅为前端提示，不作为保存校验条件；系统不限制图片必须为固定倍数或固定像素尺寸。

埋点要求：

1. 每个一级导航和推荐位均保存不可因改名、换图或排序而变化的稳定 ID，分别作为 `navigation_id` 和 `recommendation_id`。
2. 一方平台曝光使用 `ui_impression`，点击使用 `ui_interaction`；GA4 分别使用 `view_promotion` 和 `select_promotion`。事件均携带 `navigation_id`、`recommendation_id` 和 `position_id`，其中 `position_id` 为当前展开面板内从左到右的 `1–3`。
3. 目标类型为 Collection 时携带 Collection 稳定 ID 作为 `target_id`；目标类型为自定义 URL 时不把 URL 原文作为稳定业务 ID，按统一跳转埋点规则记录目标类型和脱敏后的目标标识。
4. 展开面板实际打开且推荐位至少 50% 可见并持续 1 秒时记录曝光；同一次面板展开内，同一个 `recommendation_id` 只记录一次。关闭后重新展开可重新记录。
5. 点击图片、标题或说明文案均视为点击整个推荐位，只记录一次点击。
6. 推荐位未展示、配置不完整或图片加载失败导致卡片未形成有效展示时，不记录曝光。

## 6. 交互规则

### 6.1 排序

所有层级（L1/L2/L3）均使用**拖拽排序**：行左侧显示拖拽手柄（⠿），拖动行至目标位置后释放即完成排序。

- L1：当前维度内排序
- L2：同一 nav_id 下排序
- L3：同一 parent_id 下排序

排序结果即为前台展示顺序，后台无延迟。

### 6.2 启用/停用

- L1 停用 → 前台不展示该导航项及其所有子项
- L2 停用 → 前台该 L2 不展示，其下 L3 不影响存储但不展示
- 停用不触发删除，随时可重新启用

### 6.3 删除

- **启用状态的导航项不可删除**，操作列删除按钮置灰，hover 显示「请先停用再删除」
- 停用后可删除，删除前弹 Popconfirm 二次确认（含级联说明）
- 删除 L1 → 级联删除该 L1 下所有 L2、L3
- 删除三级结构的 L2 → 级联删除其下所有 L3

### 6.4 导航结构规则

三种导航结构在 L1 创建时确定，创建后不可修改，三种结构严格互斥：

| 结构 | L1 | L2 | L3 |
|------|----|----|-----|
| 直跳 | 有跳转，无下级 | — | — |
| 两级 | 有跳转 | 全部直跳（is_leaf=true），必须配置跳转链接 | — |
| 三级（Mega Menu） | 有跳转 | 全部为列头（is_leaf=false），必须配置跳转链接 | 全部直跳，必须配置跳转链接 |

PCPreview 中 Mega Menu 展示样式：L2 列头（紫色加粗）+ 其下 L3 竖向列表；推荐位按第 4.8 节规则占用剩余区域。

## 7. 边界情况

| 场景 | 处理 |
|------|------|
| L1 levels=2/3 但无任何 L2 | 前台不展开菜单，仅点击跳转（等同直跳效果），后台预览显示空 |
| 三级结构 L2 列头无 L3 | 前台列头显示但无子项，建议停用或补充 L3 |
| 同名 L1 | 新增/编辑时校验同维度同名，不允许保存 |
| enabled L1 = 0 | 预览面板提示「暂无启用导航」 |
| 尝试删除启用中的导航项 | 删除按钮禁用，提示「请先停用再删除」 |
| 导航列数为 0 | 不生成推荐位配置区，前台不展示推荐位 |
| 导航列数为 5 列及以上 | 不生成推荐位配置区，前台不展示推荐位 |
| 应展示的推荐位配置不完整 | 不允许保存，并在缺失字段下展示对应校验提示 |

### 4.9 Shop 导航卡片样式与图片校验（v1.5 新增）

Shop 一级导航配置中，运营需选择卡片样式：`方形图卡`或`横向大图`。二级/三级导航的图片上传和保存校验必须使用所属一级导航的卡片样式：

| 卡片样式 | 图片要求 | 校验规则 |
|---|---|---|
| 方形图卡 | 1:1 图片 | 图片宽高比必须为 1:1；不符合时阻止上传或替换，并在上传控件下提示“图片需为 1:1 方形比例” |
| 横向大图 | 横版图片 | 图片宽高比必须为横版比例（宽大于高）；不符合时阻止上传或替换，并在上传控件下提示“图片需为横版比例” |

1. 图片校验以运营已选择的卡片样式为准，不能只根据文件扩展名判断。
2. 校验适用于新增、替换和编辑图片；校验失败时不写入该语言图片字段，也不改变已保存图片。
3. 二级/三级导航按当前国家启用的语言分别上传图片；每个语言字段分别执行同一比例校验。
4. 任一语言图片校验失败时，不允许保存本次图片变更；页面保留已填写内容并定位到失败的语言上传项。
5. 推荐像素尺寸仅作为上传区提示，实际拦截条件为图片宽高比；具体比例以卡片样式规则为准。

### 4.10 Shop 导航层级与二级导航字段规则（v1.6 新增）

Shop 创建一级导航时选择导航层级数，二级导航配置项随层级模式变化：

- **两级导航**：二级导航名称直接制作在多语言图片中，新增二级导航不展示、不要求填写 Name；需要按当前国家支持的语言分别上传图片，并配置目标类型及对应的 Collection 或自定义 URL。
- **三级导航**：二级导航仅作为文字分组标题，新增二级导航只配置 Name；不上传图片，也不配置跳转目标。图片、目标类型及对应链接在新增三级导航时配置。
- 新增二级导航抽屉需明确展示当前一级导航、导航层级数和当前国家上下文；字段变化应随层级选择即时生效。
- 两级模式下图片和目标字段为必填；三级模式下 Name 为必填，图片和目标字段不出现在二级导航表单中。

### 4.11 三级导航进入与管理（v1.7 新增）

当一级导航创建时选择「三级」：

- 二级导航列表中的每个二级导航名称均可点击，进入该二级导航下的三级导航管理页。
- 三级导航管理页展示当前二级导航、国家/渠道/终端上下文，以及已有三级导航列表。
- 页面支持新增、编辑、启停三级导航；新增三级导航需配置 Name、按当前国家支持语言上传图片、目标类型及对应的 Collection 或自定义 URL。
- 返回操作回到当前一级导航的二级导航列表，保留原有筛选和配置上下文。
- 两级导航模式下，二级导航名称不作为三级导航入口，继续按两级模式直接管理图片和跳转目标。

### 4.12 三级导航名称由图片承载（v1.8 新增）

三级导航与两级导航保持一致：名称直接制作在各语言图片中，三级导航配置表单不再展示或要求填写 Name。三级导航仍需按当前国家支持的语言分别上传图片，并配置目标类型及对应的 Collection 或自定义 URL。未上传完整必需语言图片时，不允许保存。

### 4.13 配置内容拖拽排序（v1.9 新增）

首页 Banner、首页 Collection、Shop 一级/二级/三级导航、PC 导航推荐位及 Footer 法律文件/FAQ 配置列表均支持拖拽调整顺序。列表每行使用拖拽手柄（⠿）表示可拖拽区域；拖拽完成后保存当前排序，并按新顺序应用于对应 C 端展示或配置优先级。拖拽过程中仅允许在同一配置列表内调整，不跨国家、渠道、终端或不同配置类型移动。
