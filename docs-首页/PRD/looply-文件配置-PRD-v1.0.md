# Looply 文件配置 PRD v1.0

## 一、范围与职责

CMS「文件配置」按国家维护法律文件、FAQ 和社媒账号，供业务模块读取当前已发布生效内容。

本次后台交付覆盖内容录入、解析校验、预览、保存发布、版本管理和第五章的生效内容输出。PC Footer 的国家与语言识别、入口名称、跳转、可见性及回退由其他已有前端需求负责；法律文件页面、FAQ 页面及首页各自负责内容消费。具体接口由技术方案定义。

页面顶部仅选择国家，国家来自 C2 业务国家管理，可提前维护未启用国家；支持语言使用市场配置。法律文件、FAQ、社媒账号分别维护；切换国家或页签时，有未保存修改则提示继续编辑或放弃。放弃后恢复已保存内容。配置不按渠道或终端拆分。

## 二、法律文件

### 2.1 列表与上传

开发预置文件类型：Terms of Service、Privacy Policy、Seller Agreement、Returns & Refunds、Accessibility Statement。运营维护内容，文件类型名称只读。

列表按文件类型展示名称、各语言版本、更新时间，提供「下载线上版本」「历史版本」「上传文件」。下载可选择当前国家该文件的语言；没有生效版本时不可下载。

点击上传文件，展示只读国家和文件名称，并按当前市场支持语言生成独立上传区；每区标明语言、所选文件和处理结果。普通新版本发布须上传本次全部语言文件，不能用旧线上文件抵作本次上传；历史回滚的文件带入规则见 2.3 节。

仅支持上传 `.html` 正文片段文件，保留标题、段落、列表、引用、表格、强调和链接。字体、颜色及页面布局由消费页面统一控制；含完整网页外壳（DOCTYPE、html、head 或 body）的文件拒绝处理，提示改为正文片段。脚本、自定义样式和不安全内容按第五章清理。法律正文及链接文字由法务提供，不经过自动翻译，正文不可在线编辑。

### 2.2 自动预览与发布

上传后自动解析并展示对应语言的正文预览，正文结构按 2.1 节保留。系统校验文件格式、正文非空、链接和锚点；自动校验不等于法务内容审核。运营查看预览后点击「发布新版本」。

| 状态 | 触发条件 | 可执行操作 |
|---|---|---|
| 未上传 | 当前语言未选择文件或已移除 | 上传 |
| 解析中 | 文件正在处理 | 等待 |
| 校验失败 | 解析失败或内容校验未通过 | 查看错误、重新上传 |
| 可预览 | 解析校验通过，正文预览已展示 | 查看、替换或移除文件 |

全部支持语言均通过校验后才可发布；任一缺失或失败则阻止发布。替换或移除文件立即取消该文件之前的通过状态。全部语言作为同一次发布生效，避免部分语言更新成功、部分失败。

版本号由系统生成；内容对应同一发布批次，各语言正文可以不同。保留各语言文件、发布时间、操作人和历史记录。发布失败时保留本次上传内容，线上继续使用之前的生效版本。

打开上传区时记录来源版本；发布时若当前版本或市场支持语言发生变化，阻止发布，提示重新核对后上传。

### 2.3 历史版本

历史记录按发布批次展示版本号、发布时间、操作人、当前标记及各语言文件；当前版和历史版均可按语言下载。

历史发布批次提供「回滚」，当前批次不提供。回滚范围为当前国家、同一文件类型的一个历史发布批次，其他国家和文件类型不受影响。

回滚先二次确认，再将所选批次中与当前支持语言对应的文件自动带入待发布预览，无需重新上传这些文件。历史批次缺少当前支持语言时，提示补齐对应语言文件；历史批次中已不受当前市场支持的语言不参与本次发布，市场语言配置保持不变。

待发布内容遵循 2.2 节的完整语言覆盖、内容校验、版本冲突及发布失败处理规则；开始回滚时记录当前生效版本和市场支持语言，用于发布前冲突检查。确认发布前线上版本不变；全部当前支持语言通过校验后一次生效，生成新版本，记录回滚来源批次及补齐文件，保留原历史记录。

仅恢复某一种语言时，按 2.1 节普通新版本上传流程提交完整语言集合。

## 三、FAQ

### 3.1 全量导入

按国家上传一份英语 FAQ `.html` 正文片段文件；首次配置及后续更新均支持下载后台文件后修改，或自行制作符合格式要求的文件。

每个问题使用 `<h2>`。问题可以直接位于正文，也可以由不承载其他业务语义的 `div`、`section`、`article` 包装；按文档顺序识别全部问题标题，从该标题之后到下一个 `<h2>` 之前的内容为答案，最后一条答案延续至正文结束。位于列表、表格等正文业务容器内的 `<h2>` 不作为合法问题标题，提示对应位置并要求调整格式。完整网页外壳的处理与 2.1 节一致。

答案保留段落、强调、列表和合法链接；预览、保存后的内容及下载文件保持该结构，列表可显示纯文本摘要。脚本、自定义样式和不安全内容按第五章清理。

上传后自动解析并展示问题、答案、总条数及校验结果。问题为空、答案为空、首个问题之前存在无法归属的正文、条目标识重复、格式无法识别或链接非法时，提示具体条目并阻止保存。非 `.html` 文件在选择或拖入时拒绝。

导入固定全量覆盖当前国家 FAQ，先解析预览，再确认保存；保存前提示未包含在文件中的旧条目将被删除。当前国家已有 FAQ 且本次文件全部无条目标识时，额外提示“原条目将被替换，首页精选需重新设置”。解析失败或取消时保留原内容。

下载的 HTML 文件携带来源版本和每条 FAQ 的稳定标识。保留当前国家已有条目标识的项目按原条目更新问题和答案，保留首页精选及翻译资源关联；无标识的项目按新条目处理，由系统分配标识，默认不精选，并按 3.2 节建立翻译资源。条目匹配以标识为准，不根据文字相同推断为原条目；非空标识无法匹配当前国家已有条目时，提示对应条目并阻止保存。未匹配的旧项移除，列表顺序以本次文件顺序为准。

打开导入区时记录当前国家 FAQ 的版本，尚无内容时记录空状态。文件携带来源版本时，还须校验其属于当前国家且与当前版本一致；自行制作的文件可不携带来源版本。保存时检查当前版本是否自打开导入区后发生变化，首次导入也执行此检查；任一版本校验失败则保留输入并提示重新核对，原内容不变。

### 3.2 列表维护

列表展示问题与答案摘要、首页精选开关及删除操作；支持拖拽排序。FAQ 无启用或停用状态，点击删除经二次确认后从待保存列表移除。

排序、首页精选和删除在 FAQ 区内点击「保存」后统一生效；保存失败保留修改。列表读取时记录当前国家版本，保存时检查版本是否变化；冲突时保留修改并提示重新核对，原生效内容不变。保存成功输出完整有序 FAQ 列表及首页精选标记，删除项同时退出精选集合。空列表显示上传引导。

列表修改保存前，按 5.2 节重新校验完整 FAQ 的锚点；删除后仍有链接指向已移除目标时阻止保存，并保留待修改内容。

问题和答案作为独立动态业务字段进入翻译系统。已有条目沿用原翻译资源关联，源内容变化后按源内容版本更新翻译资源；新条目建立新的翻译资源，不继承被替换条目的译文。语言选择和译文回退由消费模块负责。

## 四、社媒账号

平台固定为 Facebook、TikTok、Instagram、YouTube；平台名称和图标只读，每个平台按国家维护 URL。

URL 可为空；非空必须为合法 HTTPS 地址。点击本区「保存当前国家」后生效，错误定位到输入框；失败保留输入。输出当前国家的平台标识与 URL，前台展示和打开方式由 Footer 需求定义。

## 五、内容输出与公共校验

### 5.1 生效内容输出

| 内容 | 输出维度 | 对外有效内容 |
|---|---|---|
| 法律文件 | 国家、文件类型、语言 | 当前已发布生效版本、正文、版本号 |
| FAQ | 国家、条目标识 | 当前已保存问题和答案、顺序、首页精选、源版本 |
| 社媒账号 | 国家、平台标识 | 当前已保存 URL，包括空值 |

最新上传或待发布内容不等于当前生效内容。未配置时返回该范围无内容，不以其他国家的数据替代。各消费模块负责国家/语言选择、路由、展示和回退。

### 5.2 校验、权限与异常

文件解析清除脚本、自定义样式、可执行内容及不安全资源。链接仅允许合法 HTTPS 地址、以单个 `/` 开头的站内根路径和 `#标识` 同页锚点；HTTPS 地址须有有效主机，协议相对地址、其他协议和无效链接均阻止通过。

同一份正文中的锚点标识唯一，每个同页锚点必须存在对应目标；FAQ 按本次完整文件校验。解析、保存和下载保留有效的锚点标识与链接。链接 URL 不翻译；站内路径由消费模块结合其国家/语言上下文处理。

只读用户可查看和下载；编辑权限控制上传、保存、发布、删除、排序、精选及回滚。目标不存在时提示刷新；网络失败保留输入并提供重试，不显示成功结果。

### 5.3 多语言内容归属

| 业务对象 | 业务字段或内容 | 类别 | 来源与处理 | 覆盖的展示面 |
|---|---|---|---|---|
| 当前国家 FAQ 条目 | 问题（question） | 动态业务内容 | 英语源文；按国家、稳定条目标识和源内容版本关联问题译文，执行 3.2 节的资源更新规则 | 独立 FAQ 页面、首页精选 FAQ、后台英语预览 |
| 当前国家 FAQ 条目 | 答案（answer） | 动态业务内容 | 英语源文；独立于问题维护答案译文，保留允许的正文结构与链接 | 独立 FAQ 页面、首页精选 FAQ、后台英语预览 |
| 法律文件类型 | 固定文件名称 | 静态 UI 文案 | 开发预置类型对应 message package 文案 | 后台文件列表及上传区 |
| 当前国家法律文件 | 正文及链接文字 | 不翻译 | 法务提供的对应语言版本，按发布批次生效 | 法律文件页面、后台正文预览 |
| 社媒平台 | 平台名称、图标 | 不翻译 | 开发预置固定平台资产 | 后台社媒列表、消费模块 |
| 社媒账号及正文链接 | URL、路径、锚点 | 不翻译 | 按 5.2 节校验，消费模块负责路径上下文 | 后台及对应消费页面 |
| 后台界面 | 菜单、标签、按钮、校验和状态提示 | 静态 UI 文案 | 前后端 message package 管理 | 文件配置后台 |
| 版本与审计记录 | 版本号、操作人、时间、来源批次、稳定标识 | 不翻译 | 系统生成或记录 | 后台列表、下载与历史记录 |

FAQ 目标语言由消费模块的当前语言确定；本文提供英语源文和内容版本，不另设后台语言选择。沿用已有 FAQ 翻译资源的正式标识、字段映射和接入配置，按 3.2 节维护条目与源内容版本的关联；相关资料引用记录见[技术依赖 Checklist](./looply-文件配置-技术依赖Checklist.md)。

## 六、验收与关联

- 切换国家不串数据；放弃修改能恢复已保存内容。
- 每份法律文件的上传区数量与市场支持语言一致；缺一语言、移除文件或校验失败均不能发布。
- 上传自动出现可阅读的正文预览；上传不会直接改变生效内容。
- 当前版和历史版按所选语言下载；回滚按 2.3 节恢复所选国家、文件类型的历史批次，覆盖语言新增与移除场景，确认发布前线上不变，发布后可追溯来源批次及补齐文件。
- FAQ 两种文件来源均可解析预览并确认全量覆盖；按 3.1、3.2 节核验已有标识保留关联、无标识新增与精选重置提示，以及带／不带来源版本文件的保存冲突检查；直接删除、排序和精选的结果与保存后的输出一致。
- FAQ 支持直接正文或允许包装内的 h2 分题；非法业务容器内标题、完整网页外壳、重复或无目标锚点均不能通过。富文本及有效链接在预览、保存、下载后保持。
- 社媒 URL 校验与空值保存符合第四节。
- 消费方只能读取当前生效内容，不能读到未发布草稿。
