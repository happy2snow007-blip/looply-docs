# Looply 营销承接页 PRD v0.2

> 状态：当前工作稿。覆盖 PC 与 H5 已确认配置及展示规则；制品一致性与实际运行验收结论见独立 Review 报告。

## 一、概述

### 1.1 背景与目标

Looply 需要为 Google、Meta、TikTok 等广告提供可复用的营销承接页。页面面向美国市场新客，目标是让用户快速理解活动和 Looply，浏览活动商品，并进入现有商品详情页和结算流程。

首期目标是建立由固定公共内容、活动内容及现有 Collection 页面配置组成的营销承接页模板；市场可复用 Collection 中已配置的标题、副标题、图文筛、筛选、排序和商品池，并在活动变化时保持投放链接稳定。

### 1.2 当前版本范围

- PC 与移动端营销承接页模板。
- 品牌导向·文字型、活动导向·图片型、品类合集三种页面模板，支持保存后切换。
- 文字型活动区。
- 图片型活动区及独立的图片下方保障条展示开关。
- 活动标题、说明和活动图片展示；优惠信息可写入标题或说明。
- 品类合集模板关联任意已生效的 Collection，复用其前台内容配置及商品能力，包括标题、副标题、Banner、图文筛、快筛、抽屉筛、排序和商品池。
- 商品点击进入现有商品详情页，继续现有购物和结算流程。
- Landing 页持有唯一稳定地址；投放短链复用短链管理创建，并与 Landing 页关联。
- 保存即生效及只读生效历史，记录版本、配置快照、生效时间和操作人。
- 页面返回首页入口。
- 移动端营销承接页常驻“联系我们”入口，用于商品咨询。

### 1.3 当前版本不包含

本版本不包含按用户分组展示不同页面内容、同一链接同时对应多份并行页面内容、页面内商品详情和结算、重新建设商品筛选／排序／库存能力。

### 1.4 用户角色

| 角色 | 使用目标 |
|---|---|
| 市场运营 | 创建活动页面、配置活动内容和商品集合、预览并保存生效 |
| 广告用户 | 了解广告对应活动、浏览商品、进入商品详情和结算 |
| 管理员 | 管理公共品牌内容、保存权限和页面版本 |

### 1.5 网站语言与翻译复用

Landing 跟随网站当前设置的语言，语言选择与切换复用网站现有入口和规则。品牌介绍、活动标题和副标题、介绍入口文案、固定界面文案及译文缺失处理，均沿用网站现有翻译规则。图片型按网站当前语言和访问终端读取已配置的活动图：英语读取 en-US，西语读取 es-US；四张图片的必填校验见第 2.3 节。后台配置预览的语言跟随上传项，仅用于检查对应图片，不改变访客的网站语言设置。

## 二、需求详细描述

### 2.1 页面模板

编辑页在同一完整页面内配置。「基础信息」卡片内依次为选择模板、页面名称、页面地址。文字型／图片型展示「页面内容」→「商品配置」；品类合集型直接展示「商品配置」，仅配置关联 Collection，不另设页面内容卡片或重复配置 Collection 内的展示字段。右侧保留实时预览。文字型页面内容分为「品牌介绍」和「活动内容」，各自通过 PC / H5 页签配置；图片型分为「活动 / 广告图片」和「品牌与保障」，图片通过 PC / H5 页签配置。配置区 PC / H5 页签与右侧实时预览共用当前端；切换时保留已填写内容，保存时校验当前模板适用的字段。品类合集型前台内容直接读取关联 Collection 当前生效配置，详见第 2.3a 节。模板保存后允许切换；每次保存立即生效并记录新的配置版本，页面地址和投放短链保持不变。

| 模板 | 页面目标 | 配置内容 |
|---|---|---|
| 品牌导向 · 文字型 | 先建立 Looply 信任，再承接活动商品 | 公共品牌区、活动标题、活动说明和商品区 |
| 活动导向 · 图片型 | 突出广告活动，弱化品牌信息 | PC / 移动端活动图、图片下方保障条开关和商品区 |
| 品类合集 | 复用 Collection 已配置的内容与商品能力 | 关联 Collection；Collection 标题、副标题、Banner、图文筛及筛选／排序／商品池配置 |

切换模板后，编辑页只展示当前模板适用的配置项；保存时按当前模板校验并替换前台结构。模板切换不删除另一模板历史版本中的配置，生效历史保留每次保存时的模板及对应配置快照。

### 2.2 品牌导向 · 文字型模板

文字型模板的品牌区展示标题、副标题、三个卖点和介绍入口。标题分别配置 PC、移动端内容，两端标题均必填；品牌副标题仅 PC 配置和展示，选填，移动端仅展示标题；保存时校验两端标题，空值或仅含空格时阻止保存并提示填写。初始文案为 `Designer pieces deserve another chapter.` 和 `Based in Los Angeles, Looply buys and sells authenticated pre-owned designer pieces.`，实时预览读取所选端配置。

活动内容分别配置 PC / H5 的标题和副标题，两项均选填。每端独立按填写内容展示：仅填写标题或副标题时只展示对应项；两项均为空时整块收起，不保留空白间距。仅含空格的内容按未配置处理。

三个卖点的固定标题和说明为：Authenticity / `3× Money-Back Guarantee`；Shipping / `Free shipping within the contiguous U.S.`；Returns / `Hassle-free returns within 15 days.`。PC 横排展示三个卖点，包含图标、标题和说明；H5 三列横排展示标题和完整说明，不显示图标。开启点击跳转时标题后展示箭头，整个对应卖点为独立点击区；关闭时去掉箭头并保留标题和说明。

「跳转设置」中，每行左侧为文案、右侧为开关，介绍入口文案输入框位于介绍页开关下方。跳转配置分两组：「三个卖点可点击跳转」统一控制 Authenticity、Shipping、Returns，开启后分别跳转到固定的鉴定、配送政策、退货政策详情页；「点击跳转到介绍页」单独控制 About Looply 入口。两个开关默认开启。关闭三个卖点跳转时，保留卖点内容但不可点击；关闭介绍页跳转时，隐藏后台介绍入口文案输入框以及前台和实时预览中的介绍入口。已填写文案保留，重新开启后恢复。目标地址由系统维护，后台无需输入链接。介绍入口文案仍可配置，默认 `Meet Looply →`。两组开关在 PC / H5 共用，也适用于图片型模板的品牌与保障模块。 PC 介绍入口位于品牌标题区右侧；H5 入口接在品牌标题末尾，以较小的无衬线字体和下划线区分，空间不足时自然换行。只有入口文字和箭头可点击，品牌标题及背景不作为介绍页点击区。介绍文案为空或仅含空格时隐藏入口；再次编辑保留已保存空值。

### 2.3 活动导向 · 图片型模板

该模板用于承接 Meta、TikTok、KOL 或品牌视觉活动，公共品牌内容弱化，页面以活动主图为主。

图片型面向美国市场，按英语（en-US）、西语（es-US）分别配置 PC 活动图、移动端活动图（四张均必填），活动标题、说明和优惠信息由运营直接制作在图片中。选择图片型后隐藏活动标题与说明输入项，也不校验文字型标题。活动图按固定横幅区域展示：PC 宽高比为 10:3，H5 为 375:157；区域高度由对应端的展示宽度和固定比例确定，不随原图高度变化。图片保持原比例居中裁切并填满区域。前台、实时预览与后台对应端上传框使用相同比例和裁切方式；空态与已上传状态占用相同比例的区域。图片上不额外叠加标题、说明或遮罩。任一语言、任一端活动图缺失时阻止保存并切换至对应端和语言预览。

编辑区保留 PC / H5 页签，每个页签下平铺 English、Español 两个图片上传位置。空状态提示统一为“点击或拖入图片”；上传后图片显示在框内，右上角 × 移除当前语言、当前端的图片，并恢复该框空态。点击该语言上传项或上传图片后，右侧预览跟随该语言；预览区仅保留 PC / 移动端切换。切换端、语言时保留其他已上传图片。语言图片配置纳入保存和历史快照，查看历史时按语言与终端展示四张图片。

选择图片型后显示「展示图片下方保障条」开关，默认开启。保障条位于活动图片与商品区之间，展示三个卖点和可配置的介绍入口，上方展示 `Designer pieces deserve another chapter.`，PC 介绍入口位于该文案右侧，H5 介绍入口接在文案末尾；三个卖点按第 2.2 节展示完整说明并遵循两组跳转开关。

图片型模板的内容结构为活动图片、可选保障条和商品区。编辑已有页面时回显已保存配置。关闭保障条后整条收起，商品区顺接活动区；文字型页面的介绍入口位置按第 2.2 节。

开关变更即时反映在右侧预览中，保存后对外生效；保障条开关纳入当次版本快照。

### 2.3a 品类合集模板

后台「商品配置」仅配置关联 Collection，并展示该 Collection 的只读摘要。品类合集型不在 Landing 页单独配置品类标题、副标题、Banner、图文筛项目／图片／顺序或其他 Collection 筛选项，避免同一内容在两个模块分别维护。

前台商品内容区完整复用所选 Collection 当前生效的展示配置：页面标题与副标题读取 Collection 基础信息；Banner 读取 Collection Banner 配置；图文筛读取 Collection 的模块开关、图片／文字展示样式、筛选项、图片、筛选条件和顺序；快筛、抽屉筛、排序及商品池沿用 Collection 配置。图文筛启用且有可展示项时，前台按 Collection 配置顺序展示筛选项，不额外展示「All」入口，用户再次点击当前品牌项恢复全部商品；图文筛关闭或没有可展示项时，整行隐藏。PC 按配置顺序一排最多展示前 8 项，不换行、不展示左右翻页箭头；H5 首屏约展示 4.5 项，可横向滑动查看更多。图文筛与下方商品筛选栏紧凑衔接。Landing 实时预览按同一配置展示图文筛，并呈现单选状态和商品筛选结果。Collection 配置了什么内容，Landing 品类合集型就展示什么；Collection 中未启用或未配置的模块遵循 Collection 本身的展示与空态规则。用户在 Landing 页操作图文筛或筛选器时，沿用 Collection 已定义的筛选行为和商品结果规则。Landing 上述入口、端内数量与布局采用本节规则；图文筛数据字段和筛选条件引用 [Collection PRD v1.6 §2.5、§4.4](https://happy2snow007-blip.github.io/looply-docs/docs-Collection%E7%AE%A1%E7%90%86/PRD/looply-collection-landing-PRD-v1.6.md)。

PC 与 H5 均复用关联 Collection；图文筛入口与布局采用本节规则，其余行为沿用 Collection。关联更新与异常见第 2.4 节。

### 2.4 商品区

商品区可直接关联已有的生效 Collection，不限制名称前缀。新建广告专用 Collection 时建议名称以 `market` 开头，作为管理约定而非关联条件。

关联字段下方展示中文操作提示：“可直接关联已有的生效 Collection。如需新建广告专用合集，请先前往 Collection 模块配置，建议名称以 market 开头。”选择器支持按名称搜索，展示所有状态为「生效」的 Collection。关联后展示 Collection 名称、状态、商品数量和最近更新时间；当前版本只允许选择状态为「生效」的 Collection。

Landing 后台商品配置仅提供 Collection 关联及只读摘要，不展示商品管理列表或重复配置 Collection 展示内容的表单。品类合集型按第 2.3a 节读取当前生效配置；Collection 更新后，所有关联 Landing 页读取最新配置和商品结果，无需重新保存 Landing。已关联 Collection 后续进入草稿、停用或失效状态时，编辑页回显实际状态并阻止保存；访客端失效、空商品池、筛选无结果及网络异常，复用 [Collection PRD v1.6 §3.4](https://happy2snow007-blip.github.io/looply-docs/docs-Collection%E7%AE%A1%E7%90%86/PRD/looply-collection-landing-PRD-v1.6.md) 的对应页面状态。

商品点击进入现有商品详情页，结算继续使用现有流程。页面返回后保留活动页的浏览入口。

### 2.5 页面导航与链接

页面固定提供 Logo 返回首页、购物袋和必要的站内导航。卖点及介绍入口链接按第 2.2 节配置。

### 2.6 移动端常驻联系入口

移动端三种营销承接页模板均复用网站现有常驻客服入口组件，位于视口右下方，不受模板或保障条开关影响。点击后的目标、游客与登录态、服务可用状态、异常处理、浮层层级、安全区域及无障碍行为，均沿用现有组件逻辑。

### 2.7 稳定页面地址与投放短链

Landing 完整复用现有短链管理的短码生成与校验、UTM 字段与拼接、重定向参数透传、复制及效果统计逻辑。Landing 负责带入稳定页面地址、页面关联和默认备注，提供关联短链入口，并在返回时展示短链管理中同一记录的最新数据。以下仅定义 Landing 的关联与跨模块动作。

页面地址由系统固定的域名及路径前缀，加上根据页面名称自动生成的只读后缀组成。基础信息规则如下：

| 字段 | 规则 |
|---|---|
| 页面名称（英文） | 必填，最多 100 个字符；支持英文字母、数字、空格和短横线，至少包含一个英文字母。用于后台管理，不翻译，与前台活动标题独立；保存后仍可修改。 |
| 地址后缀 | 新建时随页面名称自动生成：去除首尾空格、字母转小写、连续空格或短横线合并为一个短横线，并去除首尾短横线。例如 `Gucci Picks` 生成 `gucci-picks`。后缀由系统自动生成，运营不可编辑；页面名称变化时，仅在页面尚未保存时同步更新预览后缀。 |
| 页面地址 | 新建时展示固定前缀及系统生成的只读后缀；首次保存成功后完整地址保持只读、可复制。地址标识页面，不包含活动商品筛选条件。 |

地址后缀由系统生成，仅允许小写英文字母、数字和单词之间的单个短横线。在同一固定前缀下必须唯一；保存时发现生成结果重复或格式不合法，应提示调整页面名称并阻止保存，保留已填写内容。并发创建也须保证地址唯一。

首次保存成功后地址固定。后续修改页面名称、图片、文案或关联 Collection 均不改变页面地址，也不要求重新生成已关联的投放短链。关联 Collection 及活动内容保存为该页面的配置。已有页面继续保留原地址。

前台访问该地址时读取当前生效的页面配置，按配置获取和展示商品。内容更新生效后须同步更新相关缓存，使新访问或刷新页面读取生效内容；已打开的页面不强制自动跳转或刷新。

扩展约束：稳定页面标识与内容配置分离；后续增加按用户分组配置时仍可沿用原页面地址和短链关联。本期所有用户读取同一生效配置，历史版本仅用于只读追溯。

Landing 页列表提供「投放链接」入口，进入当前页面的关联短链列表，支持查看、复制已有短链和创建投放链接。关联列表展示短码、渠道（utm_source）、utm_medium、备注、创建时间和操作；复制操作复制完整短链地址。同一 Landing 页可关联多条短链，各自使用不同的渠道和 UTM 参数，统一指向该页面的稳定地址。

点击「生成投放链接」跳转短链管理模块的「创建运营短链」页，导航选中短链管理：基础 URL 自动带入当前 Landing 页稳定地址，关联 Landing 页以页面唯一标识保存，带入的基础 URL 锁定；备注名称默认带入页面名称，允许修改。创建表单中自定义短码及 UTM 字段沿用短链管理配置。带入的基础 URL 不携带活动商品筛选参数。

创建成功后返回原 Landing 页的关联列表并展示新增记录；取消或返回也回到原列表。短链由短链管理统一保存，Landing 查询同一份记录。关联列表提供「复制链接」「编辑链接」「查看链接」和「查看效果」：「编辑链接」和「查看链接」均进入短链管理中对应短链的编辑页或详情页；编辑时可修改短码、备注及 UTM 参数，关联 Landing 页与基础 URL 保持绑定。保存后短链管理更新同一条短链记录，返回 Landing 关联列表时重新读取并展示最新短码、渠道、备注和 UTM 信息；不创建副本或解绑关联。「查看效果」进入该短链的效果详情，返回时回到原关联列表。Landing 页内容更新时保留短链关联及其 UTM 参数。

### 2.8 配置保存、生效与历史追踪

编辑页底部提供「保存」按钮，实时效果预览展示当前编辑内容。配置校验通过并保存成功后立即生效，同时记录递增版本、完整配置快照、生效时间和实际操作人。

首次保存成功按第 2.7 节规则确定稳定页面地址，页面即可访问；后续保存成功用新配置替换当前内容。页面地址、关联短链及 UTM 参数保持不变，访问和缓存规则见第 2.7 节。

Landing 页列表按「页面名称、页面地址、关联 Collection、操作」展示。页面地址为稳定 Landing 地址，支持复制；操作为「编辑、投放链接、生效历史」。列表提供按页面名称查询，支持查询按钮及回车提交；重置清除查询条件并恢复列表。按最近更新时间倒序，每页 10 条；区分暂无页面、没有匹配结果、加载中、加载失败及重试状态。

「生效历史」按生效时间倒序分页展示版本、状态、生效时间、操作人及「查看配置」。时间显示到秒并标注时区。

| 状态 | 含义 | 触发时机 | 记录内容／适用场景 |
|---|---|---|---|
| 当前生效 | 当前对外使用的版本 | 保存成功 | 每张页面最多一个 |
| 历史版本 | 曾生效、已被后续版本替代 | 新版本生效成功 | 保留原快照、生效时间和操作人 |

「查看配置」只读展示当次生效的 Landing 配置。品类合集型记录关联 Collection 标识，不复制 Collection 的标题、副标题、Banner、图文筛、筛选器、排序或商品池配置；历史版本不冻结这些 Collection 数据。历史记录范围不包含当时商品结果、价格或库存快照。页面按实际访问时关联 Collection 的当前生效配置展示。

保存失败时保留编辑内容，原生效配置和历史记录保持不变；重试同一次保存请求不得重复生成版本。多人同时修改导致配置已变化时阻止覆盖并提示重新加载；无权限或页面不存在时阻止提交。切换生效配置与保存历史须同时成功，成功后提示「已保存并生效」。

UI 关联：后台 V5 Demo 的编辑页、列表和生效历史页；后台为 PC 操作，移动端消费生效内容。

## 三、页面流转

后台：编辑 Landing 页 → 保存（立即生效）→ Landing 页列表 → 投放链接列表 → 生成投放链接 → 短链管理创建页（带入并锁定页面地址、带入页面关联与备注）→ 创建成功 → 返回关联列表。

后台：Landing 页列表 → 生效历史 → 查看配置。

广告 → 营销承接页 → Collection 商品卡 → 商品详情页 → 购物袋／结算页

营销承接页 Logo → Looply 首页

卖点 → 对应固定详情页；介绍入口 → About Looply 介绍页（开关与点击区见第 2.2 节）

## 四、依赖与风险

- Collection 内容、商品及交互能力完整复用，范围见第 2.3a、2.4 节；对应端能力的接入与联调由开发核对。
- 依赖短链管理支持创建时带入页面地址、保存 Landing 页关联并查询关联短链；前台需支持按稳定页面标识读取生效配置及缓存更新，并保证配置保存、生效切换与历史记录同时成功。
- 优惠文案、优惠码、有效期和资格由优惠系统提供，页面展示不替代优惠资格校验。
- Free Shipping、Easy Returns、3× Money-Back Guarantee 的正式文案、适用范围与条款需在发布前确认。
- 公共品牌区使用的 Slogan 当前按用户指定文案记录；正式品牌口径需与品牌负责人确认。
- 网站语言状态、翻译及译文缺失处理复用第 1.5 节规则。

## 五、版本规划

本次沿用 v0.2 工作稿，当前开发范围见第 1.2 节；后续分组内容扩展遵循第 2.7 节的稳定地址约束。历史版本回滚等后续讨论保留在 Checklist，另行确认后纳入后续版本。

| 场景 | 验收结果 | 权威章节 |
|---|---|---|
| 网站语言 | 网站语言切换后，图片读取对应语言与终端资产，文字及缺译处理沿用现有翻译规则 | 1.5 |
| 新建与模板切换 | 基础信息顺序正确；三模板只展示适用配置，端切换联动预览并保留输入 | 2.1 |
| 文字型品牌与活动 | 两端品牌标题校验；H5 无品牌副标题；活动仅按非空字段显示，空区收起 | 2.2 |
| 卖点及介绍入口 | 完整卖点说明、端内布局、两组开关、默认文案和独立点击区一致；关开后保留已填文案 | 2.2 |
| 四张图片 | 缺任一图阻止保存；PC/H5 上传框、空态及预览比例一致，裁切居中且不被原图撑高 | 2.3 |
| 上传与移除 | 上传图片显示在框内；× 仅清除当前项；点击不同语言上传项时预览跟随，其他项保留 | 2.3 |
| 图片保障条 | 开关即时改变预览，保存及历史回显一致；关闭时商品区顺接活动图 | 2.3 |
| 品类合集 | 只关联 Collection；标题、Banner、图文筛来源正确；无 All 入口，PC 前8一排、H5横滑；点当前项恢复完整商品池 | 2.3a |
| Collection 关联 | 所有生效项可搜索选择，无名称前缀限制；状态异常阻止保存；当前配置更新按引用同步 | 2.4 |
| 导航及联系 | 商品、Logo、购物袋及联系入口进入对应现有流程，三模板端内行为一致 | 2.4–2.6 |
| 页面地址 | 名称生成只读后缀，格式及唯一性校验；首次保存后改名、改内容和 Collection 均保持地址 | 2.7 |
| 投放短链 | 创建带入并锁定页面地址；编辑、查看和效果进入短链模块；保存返回后关联列表展示同一记录最新值 | 2.7 |
| 保存与历史 | 保存立即生效、版本递增、历史只读；四张语言图片可查；失败不改变原配置，重复和冲突按保存规则处理 | 2.8 |

联调验证短链管理现有的 UTM 与重定向参数透传规则在 Landing 目标地址上保持一致，并覆盖普通浏览器、社媒内置浏览器、已安装 App 和社媒爬虫访问。正式服务与异常处理的验收须在真实系统中执行。
