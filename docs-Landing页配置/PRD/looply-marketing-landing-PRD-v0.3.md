# Looply 营销承接页 PRD v0.3

> 状态：当前工作稿。覆盖 PC 与 H5 已确认配置及展示规则；制品一致性与实际运行验收结论见独立 Review 报告。

## 一、概述

### 1.1 背景与目标

Looply 需要为 Google、Meta、TikTok 等广告提供可复用的营销承接页。页面面向美国市场新客，目标是让用户快速理解活动和 Looply，浏览活动商品，并进入现有商品详情页和结算流程。

本期将页面统一为图片、Slogan 和跳转、三个保障、商品配置四个模块。市场可按需要组合前三个模块，商品内容继续复用 Collection，投放地址保持稳定。

### 1.2 当前版本范围

- PC 与 H5 共用四模块配置结构，前三个模块可独立隐藏。
- 可选图片，支持单个可拖拽跳转入口；PC/H5、英语/西语分别配置图片与入口。
- 可选 Slogan，文案可修改，支持可选跳转入口。
- 三个保障支持整体展示及跳转开关。
- 商品配置继续关联生效 Collection，完整复用标题、副标题、Banner、图文筛、筛选、排序和商品池。
- 稳定页面地址、投放短链、生效历史、商品详情及购物流程保持原逻辑。

### 1.3 当前版本不包含

本版本不包含按用户分组展示不同页面内容、同一链接同时对应多份并行页面内容、页面内商品详情和结算、重新建设商品筛选／排序／库存能力。

### 1.4 用户角色

| 角色 | 使用目标 |
|---|---|
| 市场运营 | 创建活动页面、配置活动内容和商品集合、预览并保存生效 |
| 广告用户 | 了解广告对应活动、浏览商品、进入商品详情和结算 |
| 管理员 | 管理公共品牌内容、保存权限和页面版本 |

### 1.5 网站语言与翻译复用

Landing 跟随网站当前设置的语言；美国市场、英语／西语、当前 locale、游客浏览器保存和登录账号保存复用[首页 PRD v1.10 §2.1](https://happy2snow007-blip.github.io/looply-docs/docs-%E9%A6%96%E9%A1%B5/PRD/looply-%E9%A6%96%E9%A1%B5-PRD-v1.10.md)。缺失译文处理继续沿用网站现有规则。Slogan、Slogan 跳转文案、图片入口文案属于动态业务内容，沿用网站业务内容翻译流程；Collection 文案复用 Collection 自有翻译。链接、颜色、样式和位置不翻译；后台标签、校验提示和三个保障固定文案属于静态 UI 文案。页面名称仅后台使用，不翻译。

图片按英语（en-US）、西语（es-US）及 PC/H5 独立配置；图片入口文案与对应语言图片一起维护。每个语言和终端组合可以独立留空，前台按当前语言、终端读取该组合，未配置图片则隐藏该图片模块。后台语言切换仅用于预览，不影响访客网站语言。

## 二、需求详细描述

### 2.1 页面结构与配置顺序

统一在一个完整页面配置。「基础信息」包含页面名称、页面地址。其后依次为「图片（选填）」「Slogan 和跳转（选填）」「三个保障」「商品配置」，右侧为实时预览。前台顺序对应图片 → Slogan 和跳转 → 三个保障 → Collection 商品内容区，隐藏的模块不保留空白间距。

编辑区 PC/H5 与右侧预览共用当前终端，图片上传项与预览共用当前语言。切换端或语言时保留已配置内容，保存包含全部终端及语言配置。各模块相互独立，隐藏 Slogan 不影响保障及图片，隐藏保障不影响商品区。

### 2.2 图片模块

图片可承载品牌或达人信息，属于选填。PC 图片固定宽高比 10:3，H5 为 375:157，保持原比例居中裁切填满；后台画布、实时预览与前台使用相同区域比例和裁切方式。区域高度由展示宽度及固定比例计算，不随原图高度变化。

编辑区按 PC/H5 切换，每端平铺 English、Español 上传位置，接受不超过 3 MiB 的图片。未上传时提示「点击或拖入图片」；上传后图片位于框内，「更换图片」选择新图；新图读取成功后替换，失败时保留原图和入口配置。右上角 × 移除当前语言、当前端图片并恢复空框。实时预览和前台在没有图片时直接收起模块。上传失败保留原图并反馈失败，文件类型或大小不合法时拒绝替换。

每张图片支持一个独立跳转入口。上传图片后配置以下内容：

| 字段 | 规则 |
|---|---|
| 跳转文案 | 选填，最多 60 字符，支持当前图片语言文案；仅空格按空值处理。 |
| 跳转链接 | 选填，接受 http/https 绝对链接或单斜杠开头的站内路径；去除首尾空格后保存。 |
| 入口样式 | 实心按钮、描边按钮、文字链接；默认实心按钮。 |
| 颜色 | 默认 #A4002A；实心按钮使用此背景色及白色文字，描边按钮使用此文字和边框颜色，文字链接使用此文字颜色。 |
| 位置 | PC/H5、英语/西语分别定位，以入口左上角相对图片展示区域的横纵百分比保存，初始为横向 10%、纵向 70%。 |

文案及链接同时为空时，仅展示内容图片；二者完整且链接有效时展示可点击入口。只填一项或链接格式无效时，保存提示补齐或同时清空，并定位到相应终端、语言。图片本身不是跳转点击区。点击前台入口在新标签页打开目标，站内路径按网站域名解析。

后台可在图片上拖动入口；鼠标松开后更新位置，并即时同步右侧预览。入口可聚焦后用方向键按 1 个百分点微调，保证可操作的替代定位方式。拖动位置限制在展示区域内，入口整体不超出图片；浏览器缩放、预览宽度或文案长度改变时，按保存比例定位，并将超出区域的部分向内约束。长文案在图片区域内换行。

删除图片时保留该组合的入口配置，供重新上传后恢复；无图时入口不展示、不参与完整性校验。更换图片保留入口样式和位置，预览即时更新，运营需确认新构图下的遮挡与位置。前台入口不能拖动，拖动仅发生在后台配置画布。

### 2.3 Slogan 和跳转、三个保障

Slogan 默认 `Designer pieces deserve another chapter.`，可修改、可清空。未填写或仅含空格时，整条模块连同跳转入口隐藏且不留间距。Slogan 使用网站当前语言译文，PC/H5 共用内容；H5 自然换行。

Slogan 跳转文案和链接均可配置，文案最多 60 字符。编辑时填写跳转文案即在实时预览展示；链接未填或无效时预览入口不可点击。两项都为空时不展示入口；配置 Slogan 且只填写跳转的一项时，保存提示补齐或同时清空。链接格式与图片入口一致，点击在新标签页打开；只有入口可点击。入口宽度随跳转文案自适应，空间不足时换行；长文案完整展示，不截断、不省略，连续长字符也须折行，避免溢出页面。具体入口位置、边距、字号、行高和点击区域尺寸以 UI 稿为准；本 PRD 不指定固定像素值。Slogan 留空时保存已填跳转配置但隐藏整条模块，恢复 Slogan 后按已保存配置展示。

三个保障使用「保障展示」单选项：不展示、仅展示内容、展示并支持跳转，默认「展示并支持跳转」。「不展示」收起整块；「仅展示内容」保留三项内容，去掉箭头和点击行为；「展示并支持跳转」展示内容及对应跳转。选择后即时更新预览，保存后生效。已有配置按原展示和跳转状态回显对应选项。

| 保障 | 固定说明 | 支持跳转时的目标 |
|---|---|---|
| Authenticity | 3× Money-Back Guarantee | 网站现有鉴定详情页 |
| Shipping | Free shipping within the contiguous U.S. | 网站现有配送政策详情页 |
| Returns | Hassle-free returns within 15 days. | 网站现有退货政策详情页 |

PC 横排三项，展示图标、标题和说明；H5 三列展示标题及完整说明。开启跳转时标题后展示箭头，每个保障块为独立点击区，目标由系统维护，PC/H5 共用该选择，点击在新标签页打开。保障展示状态独立于 Slogan、图片。

### 2.3a Collection 展示复用

商品模块继续使用当前 Collection 逻辑。后台仅配置关联 Collection，并展示只读摘要；Collection 标题、副标题、Banner、图文筛、筛选器、排序和商品池在 Collection 中维护。

前台商品内容区完整读取所选 Collection 当前生效配置。图文筛读取模块开关、图片／文字样式、筛选项、图片、筛选条件及顺序。启用且有可展示项时按配置顺序展示，再次点击当前品牌恢复全部商品；关闭或为空时收起整行。保持已确认的 Landing 布局：无 All 入口，PC 一排最多前 8 项、不换行、无左右箭头；H5 首屏约 4.5 项，可横向滑动，和下方筛选栏紧凑衔接。

其余展示、空态、筛选和商品结果规则复用 [Collection PRD v1.6 §2.5、§4.4](https://happy2snow007-blip.github.io/looply-docs/docs-Collection%E7%AE%A1%E7%90%86/PRD/looply-collection-landing-PRD-v1.6.md)，关联更新与异常见第 2.4 节。

### 2.4 商品区

商品区可直接关联已有的生效 Collection，不限制名称前缀。新建广告专用 Collection 时建议名称以 `market` 开头，作为管理约定而非关联条件。

关联字段下方展示中文操作提示：“可直接关联已有的生效 Collection。如需新建广告专用合集，请先前往 Collection 模块配置，建议名称以 market 开头。”选择器支持按名称搜索，展示所有状态为「生效」的 Collection。关联后展示 Collection 名称、状态、商品数量和最近更新时间；当前版本只允许选择状态为「生效」的 Collection。

Landing 后台商品配置仅提供 Collection 关联及只读摘要，不展示商品管理列表或重复配置 Collection 展示内容的表单。商品内容区标题、副标题统一读取关联 Collection 当前生效配置及对应语言内容；市场运营在 Collection 中维护文案，更新后影响所有引用该 Collection 的页面。不同活动需要独立文案时，分别关联活动专用 Collection。商品模块其余内容按第 2.3a 节读取当前生效配置；Collection 更新后，所有关联 Landing 页读取最新配置和商品结果，无需重新保存 Landing。已关联 Collection 后续进入草稿、停用或失效状态时，编辑页回显实际状态并阻止保存；访客端失效、空商品池、筛选无结果及网络异常，复用 [Collection PRD v1.6 §3.4](https://happy2snow007-blip.github.io/looply-docs/docs-Collection%E7%AE%A1%E7%90%86/PRD/looply-collection-landing-PRD-v1.6.md) 的对应页面状态。

商品点击进入现有商品详情页，结算继续使用现有流程。页面返回后保留活动页的浏览入口。

### 2.5 页面导航与链接

页面固定提供 Logo 返回首页、购物袋和必要的站内导航。图片入口、Slogan 跳转及保障入口分别按第 2.2、2.3 节配置。

### 2.6 移动端常驻联系入口

移动端营销承接页复用网站现有常驻客服入口组件，位于视口右下方，不受图片、Slogan 或保障显示状态影响。点击后的目标、游客与登录态、服务可用状态、异常处理、浮层层级、安全区域及无障碍行为，均沿用现有组件逻辑。

### 2.7 稳定页面地址与投放短链

Landing 完整复用现有短链管理的短码生成与校验、UTM 字段与拼接、重定向参数透传、复制及效果统计逻辑。Landing 负责带入稳定页面地址、页面关联和默认备注，提供关联短链入口，并在返回时展示短链管理中同一记录的最新数据。以下仅定义 Landing 的关联与跨模块动作。

页面地址由系统固定的域名及路径前缀，加上根据页面名称自动生成的只读后缀组成。基础信息规则如下：

| 字段 | 规则 |
|---|---|
| 页面名称（英文） | 必填，最多 100 个字符；支持英文字母、数字、空格和短横线，至少包含一个英文字母。用于后台管理，不翻译，与前台活动标题独立；保存后仍可修改。 |
| 地址后缀 | 新建时随页面名称自动生成：去除首尾空格、字母转小写、连续空格或短横线合并为一个短横线，并去除首尾短横线。例如 `Gucci Picks` 生成 `gucci-picks`。后缀由系统自动生成，运营不可编辑；页面名称变化时，仅在页面尚未保存时同步更新预览后缀。 |
| 页面地址 | 新建时展示固定前缀及系统生成的只读后缀；首次保存成功后完整地址保持只读、可复制。地址标识页面，不包含活动商品筛选条件。 |

地址后缀由系统生成，仅允许小写英文字母、数字和单词之间的单个短横线。在同一固定前缀下必须唯一；保存时发现生成结果重复或格式不合法，应提示调整页面名称并阻止保存，保留已填写内容。并发创建也须保证地址唯一。

首次保存成功后地址固定。后续修改页面名称、图片、文案或关联 Collection 均不改变页面地址，也不要求重新生成已关联的投放短链。Collection 更新行为见第 2.4 节。

前台访问该地址时读取当前生效的页面配置，按配置获取和展示商品。内容更新生效后须同步更新相关缓存，使新访问或刷新页面读取生效内容；已打开的页面不强制自动跳转或刷新。

扩展约束：稳定页面标识与内容配置分离；后续增加按用户分组配置时仍可沿用原页面地址和短链关联。本期所有用户读取同一生效配置，历史版本仅用于只读追溯。

Landing 页列表提供「投放链接」入口，进入当前页面的关联短链列表，支持查看、复制已有短链和创建投放链接。关联列表展示短码、渠道（utm_source）、utm_medium、备注、创建时间和操作；复制操作复制完整短链地址。同一 Landing 页可关联多条短链，各自使用不同的渠道和 UTM 参数，统一指向该页面的稳定地址。

点击「生成投放链接」跳转短链管理模块的「创建运营短链」页，导航选中短链管理：基础 URL 自动带入当前 Landing 页稳定地址，关联 Landing 页以页面唯一标识保存，带入的基础 URL 锁定；备注名称默认带入页面名称，允许修改。创建表单中自定义短码及 UTM 字段沿用短链管理配置。带入的基础 URL 不携带活动商品筛选参数。

创建成功后返回原 Landing 页的关联列表并展示新增记录；取消或返回也回到原列表。短链由短链管理统一保存，Landing 查询同一份记录。关联列表提供「复制链接」「编辑链接」「查看链接」和「查看效果」：「编辑链接」和「查看链接」均进入短链管理中对应短链的编辑页或详情页；编辑时可修改短码、备注及 UTM 参数，关联 Landing 页与基础 URL 保持绑定。保存后短链管理更新同一条短链记录，返回 Landing 关联列表时重新读取并展示最新短码、渠道、备注和 UTM 信息；不创建副本或解绑关联。「查看效果」进入该短链的效果详情，返回时回到原关联列表。Landing 页内容更新时保留短链关联及其 UTM 参数。

### 2.8 配置保存、生效与历史追踪

编辑页底部提供「保存」按钮，实时效果预览展示当前编辑内容。配置校验通过并保存成功后立即生效，同时记录递增版本、四模块完整配置快照、生效时间和实际操作人。

首次保存成功按第 2.7 节规则确定稳定页面地址，页面即可访问；后续保存成功用新配置替换当前内容。页面地址、关联短链及 UTM 参数保持不变，访问和缓存规则见第 2.7 节。

Landing 页列表按「页面名称、页面地址、关联 Collection、操作」展示。页面地址为稳定 Landing 地址，支持复制；操作为「编辑、投放链接、生效历史」。列表提供按页面名称查询，支持查询按钮及回车提交；重置清除查询条件并恢复列表。按最近更新时间倒序，每页 10 条；区分暂无页面、没有匹配结果、加载中、加载失败及重试状态。

「生效历史」按生效时间倒序分页展示版本、状态、生效时间、操作人及「查看配置」。时间显示到秒并标注时区。

| 状态 | 含义 | 触发时机 | 记录内容／适用场景 |
|---|---|---|---|
| 当前生效 | 当前对外使用的版本 | 保存成功 | 每张页面最多一个 |
| 历史版本 | 曾生效、已被后续版本替代 | 新版本生效成功 | 保留原快照、生效时间和操作人 |

「查看配置」只读展示当次生效的 Landing 配置。图片模块记录各语言、各端的图片及入口文案、链接、样式、颜色和百分比位置；Slogan 模块记录文案与跳转配置；保障模块记录展示、跳转开关；商品模块记录 Collection 引用。商品模块仅记录关联 Collection 标识，不复制 Collection 的标题、副标题、Banner、图文筛、筛选器、排序或商品池配置；历史版本不冻结这些 Collection 数据。历史记录范围不包含当时商品结果、价格或库存快照。页面按实际访问时关联 Collection 的当前生效配置展示。

保存失败时保留编辑内容，原生效配置和历史记录保持不变；重试同一次保存请求不得重复生成版本。多人同时修改导致配置已变化时阻止覆盖并提示重新加载；无权限或页面不存在时阻止提交。切换生效配置与保存历史须同时成功，成功后提示「已保存并生效」。


旧版页面再次编辑时转换为四模块表单：文字型保留 Slogan 及原介绍入口、开启保障；图片型保留原图片，原保障条开启时保留 Slogan 和保障，关闭时隐藏两者；品类合集型图片与 Slogan 留空、保障关闭。关联 Collection、稳定页面地址及短链关联保持原值。旧品牌副标题不进入新页面结构，图片原有像素内容保持不变；旧版生效历史保留原快照。转换后的配置仅在保存成功后生效。

UI 关联：后台 V6 Demo 的编辑页、列表和生效历史页；后台为 PC 操作，移动端消费生效内容。

## 三、页面流转

后台：编辑 Landing 页 → 保存（立即生效）→ Landing 页列表 → 投放链接列表 → 生成投放链接 → 短链管理创建页（带入并锁定页面地址、带入页面关联与备注）→ 创建成功 → 返回关联列表。

后台：Landing 页列表 → 生效历史 → 查看配置。

广告 → 营销承接页 → Collection 商品卡 → 商品详情页 → 购物袋／结算页

营销承接页 Logo → Looply 首页

图片入口／Slogan 跳转 → 配置的目标链接；三个保障 → 对应固定详情页（见第 2.2、2.3 节）

## 四、依赖与风险

- Collection 内容、商品及交互能力完整复用，范围见第 2.3a、2.4 节；对应端能力的接入与联调由开发核对。
- 依赖短链管理支持创建时带入页面地址、保存 Landing 页关联并查询关联短链；前台需支持按稳定页面标识读取生效配置及缓存更新，并保证配置保存、生效切换与历史记录同时成功。
- Free Shipping、Easy Returns、3× Money-Back Guarantee 的正式文案、适用范围与条款需在发布前确认。
- 公共品牌区使用的 Slogan 当前按用户指定文案记录；正式品牌口径需与品牌负责人确认。
- 网站语言状态、翻译及译文缺失处理复用第 1.5 节规则。

## 五、版本规划

本次形成 v0.3 四模块配置工作稿，当前开发范围见第 1.2 节；后续分组内容扩展遵循第 2.7 节的稳定地址约束。历史版本回滚等后续讨论保留在 Checklist，另行确认后纳入后续版本。

| 网站语言 | 网站语言切换后，图片读取对应语言与终端资产，文字及缺译处理沿用现有翻译规则 | 1.5 |
| 四模块配置 | 基础信息后依次为图片、Slogan、保障及商品；PC/H5 切换联动预览并保留输入 | 2.1 |

| 图片入口 | 单入口三种样式；拖拽与方向键均生效，位置不越界；换端、换语言、保存再编辑恢复位置 | 2.2 |
| 入口校验 | 图片存在／Slogan 非空时，文案与链接成对校验；无图／空 Slogan 的隐藏入口免校验；均空无入口；有效目标可点击 | 2.2、2.3 |
| Slogan | 默认文案可改；空白时整条及跳转隐藏；恢复后跳转配置保留；短文案、60 字符长文案及连续长字符在 PC/H5 均完整展示、换行且不溢出；仅入口可点击，具体位置与尺寸按 UI 稿验收 | 2.3 |

| Collection 关联 | 所有生效项可搜索选择，无名称前缀限制；状态异常阻止保存；当前配置更新按引用同步 | 2.4 |
| 导航及联系 | 商品、Logo、购物袋及联系入口进入对应现有流程，端内行为沿用现有组件 | 2.4–2.6 |
| 页面地址 | 名称生成只读后缀，格式及唯一性校验；首次保存后改名、改内容和 Collection 均保持地址 | 2.7 |
| 投放短链 | 创建带入并锁定页面地址；编辑、查看和效果进入短链模块；保存返回后关联列表展示同一记录最新值 | 2.7 |
| 保存与历史 | 保存立即生效、版本递增、历史只读；四模块及各语言图片入口、位置可查；失败不改变原配置，重复和冲突按保存规则处理 | 2.8 |

联调验证短链管理现有的 UTM 与重定向参数透传规则在 Landing 目标地址上保持一致，并覆盖普通浏览器、社媒内置浏览器、已安装 App 和社媒爬虫访问。正式服务与异常处理的验收须在真实系统中执行。
