# Looply 物流管理模块 — 竞品调研报告 v1.0

> 版本：v1.0 | 日期：2026-05-09 | 作者：产品架构组

---

## 一、调研背景

Looply 作为面向美国市场的二手奢侈品电商平台，需要设计物流管理模块支撑以下核心场景：

- 运单号录入与物流轨迹追踪
- 配送限制管理（禁售地址、可配送区域）
- 运费策略（初期免运费）
- 退货物流闭环

本报告调研美国主流二手奢侈品/时尚电商平台的物流方案，为 Looply 物流模块设计提供参考。

---

## 二、竞品物流方案对比

### 2.1 The RealReal

| 维度 | 方案 |
|------|------|
| 承运商 | UPS Ground（主力）、UPS SurePost、OnTrac、DHL eCommerce |
| 物流追踪 | UPS 原生追踪系统，订单页面内嵌追踪链接 |
| 运费策略 | 买家付运费；寄售者寄送免费（平台提供预付面单）；夏威夷/阿拉斯加加收 $5 |
| 配送时效 | UPS Ground 3-5 个工作日 |
| 退货方案 | 14天内可退，平台提供退货面单 |
| 配送限制 | 仅限美国境内 |

**模式**：中心化仓储——所有商品先入仓鉴定后再发货，物流链路简单可控。

---

### 2.2 Vestiaire Collective

| 维度 | 方案 |
|------|------|
| 承运商 | DHL、UPS（根据路线选择） |
| 物流追踪 | 平台内追踪 + 承运商追踪号 |
| 运费策略 | 买家承担，根据商品价格/路线/重量动态计算 |
| 配送模式 | 两种：(1) 卖家寄到鉴定中心再转发买家；(2) Direct Shipping 卖家直发 |
| 退货方案 | 收货后 48-72 小时内可退，退货运费买家承担 |
| 配送限制 | 支持国际配送（全球多个鉴定中心） |

**模式**：全球化物流网络，多鉴定中心模式，支持跨境交易。

---

### 2.3 Poshmark

| 维度 | 方案 |
|------|------|
| 承运商 | USPS Ground Advantage（2025年从 Priority Mail 切换） |
| 物流追踪 | USPS 追踪号，App 内实时状态更新 |
| 运费策略 | 买家付固定运费 $7.67-$7.97（5磅以内）；超重按阶梯计费 |
| 配送时效 | 3-5 个工作日 |
| 退货方案 | 收货后 3 天内可申请退货，平台仲裁后提供退货面单 |
| 配送限制 | 仅限美国境内；**支持 PO Box**（USPS 优势） |

**模式**：P2P 模式，卖家自行打包发货；平台提供预付面单；统一费率降低买家决策成本。

---

### 2.4 ThredUp

| 维度 | 方案 |
|------|------|
| 承运商 | USPS（Clean Out Kit）、UPS/FedEx（买家订单） |
| 物流追踪 | 平台内追踪 |
| 运费策略 | 满额免运费；Clean Out Kit 免费寄送和退回 |
| 配送模式 | 中心化仓储——卖家寄 Clean Out Kit 到仓库，平台处理后发货 |
| 退货方案 | 提供退货面单，部分情况免费退货 |
| 配送限制 | 仅限美国境内 |

**模式**：完全中心化运营，卖家零物流负担。

---

### 2.5 Rebag

| 维度 | 方案 |
|------|------|
| 承运商 | UPS/FedEx（推测） |
| 运费策略 | 标准运费 $20；Rebag+ 会员免运费；支持加急配送 |
| 配送时效 | 标准 6-9 个工作日；加急 3-5 个工作日 |
| 国际配送 | 支持，结账时自动计算关税（DDP 模式） |
| 退货方案 | 提供退货面单 |

**模式**：会员免运费策略驱动复购；DDP 国际配送对买家友好。

---

### 2.6 StockX

| 维度 | 方案 |
|------|------|
| 承运商 | UPS（主力） |
| 物流追踪 | UPS 追踪，平台内状态更新 |
| 配送模式 | 卖家寄到鉴定中心 → 鉴定通过 → 转发买家（三段式物流） |
| 运费策略 | 运费含在交易费中；卖家使用平台预付面单 |
| 退货方案 | 鉴定通过后不支持退货（All Sales Are Final） |
| 配送限制 | 支持国际配送 |

**模式**：鉴定中心中转；UPS 深度合作；不支持退货降低逆向物流成本。

---

### 2.7 eBay（参考）

| 维度 | 方案 |
|------|------|
| 承运商 | USPS、UPS、FedEx（卖家自选） |
| 物流追踪 | 多承运商追踪集成，平台内统一展示 |
| 运费策略 | 卖家自定义（免运费/固定/按重量） |
| 国际配送 | eBay International Shipping Program——卖家寄到国内中转仓，eBay 处理国际段 |
| 配送限制 | 支持 PO Box（USPS）；国际配送覆盖 60+ 国家 |

**模式**：高度灵活；国际配送中转模式值得参考。

## 三、竞品关键策略总结

| 平台 | 配送模式 | PO Box | 军事地址 | 国际配送 | 运费模式 |
|------|----------|--------|----------|----------|----------|
| The RealReal | 中心化仓储 | 不支持 | 不支持 | 不支持 | 买家付 |
| Vestiaire | 鉴定中心中转 | 不支持 | 不支持 | 支持 | 动态计算 |
| Poshmark | P2P 直发 | **支持** | 不明确 | 不支持 | 固定费率 |
| ThredUp | 中心化仓储 | 不支持 | 不支持 | 不支持 | 满额免 |
| Rebag | 中心化仓储 | 不支持 | 不支持 | 支持 | 会员免 |
| StockX | 鉴定中心中转 | 不支持 | 不支持 | 支持 | 含在交易费 |
| eBay | 卖家自选 | **支持** | 支持(USPS) | 支持 | 卖家定 |

**行业共识**：
- 使用 UPS/FedEx 的平台普遍**不支持 PO Box 和军事地址**
- 仅使用 USPS 的平台（Poshmark）才支持 PO Box
- 奢侈品平台因高货值 + 签收要求，倾向 UPS/FedEx

## 四、物流追踪/面单平台对比

| 功能 | AfterShip | EasyPost | Shippo |
|------|-----------|----------|--------|
| 定位 | 追踪为主 | 全链路 API | 全链路 API |
| 支持承运商 | 1,100+ | 100+ | 85+ |
| 面单生成 | 不支持 | 支持 | 支持 |
| 地址校验 | 有限 | 内置 | 内置 |
| 追踪能力 | 核心优势，品牌化追踪页 | 统一追踪 API | 统一追踪 API |
| 费率比价 | 不支持 | 实时多承运商比价 | 实时多承运商比价 |
| Webhook | 支持 | 支持 | 支持 |
| 适用场景 | 已有面单方案，需增强追踪 | 需要完整物流 API | 中小电商快速接入 |
| 定价 | 按追踪量计费 | 按面单量（有免费额度） | 按面单量 |

**Looply 初期选型建议**：

由于 Looply 初期是线下出单 + 后台录入运单号的模式，**不需要面单生成能力**，因此：
- **首选 AfterShip**：纯追踪场景最合适，自动识别承运商，Webhook 推送状态，免费档 50 单/月
- **备选 EasyPost**：如果后期需要自动出单，可一步到位

## 五、配送限制行业做法

### 5.1 PO Box 限制

| 事实 | 说明 |
|------|------|
| UPS/FedEx 不配送 PO Box | 仅 USPS 支持 PO Box 投递 |
| 奢侈品平台普遍不支持 | The RealReal、Rebag、StockX 均不支持 |
| 原因 | 高货值商品需要签收确认，PO Box 无法当面签收 |

### 5.2 军事地址（APO/FPO/DPO）

| 事实 | 说明 |
|------|------|
| 仅 USPS 配送军事地址 | UPS/FedEx 不支持 |
| 大多数奢侈品平台不支持 | 配送时效不可控（7-45天），丢件风险高 |
| Amazon 支持但有品类限制 | 部分品类（电池、液体等）不可寄 |

### 5.3 地址识别方式

| 地址类型 | 识别规则 |
|----------|----------|
| PO Box | 正则匹配：`PO Box`、`P.O. Box`、`Post Office Box`、`POB` |
| 军事地址 | State 字段为 `AA`/`AE`/`AP`，或 City 为 `APO`/`FPO`/`DPO` |
| 夏威夷/阿拉斯加 | State 字段为 `HI`/`AK` |
| 美国海外领地 | State 字段为 `GU`/`PR`/`VI`/`AS`/`MP` |

## 六、对 Looply 的设计建议

### 6.1 物流模式定位

Looply 采用**中心化仓储模式**（与 The RealReal、StockX 一致）：
- 卖家/供应商寄送商品到 Looply 仓库
- 仓库质检/鉴定后上架
- 买家下单后从仓库发货

这意味着：发货地点固定、包裹规格可控、承运商可统一管理。

### 6.2 初期配送限制建议

| 限制项 | 建议 | 理由 |
|--------|------|------|
| PO Box | **不支持** | 奢侈品需签收确认，行业惯例 |
| 军事地址 | **不支持** | 时效不可控，丢件风险高，行业惯例 |
| 夏威夷/阿拉斯加 | 支持，但预留附加费配置 | 初期免运费可先不加收 |
| 美国海外领地 | **不支持** | 物流复杂度高，初期不值得 |
| 国际配送 | **不支持** | Phase 1 仅美国 |

### 6.3 运费策略建议

初期免运费是正确策略（商品小、发货地可控、提升转化率）。后期可参考：
- Rebag 模式：会员免运费，非会员 $15-20
- ThredUp 模式：满额免运费（如满 $150 免运费）

### 6.4 物流追踪技术方案

```
初期流程：
运营线下出单 → 获取运单号 → 后台录入运单号
                                    ↓
                        调用 AfterShip API 创建 tracking
                                    ↓
                        AfterShip Webhook 推送状态变更
                                    ↓
                        Looply 更新订单物流状态 + 买家可查看轨迹
```

### 6.5 承运商建议

| 承运商 | 用途 | 理由 |
|--------|------|------|
| UPS Ground | 主力承运商 | 行业标配，签收可靠，追踪完善 |
| FedEx Ground | 备选 | 部分区域时效更优 |
| USPS | 暂不使用 | 不需要支持 PO Box，且奢侈品需签收 |

---

## 七、总结

Looply 初期物流管理模块应该是一个**极轻量的配置 + 追踪模块**：

1. **配送限制**：后台配置禁止 PO Box + 军事地址 + 海外领地，前端下单时校验
2. **物流追踪**：对接 AfterShip，运营录入运单号后自动追踪
3. **运费**：初期全免，后台预留运费模板配置能力
4. **承运商**：初期固定 UPS，后台预留承运商管理能力

这个方案与 The RealReal 早期模式高度一致，验证可行后再逐步扩展面单自动化、费率比价、国际配送等能力。
