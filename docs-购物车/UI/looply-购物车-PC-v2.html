购物车核心区域
1 Header 顶部导航栏 导航 ▾
Cart Icon 角标
右上角购物袋图标显示紫色圆形角标，数字为购物车内商品总数（含已售罄商品）。删除商品后实时更新。角标数字为 0 时隐藏角标。
导航链接
New Arrivals / Brands / Bags / Jewelry & Accessories / Electronics，点击跳转对应分类列表页。与商详页导航栏保持一致。
导航 Hover
鼠标悬停导航链接，文字颜色从 #1A1A1A → #6B7280，过渡 0.2s。
2 全选 & 商品列表 核心 ▾
Select All 全选
勾选"Select All"时，所有可选商品（非 Sold Out）的 checkbox 同步勾选；取消全选同步取消。已售罄商品的 checkbox 始终禁用，不受全选控制。
Checkbox 联动
单独取消某件商品勾选后，Select All 自动取消勾选。重新勾选所有可选商品后，Select All 自动恢复勾选。紫色 #6432FC 选中态，灰色 #D1D5DB 未选中态。
商品卡片布局
每件商品一行：Checkbox + 商品图（120×120，圆角 8px）+ 商品信息（品牌/名称/成色/价格/库存状态）+ 操作按钮（Remove / Save to Wishlist）。
卡片 Hover
鼠标悬停商品行时，背景色变为 #FAFAFA，添加圆角 8px，过渡 0.15s。已售罄商品不响应 Hover。
成色标签
四级成色，圆角胶囊标签：
· Like New：绿底 #ECFDF5 绿字 #059669
· Very Good：蓝底 #EFF6FF 蓝字 #2563EB
· Good：橙底 #FFF7ED 橙字 #EA580C
· Fair：红底 #FEF2F2 红字 #DC2626
价格展示
原价（删除线灰色 #9CA3AF）+ 现价（18px 加粗黑色）+ 节省金额（红色 #DC2626）。三者横向排列。
3 失效商品分组 & Sold Out 核心 ▾
失效商品归堆
已售罄（Sold Out）等失效商品从正常商品列表中拆出，归入底部独立分组 "Unavailable Items (N)"，与在售商品之间用分隔线隔开，视觉上明确区分。
一键清除
分组标题右侧 "Clear All" 按钮（红色文字 #DC2626），点击后一次性移除所有失效商品（带 0.3s 淡出动画）。清除后分组区域整体消失。
Sold Out 视觉
Sold Out 视觉
商品在购物车中被其他用户买走后进入 Sold Out 状态：
· 商品图添加半透明白色蒙层（60% 不透明度），图片中央叠加红色 "SOLD OUT" 标签（#DC2626 底色白字）
· 商品信息区和操作按钮降低透明度（50%）
· 库存状态行替换为红色提示 "This item is no longer available"
· Checkbox 禁用（灰底 #F3F4F6），不可勾选
Sold Out 计算规则
已售罄商品不计入 Order Summary（不算件数、不算金额）。页面标题 "Shopping Cart (N items)" 的 N 包含已售罄商品（展示购物车总量），但 Summary 的 Items 数只统计已勾选的在售商品。
Sold Out 商品操作
已售罄商品仍可执行 Remove（从购物车移除）和 Save to Wishlist（收藏，等待重新上架通知）。两个操作按钮虽降低透明度但仍可点击。
实时状态检测
进入购物车页面时调用接口批量检查所有商品库存状态。如发现有商品已售罄，页面顶部显示 Toast 提醒："Some items in your cart are no longer available"（3s 自动消失）。
4 商品操作 核心 ▾
Remove 删除
点击 Remove 按钮，商品行执行淡出 + 左移动画（opacity 0 + translateX -20px，0.3s ease），动画结束后 DOM 移除。移除后自动更新 Order Summary 和页面标题数字。
Remove Hover
鼠标悬停 Remove 按钮，文字 + 图标颜色从 #9CA3AF → #DC2626（红色警示）。
Save to Wishlist
点击后商品从购物车移至心愿单。成功后显示临时 Toast："Moved to Wishlist"（2s 消失）。商品行执行与 Remove 相同的退出动画。
Wishlist Hover
鼠标悬停 Save to Wishlist，文字 + 图标颜色从 #9CA3AF → #6432FC（品牌紫色）。
最后一件商品删除
购物车内所有商品被删除（或移至心愿单）后，切换到空购物车状态：空购物袋图标 + "Your cart is empty" + "Continue Shopping" 按钮（紫色 CTA），底部推荐区域保留可见。

5 Order Summary 订单摘要 核心 ▾
Sticky 定位
右侧 Summary 卡片采用 position: sticky; top: 88px，滚动时始终可见。圆角 12px，灰色背景 #FAFAFA，1px 边框。平板尺寸（≤1024px）时 Summary 变为单列布局，不再 sticky。
实时金额计算
每次勾选/取消商品时实时更新：
· Items (N)：已勾选商品件数
· Subtotal：已勾选商品现价之和
· Shipping：固定显示 "Free"（绿色 #059669）
· Total：等于 Subtotal（18px 加粗）
Checkout 按钮下方提示 "Free shipping. No extra sales tax added at checkout."
Checkout 按钮
点击跳转至 Checkout 页面，携带已勾选商品信息。按钮全宽紫色 #6432FC，Hover 时加深为 #5228D4。
按钮禁用态
当已勾选商品数为 0 时，Checkout 按钮变为灰色 #D1D5DB，cursor: default，点击无响应。重新勾选商品后自动恢复可用。
支付方式图标
底部展示支持的支付方式：VISA / MC / AMEX / PayPal / Klarna。纯展示，不可点击。白底灰框小卡片样式。
6 推荐区域 You May Also Like 信息 ▾
布局
标题居中 + 底部横线装饰。6 列商品卡片网格（平板 4 列，手机 2 列）。推荐算法基于购物车内商品的品类/品牌/价格区间。
卡片点击
点击商品卡片跳转至对应商品详情页（PDP）。用户可从 PDP 加购后返回购物车，购物车自动刷新。
卡片 Hover
鼠标悬停时卡片整体上移 2px（translateY），过渡 0.2s。心愿图标可独立点击收藏。
Add to Cart
每张卡片价格行下方展示 "Add to Cart" 按钮（描边样式 #1A1A1A，圆角 8px）。Hover 时反色填充（黑底白字）。点击后商品直接加入购物车，按钮短暂显示 ✓ 确认态（1s 后恢复），购物车列表顶部插入新商品并刷新结算信息。
7 空购物车状态 边界 ▾
空状态展示
购物车无商品时替换整个商品列表 + Summary 区域为居中空状态：
· 80px 灰色购物袋图标
· 标题 "Your cart is empty"（20px 加粗）
· 描述 "Looks like you haven't added any items yet."（14px 灰色）
· CTA "Continue Shopping"（紫色按钮，点击跳转首页）
推荐区域保留
空购物车状态下，底部 "You may also like" 推荐区域仍然展示，引导用户继续浏览。
8 Footer 页脚 导航 ▾
Newsletter 订阅
输入邮箱 + 点击 → 按钮提交。成功后输入框内文字替换为 "Subscribed ✓"（绿色），2 秒后恢复。邮箱格式校验失败时输入框抖动 + 红色边框提示。
社交媒体 & 导航
Facebook / Instagram / TikTok 图标点击跳转对应平台（新标签页）。About / Customer Service 栏内链接点击跳转对应页面。Hover 时颜色 #9CA3AF → #fff。
