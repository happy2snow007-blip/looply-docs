Gesture
State
Edge Case
1
Header Navigation
Nav ▼
Back Button
Tap < back arrow returns to previous page (PDP or Home). If cart was opened from tab bar, back goes to Home.
Title Count
Header shows "Cart (N)" where N = total items in cart (not just selected). Updates dynamically on remove.
2
Select All
Action ▼
Toggle
Tap checkbox toggles all items selected/deselected. Bottom bar total updates immediately.
Auto Sync
If user manually deselects one item, "Select All" unchecks automatically. If user selects all individually, it re-checks.
3
Cart Items
Core ▼
Item Tap
Tap item image or name navigates to PDP. Checkbox area is separate tap target.
Condition Badge
Each item shows condition: Like New (green), Very Good (blue), Good (orange). Badge is read-only, not tappable.
Price Display
Shows original price (strikethrough) + current price (bold) + discount percentage (red). No quantity selector — secondhand items are unique (qty=1).
Swipe Left to Reveal
Swipe item left reveals two action buttons: Save (purple, move to wishlist) and Delete (red, remove from cart). Standard iOS swipe-to-reveal pattern. Swipe threshold: 60px. Try it on the phone mockup.
Save Button
Tap purple "Save" button moves item to wishlist. Item remains in cart. Shows toast: "Saved to Wishlist". Panel auto-closes.
Delete Button
Tap red "Delete" button removes item with slide-out animation. Summary recalculates immediately.
Auto Close
Tapping anywhere else or swiping another item auto-closes the previously revealed action panel. Only one item's actions visible at a time.
4
Bottom Checkout Bar
Core ▼
Summary
Shows "N items selected" + total price of checked items. Updates in real-time as user toggles checkboxes.
Checkout Button
Tap "Checkout" navigates to Checkout page with selected items. Button is disabled (gray) when 0 items selected.
Login Gate
If user is not logged in, tapping Checkout redirects to Login page first, then returns to Checkout after auth.
5
Recommendations
Info ▼
Horizontal Scroll
Cards scroll horizontally. "See All" navigates to full recommendation list page.
Card Tap
Tap product card navigates to PDP. User can add to cart from PDP and return.
6
Empty Cart State
Edge ▼
Empty Display
When all items removed, cart shows: empty bag icon + "Your cart is empty" + "Continue Shopping" button. Bottom bar hides. Recommendations section still visible below.
