# Looply 色彩专题 PRD v0.1

## 一、色彩专题概述

本期建设单个 `The Color Archive` 色彩专题，覆盖 PC 与移动端。用户从首页对应活动入口进入专题，浏览色彩故事、材质介绍与穿搭内容，再浏览专题商品或进入完整集合。

专题链接采用可长期复用的 `/{语言地区}/journal/{主题标识}` 结构。本期英文专题地址定义为 `https://www.looply.com/en-US/journal/the-color-archive`，后续主题使用各自独立的主题标识。链接结构复用不扩大本期开发范围，Journal 栏目首页与通用专题模板不在本期范围内。

页面流转：

首页活动入口 → 色彩专题页 → `Shop All` → 完整专题商品集合（承接颜色筛选，见 2.3）。

Shop All 目标 Collection 地址（英文）：<https://www.looply.com/en-US/collections/the-color-archive>。

## 二、色彩专题页面

### 2.1 内容展示区

页面展示与布局分别参照 PC、移动端设计稿。专题图片及图文文案均以第四章引用的对应 UI 稿为内容基准，包括主题标题及介绍、品牌色彩故事、同色不同材质介绍、穿搭建议，以及商品区标题和副标题。商品卡中的实际商品信息仍来自运营集合及商品数据。

品牌故事、材质卡片和穿搭图文均为纯内容展示，不承载点击跳转。

### 2.2 Shop Color Edit 商品区

**商品来源与排序**

商品来自运营已配置的 `The Color Archive` 集合，沿用集合的运营排序。

PC 最多展示 8 件，移动端最多展示 6 件；不足上限时展示实际商品。售罄商品计入展示数量。

**收藏**

商品卡直接复用现有商品卡组件。游客可直接点击收藏入口完成收藏，无需先登录，适用于 PC 和移动端。

**颜色筛选**

颜色选项按 UI 稿展示，包括 `All`、`Red`、`Brown`、`Blue`、`Green`、`Pink`、`Black`。

移动端颜色栏单行横向滚动。可用颜色选项超出屏幕宽度时，用户可左滑查看更多颜色（包括后方的 `Pink`、`Black`），也可右滑返回前面的选项。PC 与移动端使用相同的颜色选项及下述有无商品判断规则；横向滑动仅改变颜色栏的可视范围，点击颜色后才执行筛选。

颜色匹配及集合页筛选回显复用《Collection Landing PRD v1.6》§2.10.1、§4.5.5 的 Color Dictionary，以 `color_code` 识别颜色，展示名称与色值读取对应的 `display_name`、`color_hex`。首次进入默认选中 `All`，表示整个专题集合。

点击颜色，在当前专题页内筛选商品区，上方图文内容保持不变。筛选后的商品保持集合中的相对顺序，并沿用本节的展示上限。

某颜色在整个专题集合中有商品时，展示该颜色入口；没有商品时隐藏。售罄商品计入该判断，因此某颜色全部售罄时仍保留入口。

用户已选中的颜色在后续刷新中变为无商品时，保留当前颜色筛选状态并展示商品空态；不自动切换到 `All`。该颜色入口在下一次可见的颜色选项刷新中按“没有商品时隐藏”处理。

**售罄处理**

商品售罄后保留原排序位置，显示 `Sold Out`，不由后续商品补位。该规则同时适用于专题页商品区及 `Shop All` 后的完整集合列表。

### 2.3 Shop All

点击 `Shop All`，进入已配置的完整专题商品集合，并承接专题页当前已选中的颜色：

- 已选中具体颜色：集合页 Filter 中自动选中对应颜色，商品列表按该颜色筛选。筛选范围为整个专题集合，不限于专题页预览的商品。
- 已选中 `All`：集合页不预选颜色条件，展示整个专题集合的商品。

上述规则同时适用于 PC 和移动端。

跳转失败时保留当前专题页，提示跳转失败并提供重试入口；重试进入第一章定义的完整集合，并承接本次跳转的颜色条件。

### 2.4 加载与异常状态

内容区与商品区分别处理加载和异常。商品区失败时，上方已加载的图文继续展示；只有页面框架、关键公共依赖或页面全部内容不可用时，使用整页错误态。

| 状态 | 展示与操作 | 恢复结果 |
|---|---|---|
| 首次加载 | 内容区展示骨架，颜色栏和商品卡同步展示骨架 | 各区域加载成功后展示对应内容；商品区成功后展示颜色栏和商品卡 |
| 内容区加载失败 | 仅在失败的内容区域展示公共错误提示和 `Retry`；已成功的图文区域及商品区继续展示 | `Retry` 仅重试失败内容区域，成功后恢复对应图文，不重置商品区筛选 |
| 商品为空 | 保留商品区标题和颜色栏容器，商品位置显示 `No items yet`；具体颜色入口仍按 2.2 的有无商品规则处理 | 后续取得商品结果后展示对应商品 |
| 当前颜色筛选后为空 | 保留当前颜色筛选状态，商品位置显示 `No items yet`；选中状态和颜色入口变化按 2.2 处理 | 用户可主动切换其他可用颜色或 `All` |
| 商品区首次加载失败 | 保留上方已加载图文，商品区显示错误提示和 `Retry` | 点击 `Retry` 重试商品区；成功后展示商品或对应空态 |
| 切换颜色失败 | 保留切换前的商品列表和原选中颜色，显示 `Couldn't load items. Try again.` 和 `Retry` | `Retry` 重试本次失败的目标颜色；成功后切换选中颜色及结果，结果为空时展示对应空态 |
| 商品图片加载失败 | 商品卡保留布局，图片位置使用统一图片失败占位，文字、价格和操作继续展示 | 图片恢复加载后展示商品图片 |
| 首页活动入口对应目标或专题页整体不可用 | 展示整页错误态，提供返回首页入口 | 点击返回首页进入首页 |

用户在颜色切换失败后主动选择另一颜色时，按新选择进行筛选；失败目标的重试入口随本次新选择结束，避免重试旧颜色覆盖新选择。

错误提示、重试入口及图片失败占位复用统一商品模块的文案与组件；本专题英文空态文案统一为 `No items yet`。

### 2.5 多语言

本期支持英语和西班牙语，专题图文、颜色名称、操作及状态提示按当前页面语言展示。正文列出的英文按钮、颜色名称和状态文案为英语版本，西班牙语展示对应译文。

译文缺失时，动态业务内容与静态 UI 文案分别沿用平台统一多语言兜底策略，本专题不另行定义兜底规则。

专题图文以 UI 稿为内容基准，需要接入多语言模块；商品信息使用对应语言的商品内容。两种语言共用同一专题商品范围、排序、数量上限及交互规则。

| 内容 | 多语言分类 |
|---|---|
| 专题标题、介绍、品牌故事、材质说明、穿搭建议、商品区标题及副标题 | 动态业务内容 |
| 颜色筛选名称 | 动态业务内容，复用 2.2 引用的 Color Dictionary 本地化展示名称 |
| All、Shop All、Sold Out、空态及错误提示、Retry、返回首页 | 静态 UI 文案 |
| 商品名称等商品内容 | 动态业务内容，归商品域 |
| 商品价格数值、商品标识、主题 URL 标识 | 不翻译 |

## 三、数据依赖

| 依赖 | 产品要求 |
|---|---|
| 运营专题集合 | 提供已选商品及其运营排序，作为专题商品范围和顺序依据 |
| 商品颜色 | 支持在整个集合范围判断颜色是否有商品，并筛选对应商品 |
| 商品在售状态 | 提供售罄状态，供 2.2 展示使用 |
| 首页活动入口 | 跳转至第一章定义的色彩专题地址 |
| 完整集合页面 | 接收 Shop All 传递的颜色条件，按 2.3 在 Filter 中回显并应用筛选；售罄规则见 2.2 |

## 五、数据与埋点

本期只新增色彩专题页面展示、颜色筛选点击和 `Shop All` 点击追踪，覆盖 PC、移动端、英语和西班牙语。首页专题入口、商品卡、收藏、重试、返回及其他公共操作沿用既有埋点覆盖，不在本专题新增埋点。事件语义、公共身份与页面上下文复用《Looply 数据采集与埋点产品需求 v1.9》第三至五章。

| 追踪位置／行为 | 复用事件 | 成立条件与专题业务信息 |
|---|---|---|
| 专题页面展示 | `page_view` | 按统一页面到达规则，在首次打开、刷新或有效路由进入专题时记录；关联专题标识、页面实例、来源、终端及当前语言 |
| 用户主动点击 All／颜色入口 | `ui_interaction` | 仅在用户主动点击可操作的 All 或具体颜色入口时记录，关联专题和点击的颜色／All；首次进入默认选中 All 不发送点击事件。点击事实与筛选请求成功与否分开，不以自动刷新代替点击 |
| Shop All 点击 | `ui_interaction` | 用户实际点击时记录，关联专题、目标完整集合及点击时的颜色筛选；记录的颜色与本次按 2.3 传递的筛选条件一致，All 表示不预选颜色 |

专题页面展示不代表用户已经看到页面底部商品区。颜色切换、组件重绘及商品请求重试不新增页面访问记录。相同操作已有公共组件事件时补齐专题来源，不重复发送一条同义事件。

专题稳定标识为 `the-color-archive`。本专题两项点击的唯一字段映射如下，事件均为 `ui_interaction`：

| 操作 | `module_id` | `interaction_name` | `action` | `element_id` | `target_id` |
|---|---|---|---|---|---|
| 用户主动点击 All／颜色入口 | `journal_color_edit` | `journal_color_filter` | `select` | `color_option` | 点击颜色的 `color_code`；All 为 `all` |
| Shop All 点击 | `journal_color_edit` | `journal_shop_all` | `select` | `shop_all_button` | 已配置的 The Color Archive 集合的实际 `collection_id` |

两项点击均关联专题标识 `the-color-archive`；Shop All 另关联点击时已选颜色的 `color_code`／`all`，与跳转传递的条件一致。颜色标识取自 2.2 的 Color Dictionary，不使用翻译后的标签；集合标识读取已配置集合的实际 ID，不以集合名称或 URL 代替。

验收时核对专题到达及两项点击的成立条件、稳定标识和关联信息；两端、两种语言使用相同业务标识，以终端和语言区分分析。
