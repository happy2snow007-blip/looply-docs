## 冻结结论

1. `page_location`表示事件发生时地址栏中的当前完整URL；`page_referrer`只表示当前页面实例建立前的真实上一页面。同页筛选、排序或Drawer开关不更新`page_referrer`。
2. `add_shipping_info`在同一`checkout_id`首次形成有效`shipping_tier`时成立，之后仅在有效tier变化时再次成立并递增`step_version`。地址变化但tier未变化不发送；本版本不要求`shipping_info_source`。
3. PC Favorites Drawer不形成新页面实例、不发送新`page_view`，曝光和点击沿用打开前当前页面的`page_instance_id`；Mobile Favorites按实际路由形成页面实例。
4. A01、A02必须完成Web事件对象、dataLayer、GTM Data Layer Variable、GA4 Event Tag、实际生产容器版本和真实`g/collect`请求的全链路验收；Web代码或公共函数测试不能单独判通过。
