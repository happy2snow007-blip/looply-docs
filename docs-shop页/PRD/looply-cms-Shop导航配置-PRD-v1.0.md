# Looply · CMS Shop 导航配置 PRD

**版本**：v1.0  
**日期**：2026-08-25  
**范围**：CMS > Shop页 > 导航配置

## 一、现有配置基线

本章承接《Looply Shop 页 PRD v7.1》原 `2.6 后台配置能力`，作为 Shop 导航后台配置的独立规则来源。

### 1.1 全局维度

Market、Channel、Terminal 三者组合确定一个独立配置空间。Shop 导航配置固定 `terminal=app`，Terminal 在后台只读展示。

| 维度 | 字段名 | 当前值 | 规则 |
|---|---|---|---|
| 市场 | `market_id` | `US` | 枚举来自 Market 模块 |
| 渠道 | `channel_id` | `chn_us_001` | 枚举来自商品中心渠道管理 |
| 终端 | `terminal` | `app` | 固定，不可切换 |

切换 Market 或 Channel 后，一级导航和二级/三级导航列表同步切换。

### 1.2 一级导航管理

**后台入口**：CMS > Shop页 > 导航配置。

| 字段 | 必填 | 规则 |
|---|---|---|
| `name` | 是 | 前台左侧一级导航名称 |
| `levels` | 是 | 两级或三级；创建时选择，保存后不可修改 |
| `enabled` | 是 | 默认启用；停用后前台不展示 |
| `order` | 自动 | 通过拖拽调整顺序 |
| `market_id` | 自动 | 继承当前全局维度 |
| `channel_id` | 自动 | 继承当前全局维度 |
| `terminal` | 自动 | 固定为 `app` |

同一 Market、Channel、Terminal 下一级导航名称不可重复，字母大小写不同视为同名。仅停用状态可以删除；删除一级导航时同时删除其全部二级和三级导航。

### 1.3 二级/三级导航管理

**后台入口**：CMS > Shop页 > 导航配置 > 点击一级导航名称。

- 两级模式：直接维护二级图文入口。
- 三级模式：先维护二级文字分组，再在分组下维护三级图文入口。

| 字段 | 必填 | 规则 |
|---|---|---|
| `name` | 是 | 二级分组或末级导航名称 |
| `image` | 条件必填 | 两级模式的二级导航、三级模式的三级导航必填；三级模式的二级分组不配置图片 |
| `targetType` | 条件必填 | 末级导航必填，可选 Collection 或自定义链接 |
| `collectionId` | 条件必填 | 目标类型为 Collection 时必填 |
| `targetUrl` | 条件必填 | Collection 自动生成且只读；自定义链接由运营填写 |
| `enabled` | 是 | 默认启用；停用后前台不展示 |
| `order` | 自动 | 仅在相同层级、相同父级内拖拽排序 |

三级模式的二级分组不配置图片和跳转目标。仅停用状态可以删除导航项；删除二级分组时同时删除其全部三级导航。

## 二、下个版本修改需求

本章为基于现有配置能力的增量修改；本章未涉及的规则保持不变。

### 2.1 一级导航增加展示样式

1. 一级导航新建、编辑表单增加「展示样式」。
2. 展示样式可选：
   - 方形图卡：现有样式。
   - 横向大图：新增样式。
3. 每个一级导航只能选择一种展示样式，其下所有末级导航统一使用该样式。
4. 两级和三级导航均支持两种展示样式，现有层级配置规则不变。

### 2.2 末级导航图片配置

1. 两级模式在二级导航配置图片；三级模式在三级导航配置图片。
2. 横向大图中央文案自动读取末级导航名称：两级读取二级导航名称，三级读取三级导航名称。
3. 不新增独立的图片文案字段。

### 2.3 图片上传提示

后台根据所属一级导航的展示样式，在图片上传区显示对应提示：

| 展示样式 | 上传区提示 |
|---|---|
| 方形图卡 | 建议上传 `130×130px（2×）` |
| 横向大图 | 建议上传 `476×186px（2×）` |

### 2.4 Shop 导航配置报错文案优化

#### 通用规则

1. 报错文案说明具体错误对象、原因和处理方式，不展示接口字段名、错误码或“上传结果缺少图片地址”等技术信息。
2. 字段校验错误显示在对应字段下；提交时自动定位到第一个错误字段。
3. 保存、上传、排序或状态切换失败后保留当前配置内容，不清空表单或重置列表。
4. 网络或系统异常使用页面级提示，并提供重试操作。

#### 文案要求

| 触发场景 | 修改后文案 |
|---|---|
| 一级导航名称为空 | `请输入一级导航名称` |
| 二级分组名称为空 | `请输入二级导航名称` |
| 末级导航名称为空 | 两级模式提示 `请输入二级导航名称`；三级模式提示 `请输入三级导航名称` |
| 未选择导航层级 | `请选择导航层级` |
| 未选择展示样式 | `请选择展示样式` |
| 方形图卡未上传图片 | `请上传方形图卡图片，建议尺寸为130×130px` |
| 横向大图未上传图片 | `请上传横向大图，建议尺寸为476×186px` |
| 图片格式不支持 | `图片格式不支持，请上传 JPG、PNG 或 WebP 图片` |
| 图片超过大小限制 | `图片大小不能超过{大小限制}` |
| 图片上传失败 | `图片上传失败，请重新上传` |
| 未选择目标类型 | `请选择目标类型` |
| 目标类型为 Collection，但未选择 Collection | `请选择关联的 Collection` |
| 自定义链接为空 | `请输入目标链接` |
| 自定义链接格式错误 | `目标链接格式不正确，请检查后重新输入` |
| 同级导航名称重复 | `当前层级已存在同名导航，请修改名称` |
| 启用状态下删除 | `请先停用该导航，再进行删除` |
| 保存失败 | `保存失败，请检查填写内容后重试` |
| 排序失败 | `排序保存失败，请重试` |
| 状态切换失败 | `状态更新失败，请重试` |
| 页面数据加载失败 | `导航配置加载失败，请重试` |

表格未单列的错误场景同样执行通用规则，不使用 `请先补全必填项`、`数据校验失败`、`操作失败，请重试`或直接透出服务端异常信息作为最终运营文案。
