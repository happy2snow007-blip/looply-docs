## 2. 页面整体结构

Shop 页分为三个区域，纵向排布：

```
┌─────────────────────────────────────────────────────┐
│                     TopBar                          │
├──────────────┬──────────────────────────────────────┤
│              │                                      │
│   左侧一级    │         右侧内容区                   │
│   导航       │   圆形列表 + You May Also Like        │
│  (108px)    │         (flex: 1)                    │
│              │                                      │
├──────────────┴──────────────────────────────────────┤
│                   底部 TabBar                        │
└─────────────────────────────────────────────────────┘
```

**TopBar**
- Logo「Looply」
- 搜索框（居中展开）
- 收藏图标（心形）
- 购物袋图标

**主体**
- 左侧一级导航：固定宽度 108px，可独立滚动
- 右侧内容区：`flex: 1`，可独立滚动

**底部 TabBar**
- Home
- Shop（当前页，激活态）
- Favourites
- Account

## 5. 数据模型

```typescript
interface NavItem {
  id:       string
  name:     string        // 前台显示名称
  image:    string | null // 导航项图标 URL（可选）
  enabled:  boolean
  order:    number
  circles:  Circle[]      // 该导航项下的圆形列表
}

interface Circle {
  id:           string
  name:         string       // 圆形显示名称
  image:        string | null // 圆形内图片 URL，null 时用 emoji + 彩色背景
  emoji:        string        // 无图时显示的 emoji
  color:        string        // 无图时的背景色
  enabled:      boolean
  order:        number
  collectionId: string        // 关联的 collection ID（来自商品后台）
}

// 来自商品后台，只读
interface Collection {
  id:   string
  name: string
  slug: string
}
```

## 6. 交互规则

| 操作 | 行为 |
|---|---|
| 点击左侧导航项 | 右侧内容切换到该导航项的圆形列表，左侧激活态更新 |
| 点击圆形 | 跳转至对应 collection 商品列表页（`/collection/:slug`） |
| 默认状态 | 进入 Shop 页默认选中第一个导航项 |
| 左侧导航滚动 | 独立滚动，不影响右侧内容区 |
| 右侧内容滚动 | 独立滚动，左侧导航保持不动 |

## 7. 后台配置能力需求

运营需通过后台配置 Shop 页的导航结构。配置分两层：

### 7.1 导航项层

| 能力 | 说明 |
|---|---|
| 新增导航项 | 填写名称、图标图片 |
| 删除导航项 | 同时删除其下所有圆形配置 |
| 排序 | 拖拽排序，决定左侧导航的展示顺序 |
| 启停 | 关闭后前台不展示该导航项 |
| 编辑名称/图标 | 随时可改 |

### 7.2 圆形层

| 能力 | 说明 |
|---|---|
| 新增圆形 | 在指定导航项下添加 |
| 删除圆形 | 从该导航项下移除 |
| 排序 | 拖拽排序，决定圆形在右侧的展示顺序 |
| 启停 | 关闭后前台该圆形不展示 |
| 编辑名称 | 圆形展示的文字 |
| 上传图片 | 圆形内图片 |
| 配置 emoji + 背景色 | 无图时的降级显示 |
| 关联 Collection | 从商品后台 Collection 库中搜索并选择，决定点击跳转目标 |

## 8. 边界情况

| 情况 | 处理方式 |
|---|---|
| 导航项下无圆形 | 右侧圆形区显示空态提示「暂无分类入口」 |
| 圆形图片加载失败 | 降级为彩色背景 + emoji |
| 关联的 Collection 被删除 | 后台提示「关联已断开」；前台该圆形隐藏（不展示） |
| 导航项全部禁用 | Shop 页主体区域显示空态 |
| Collection 库为空 | 后台圆形配置的关联选择器显示空态提示 |
