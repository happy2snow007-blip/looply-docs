# Looply V1.2 Shop 横向大图配置 PRD

版本：v1.0（开发交付版）  
日期：2026-09-24  
优先级：P0

## 1. 需求目标

为 Shop 导航增加横向大图卡片样式，并支持两级、三级导航下的末级导航图片配置、目标跳转和排序启停。

## 2. Shop 新增横向大图样式

### 2.1 用户端展示

1. 现有 Shop 图文卡片样式命名为「方形图卡」，展示规则保持不变。
2. Shop 右侧内容区新增「横向大图」样式。图片采用横版比例，商品卡片按单列自上而下排列。
3. 每个一级导航只使用一种展示样式，其下末级导航不混用方形图卡和横向大图。
4. 两级导航下，二级导航为末级导航；三级导航下，二级导航为分组标题，三级导航为末级导航。
5. 横向大图不叠加独立标题、说明或按钮文案；图片中的展示文字由运营按语言制作在图片内。末级导航名称仍作为导航结构字段保留，用于导航菜单和配置识别。
6. 点击横向大图后，按该末级导航配置的目标类型和目标值进入 Collection 或自定义 URL。
7. 横向大图前台展示尺寸为 `238×93px`。

### 2.2 运营后台配置

**修改位置**：CMS > Shop页 > 导航配置。

1. 一级导航新建、编辑表单增加「卡片样式」，可选「方形图卡」或「横向大图」。
2. 两级模式在二级导航配置图片；三级模式在三级导航配置图片。
3. 每个末级导航必须上传与所属一级导航展示样式对应的图片；缺少图片时不允许保存该末级导航。
4. 图片上传区根据所属一级导航的展示样式显示建议尺寸；本期不对 Shop 横向大图执行格式、尺寸或比例校验，不因图片规格不符合而拦截上传或保存。
5. 名称、目标类型、关联 Collection 或自定义 URL 沿用现有字段及校验规则；目标类型为 `Collection` 时只校验关联 Collection，目标类型为 `自定义 URL` 时只校验目标 URL。

| 卡片样式 | 上传区尺寸要求 |
|---|---|
| 方形图卡 | `130×130px（2×）` |
| 横向大图 | `476×186px（2×）` |

## 3. 开发边界

- 本期只定义 Shop 横向大图样式及其导航配置，不包含首页 Banner、PC 导航推荐图和国家化发布策略。
