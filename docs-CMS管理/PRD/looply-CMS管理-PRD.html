      Looply · CMS 后台 PRD v1.0

      版本：v1.0 | 日期：2026-06-17 | 范围：资源位管理 · 合集管理（待上线）· 全局配置（待上线）· 搜索配置（待上线）

      一、概述

      设计参考：looply-cms-antd-原型-v1.0.html — 整体概述 · 系统介绍

      1.1 背景与目标

      Looply 前台页面内容需要运营团队高频更新——坑位 Banner、合集入口等。CMS 的目标是让运营在不依赖开发的情况下完成内容日常管理。

      设计原则：

      • 骨架写死，内容放开：页面 Section 的上下顺序由产品硬编码，运营只配各 Section 内的内容，不能改页面结构
      • 低代码配置：选市场 → 选终端 → 选坑位 → 选模板 → 填参数，约束即表单
      • 预览上下文常驻：配置资源位时，右侧始终展示完整页面预览，当前编辑区高亮，其他区块灰显占位
      • 即时生效：上线后前台直接读取，无需开发部署

      1.2 本期不做

      全局配置Trust Bar / 导航链接 / Footer / Feed Tab，V2 启用，标注【待上线】
      搜索配置热门品牌 / 热搜词 / 搜索类目，V2 启用，标注【待上线】

      1.3 用户角色

      一期只有一种角色：运营，登录即有全部操作权限。

      1.4 核心操作场景

      1. 运营配置首页 Banner：资源位管理 → 市场选 US → 终端选 App → 坑位选 home_banner → 新建配置 → 选 banner_image 模板 → 上传图片 → 关联合集 → 上线
      2. 运营配置首页合集入口：资源位管理 → US / App → 坑位选 home_collection → 新建配置 → 选 collection_card_slide → 上传图片 → 关联合集 → 上线
      3. 运营调整配置展示顺序：进入坑位配置列表 → 点排序上/下按钮，同一坑位内配置在 C 端的展示位置随之变化

      二、模块一：资源位管理

      设计参考：looply-cms-antd-原型-v1.0.html — 资源位管理 — 首页 / Shop 页

      2.1 概念说明

      概念说明
      坑位（Zone）页面上固定的内容承载区，由产品定义，运营不可新建
      模板（Template）坑位支持的视觉样式，由开发实现，运营只选不建
      配置（Config）运营在某个坑位用某个模板填充的一条内容记录（原「实例」）。每条配置包含一个素材（一张图或一段视频）+ 关联一个合集

      核心逻辑：去掉 asset_item 层级。每条配置 = 一个素材 + 一个关联合集。同一坑位下可有多条配置，前台以横向平铺、支持左右滑动的方式展示所有上线配置。

      2.1.1 同坑位多配置排布

      同一坑位下多条上线配置，统一以横向平铺支持左右滑动方式展示：

      • 全幅类（banner_image / banner_video）：配置间自动轮播，切换间隔由系统固定（运营不可配），用户也可左右滑动
      • 卡片类（collection_card_slide / collection_card_small / collection_chip）：配置间横向排列，用户主动左右滑动，不自动轮播

      2.1.2 素材来源

      本期所有素材类型统一为本地上传，需满足各坑位规定的图片规格：

      素材类型支持来源格式要求
      图片（asset_image）仅本地上传JPG/PNG/WebP；分辨率要求见 §6.1
      视频（asset_video）仅本地上传MP4，建议 ≤ 20MB

      2.1.3 市场与终端维度

      运营进入坑位配置列表前，需先选定：

      1. 市场（Market）：目前仅 US，字段预留 market_id
      2. 终端（Terminal）：App（即 Mobile）/ PC

      同一 zone_key 在不同市场、不同终端下是独立的配置集合，字段结构完全一致。

      进入编辑页后，市场字段置灰不可修改。

      2.1.4 Landing 配置

      每条配置有唯一一个 Landing，自动从关联合集读取：

      字段来源展示方式
      landing_page关联合集的页面名称CMS 内展示页面名称，可点击
      landing_page_url关联合集的页面链接点击页面名称后跳转
      • 只有一种 Landing 类型，无 landing_fallback，无 shop_filter 选项
      • Landing 不可手动修改，跟随合集自动更新

      2.1.5 坑位清单（4 个）

      zone_key所属页面中文名配置上限
      home_banner首页首页 Banner4
      home_collection首页首页 Collection8
      shop_bannerShop 页Shop Banner4
      shop_collectionShop 页Shop Collection6

      2.1.6 模板清单（5 个）

      template_key中文名适用坑位MVP说明
      banner_imageBanner 大图home_banner, shop_bannerP0单素材图片，全幅展示
      banner_videoBanner 视频home_banner, shop_bannerP1单素材视频，全幅展示
      collection_card_slide合集滑动卡片home_collection, shop_collectionP0图片卡片 + 合集信息
      collection_chip文字芯片home_collection, shop_collectionP1文字 Chip，无图片
      collection_card_small小尺寸卡片home_collection, shop_collectionP1小卡片，图片+合集信息

      2.2 配置字段结构

      设计参考：looply-cms-antd-原型-v1.0.html — 新建/编辑配置页 — 表单字段

      所有配置模板共用以下统一字段结构（不再区分「实例层」和「asset_item 层」）：

      通用字段（所有模板）

      字段标签类型必填说明
      config_name模板名称text否运营内部标注，不对外展示
      market_id市场select是当前仅 US；进入编辑后置灰
      terminal终端select是App / PC；进入编辑后置灰
      zone_key坑位select是按市场+终端过滤；进入编辑后置灰
      template_key模板select/card是按 zone_key 过滤可用模板
      asset_image素材图片image图片模板必填仅本地上传；视频模板不显示
      asset_video素材视频video视频模板必填仅本地上传；图片模板不显示
      asset_poster封面帧imagebanner_video 必填视频加载前展示，仅本地上传
      title标题text否字符数限制待与设计/前端对齐
      subtitle副标题text否字符数限制待对齐；collection_chip 不显示
      cta_text按钮文案text否字符数限制待对齐；留空不渲染按钮
      text_color文字颜色select否light / dark；默认 light
      collection_id关联合集select是按 market_id 过滤；选后自动填充 landing_page / landing_page_url
      landing_page落地页名称readonly自动填充从关联合集读取，只读展示，可点击跳转
      landing_page_url落地页链接readonly自动填充从关联合集读取，通过点击 landing_page 跳转
      start_time生效开始时间datetime否空 = 立即生效（开关打开即生效）
      end_time生效结束时间datetime否空 = 永久有效

      字符数限制（title / subtitle / cta_text）均标注为"待与设计/前端对齐后给出最终数值"，当前原型仅作示意。

      collection_chip 特殊说明

      • 无 asset_image 字段（纯文字 Chip）
      • title 作为 Chip 显示文案
      • 无 subtitle、cta_text、text_color 字段

      2.3 配置状态

      设计参考：looply-cms-antd-原型-v1.0.html — 配置状态 Tag · 列表状态展示
      状态中文触发条件前台行为
      not_started未生效上线开关开，但 start_time 晚于当前时间前台不展示
      active生效中上线开关开，且当前时间在 start_time 与 end_time 之间前台展示
      paused已暂停上线开关关，且当前时间在 start_time 与 end_time 之间前台不展示，保留配置
      expired已失效当前时间大于 end_time前台不展示

      状态由上线开关 + 时间共同决定，不再有独立的「初始状态」字段。

      2.4 配置列表视图

      设计参考：looply-cms-antd-原型-v1.0.html — 资源位管理列表页 — 三级联动筛选 · 配置列表

      顶部筛选导航（三层级联）

      层级内容选择方式
      第一层：市场US（当前唯一）单选
      第二层：终端App / PC单选（Mobile 与 App 端一致，界面标注说明）
      第三层：坑位对应页面下所有坑位单选，必须选中一个坑位

      筛选后，下方展示所选坑位的配置列表（按坑位分组展示）。

      列表每行展示

      字段说明
      配置名称即 config_name，运营内部标注
      模板类型template_key 对应中文名
      状态当前状态 Tag（未生效 / 生效中 / 已暂停 / 已失效）
      预览素材缩略图，点击可放大到原尺寸

      每行操作

      操作说明显示条件
      上线/下线开关打开=上线，关闭=下线；与时间共同决定实际状态始终显示
      排序上↑点击，当前配置与上一条互换位置始终显示
      排序下↓点击，当前配置与下一条互换位置始终显示
      删除删除该配置，需二次确认弹窗（不可恢复）仅状态非「生效中」时显示；生效中配置在线上，不允许直接删除，需先下线
      编辑进入编辑页，市场/终端/坑位字段置灰不可修改始终显示，使用编辑图标（EditOutlined），排在操作列最后一位

      2.5 新建/编辑配置

      设计参考：looply-cms-antd-原型-v1.0.html — 新建配置页 · 编辑配置页

      页面流转

      资源位管理（首页/Shop页）
→ 顶部筛选（市场 + 终端 + 坑位）
→ 配置列表
→ 点击「新建配置」或编辑行
→ 编辑页（市场/终端/坑位 置灰）
→ 选模板 → 填参数（单屏，无分步）
→ 保存

      编辑页内容（单屏，不分步）

      区块 1 — 基本信息（置灰只读）

      • 市场、终端、坑位（进入前已选定，不可修改）

      区块 2 — 模板选择

      • 卡片网格，只展示该坑位允许的模板，含 P0/P1 标注
      • 切换模板弹出确认：「切换模板将清空已填参数，确认切换？」

      区块 3 — 素材与内容

      • 按模板类型显示对应字段（见 §2.2）
      • 图片上传：本地上传，规格要求见 §6.1
      • 关联合集（必填）：下拉选择，按 market_id 过滤；选择后自动填充 landing_page / landing_page_url
      • Landing 只读展示页面名称（不展示 URL）

      区块 4 — 生效时间

      • 生效开始时间（空 = 立即生效）
      • 生效结束时间（空 = 永久有效）

      校验规则

      • 关联合集必填，未填不可保存
      • 图片/视频类模板素材必填
      • 保存后上线开关默认关闭（即新建配置默认「已暂停」状态，需手动上线）

      六、公共交互规范

      设计参考：looply-cms-antd-原型-v1.0.html — 通用交互规范 · 上传 · 保存 · 确认弹窗

      6.1 素材上传规范

      坑位素材类型推荐规格格式
      home_banner / shop_banner图片750×400px（Mobile）JPG/PNG/WebP
      home_banner / shop_banner视频MP4，≤ 20MBMP4
      home_collection / shop_collection图片600×800px（3:4）JPG/PNG/WebP

      字符数限制（title/subtitle/cta_text）以及精确分辨率要求，待与设计、前端对齐后补充。

      上传失败提示：「Upload failed. Try again」

      6.2 保存与上线

      • 保存：存储配置，不影响线上
      • 上线：通过列表行的上线开关控制；上线开关打开且时间在有效范围内，前台即展示

      6.3 操作确认

      • 切换模板（清空已填参数）
      • 删除配置（不可恢复）

      6.4 空状态

      • 坑位无配置：首次使用引导态
      • 筛选无结果：无匹配态

      6.5 配置上限

      达到坑位配置上限时，新建按钮禁用，提示：「需先下线一个现有配置」
