# CMS 配置复制与定时上下线迭代 PRD

版本：v0.1｜更新：2026-11-25

## 1. 范围与页面改造边界

| 对象 | 本次新增 | 编辑页处理 |
|---|---|---|
| 首页 Banner、首页 Collection 配置 | 列表增加「复制」；支持定时上下线 | 在现有「上线状态」之后增加上线、下线两个时间字段 |
| 营销页面中的 Landing 模板 | 列表增加「复制」 | 复用现有新建编辑页，预填配置 |

仅 Landing 模板增加页面复制，图文专题保持原操作。首页 Collection 指首页展示配置，复制不会创建 Collection 本体。

以当前线上列表和编辑页为页面基线，保留现有布局、字段、组件、上线开关位置和保存行为。本次只增加上表入口及时间字段；原型仅表达业务逻辑，不作为重构线上页面的依据。

## 2. 首页 Banner / 首页 Collection：复制与定时上下线

### 2.1 复制首页配置

- 两个坑位列表均增加「复制」，打开预填内容的配置编辑页；保存生成独立记录，取消不新增。
- 复制当前市场、渠道、终端和坑位内该类型实际存在的素材、各语言图片、Alt、标题、副标题、颜色、按钮文案及跳转目标（关联合集或自定义 URL）；首页 Collection 继续关联原 Collection，不复制其商品。新记录追加到列表末尾，可拖拽调整顺序。
- 副本配置名称默认「原配置名称 - 副本」，可编辑，保存采用运营修改后的名称；重复复制依次使用「原配置名称 - 副本 2」「原配置名称 - 副本 3」。原名称为空时使用「未命名配置 - 副本」。素材文件名保持不变。
- 副本默认已暂停，上下线时间清空；修改副本不影响原配置。
- 通过列表现有「编辑」入口进入配置页设置排期，与内容一起保存。
- 保存副本时重新校验素材与所选跳转目标；源配置被删除或不可访问时提示无法复制，保留输入，不生成不完整记录。

### 2.2 时间设置

排期仅作用于当前市场、渠道、终端和坑位，同条配置的所有语言共用排期。

| 字段 | 规则 |
|---|---|
| 定时上线时间 | 选填；仅上线开关关闭时可设置；留空表示保持已暂停 |
| 定时下线时间 | 选填；上线开关打开，或已设置定时上线时间时可设置；留空表示上线后持续展示 |
| 时区 | 统一美东时间 ET（America/New_York），按目标日期适配 EST / EDT |

时间框未填写时：上线开关关闭显示「未设置」，本次打开开关显示「保存后上线」，原本生效中且保持上线显示「已上线」；可设置下线时间时，下线框显示「持续展示」。已设置时间显示具体时间。已暂停且未设置定时上线时，下线时间不可设置，提示「请先设置定时上线时间，或打开上线开关」。手动下线编辑态显示「保存后取消排期」。

时间须晚于当前时间；同时填写时，下线须晚于上线。每次排期只执行一次。清空上线时间时同步清空下线时间，保存后取消上下线安排并保持已暂停；清空下线时间并保存只取消下线安排，保留当前上线状态或未来上线安排。夏令时不存在的时间不可选，重复时刻需明确 EST / EDT。

### 2.3 状态与手动操作

- 列表开关先弹出「启用首页配置／停用首页配置」，点击「确认启用／确认停用」并提交成功后更新状态；取消不改变状态或排期。
- 内容、开关与排期统一在保存成功后生效；返回／取消不提交修改，保留原状态与原排期。
- 下表的手动操作结果及排期取消规则，均以对应提交成功为前提；失败保留原状态与原排期，编辑页保留输入并提示原因。
- 打开上线开关时清空未执行的定时上线时间，保留已填写的未来下线时间；关闭生效中配置的上线开关时清空上下线时间。已暂停配置设置定时上线时间时，上线开关保持关闭。

| 场景 / 操作 | 结果 |
|---|---|
| 保存未来上线时间 | 仍为已暂停，编辑页回显已保存的未来时间 |
| 到点成功上线 | 变为生效中，新增展示，不替换其他配置；清除已执行的上线安排，开关开启，上线框显示「已上线」，保留未来下线安排 |
| 到点成功下线 | 变为已暂停，保留配置；清除已执行的下线安排，开关关闭，下线框为空并沿用不可设置时的占位与提示 |
| 提前手动上线 | 提交成功后生效，取消未来上线任务，保留未来下线时间 |
| 手动下线 | 提交成功后下线，取消剩余上下线任务 |
| 生效中配置编辑排期 | 仅可设置、修改或清空未来下线时间 |
| 已暂停且未设置定时上线 | 保持已暂停；定时下线不可设置 |

状态只表示当前是否展示：生效中 / 已暂停；编辑页的时间字段保留尚未执行的安排。成功执行的时间不参与后续保存校验，修改名称或素材不会被该历史时间拦截，也不会重复触发旧任务。已暂停统计包含有未来上线安排的配置。删除前先清空并保存剩余排期；生效中需先下线。

### 2.4 校验与异常

- 编辑期间，配置的上线状态或排期被定时任务或其他运营修改时，阻止本次保存，提示「状态冲突，配置状态或排期已发生变化，请重新加载后编辑」。保留当前填写内容供查看，不覆盖最新配置；重新加载最新配置后方可再次编辑保存。
- 保存上线排期时校验素材、所选跳转目标和 Banner 全部启用语言图片；失败保留输入并提示原因。
- 同一市场、渠道、终端、坑位，按整个展示时段检查同时展示数量，不能超过该坑位实际配置上限。无下线时间按持续展示计入；无上线安排的暂停配置不占名额。
- 同时刻下线与上线不算重叠。编辑时以新时段替代原时段，不重复计数。
- 超限阻止保存，提示冲突时段（ET）、上限、预计数量与冲突配置，原配置和排期保持不变。手动上线、修改排期、清空下线时间也执行校验；并发保存不得绕过。
- 到点执行仍检查内容和容量；上线失败保持已暂停并显示原因，下线失败保留实际状态并显示原因。取消或替换的旧任务不再执行。
- 定时执行失败时，在编辑页对应时间字段下显示失败原因，失败时间作为只读提示保留，不作为新的待执行安排，也不自动再次触发。修改名称、素材等内容可正常保存，不因该失败时间已过期而拦截。运营可手动上下线或重新设置未来时间；对应手动操作成功或新排期保存成功后，清除该方向的失败时间与失败提示。仅修改内容或提交失败不清除提示。
- 保存失败、权限失效或记录不存在时提示原因，不显示保存成功；刷新失败不把旧状态当作执行成功。

## 3. Landing 页面复制

- 点击 Landing 记录的「复制」打开预填的新建编辑页，不创建记录、不生效。取消或返回不产生副本。
- 副本带入源页面当前保存生效的所属市场、模板类型、各语言及 PC/H5 图片、共用图片跳转链接、PC/H5 各自的品牌介绍标题、副标题、跳转文案及链接、保障展示选项。包含已保存但当前隐藏的配置，以及该页面已有的各语言文案；内容跳转链接按原值带入，保留查询参数和锚点。
- 「页面名称」和「关联 Collection」默认为空，由运营重新填写和选择。名称最多 100 个字符，支持英文字母、数字、空格和短横线，至少含一个英文字母。地址后缀不带入，系统去除新名称首尾空格、字母转小写、连续空格或短横线合并为一个短横线并去除首尾短横线，生成只读 `/landing/{后缀}`；后缀须有效且全局唯一，首次保存后固定。
- 源页面关联的投放短链及其 UTM 配置记录、页面地址、生效历史、页面标识不继承。副本首次保存成功后生成新标识、地址和第一条生效历史；需要投放链接时，在新页面单独创建。
- 副本配置及页面文案、译文归属新页面，后续编辑任一页面不影响另一页面；Collection 内容继续由重新选择的 Collection 提供。
- 保存时沿用当前 Landing 新建校验：名称必填、地址有效且唯一、Collection 同市场且生效；图片可整体留空，任一端或语言有图则须补齐 PC/H5 与全部启用语言；跳转链接接受 http/https 绝对地址或单斜杠开头的站内路径，去除首尾空格；有图时校验非空图片链接。各端品牌标题非空时，跳转文案与链接须同时为空或同时有效，跳转文案最多 60 字符；无图／空标题的隐藏跳转保留配置并免于对应校验。校验通过后点击「保存」创建副本并立即生效；失败时保留填写内容，不创建不完整记录。同一次保存重复提交或重试只生成一条副本及其首次生效历史。

## 4. 验收要点

- 首页两个坑位新增入口和时间字段一致；副本独立、命名递增、素材文件名不变、默认暂停且无排期；原 Collection 关联保留。
- 手动开关按列表确认／编辑保存成功生效；取消与失败不改变原状态和排期；执行成功清除对应安排，普通内容修改不重触发历史任务。
- 覆盖美东夏令时、同刻上下线、整个展示时段容量、取消／替换任务、状态冲突、执行失败提示及重新安排；前台按实际状态展示。
- 仅 Landing 有复制入口；复制全部端、语言与隐藏内容，保留共用图片链接及 PC/H5 各自品牌字段；名称、地址及 Collection 清空，预览不残留原 Collection 内容。
- Landing 取消无记录；保存后产生独立地址、首条历史且无原投放短链；配置与译文修改不影响原页；重复提交只创建一条，校验失败保留输入。
