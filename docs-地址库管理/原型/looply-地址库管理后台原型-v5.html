配送限制
管理配送限制规则。固定规则（PO Box / 军事地址）为系统内置，仅可选择启用或禁用；自定义规则可自由创建和编辑。
固定规则— 系统内置，不可编辑识别逻辑，仅可选择启用或禁用
PO Box 信箱地址
拦截收件地址中包含 PO Box（邮政信箱）的订单，此类地址无法接收实物包裹配送。
识别规则 /^\s*P\.?\s*O\.?\s*Box\s*\d+/i
国家：US · 全品类
军事地址 APO/FPO/DPO
拦截收件地址中包含军事地址标识（APO/FPO/DPO）的订单，此类地址需通过军事邮政系统，普通物流无法配送。
识别规则 /\b(APO|FPO|DPO)\b/i
国家：US · 全品类
