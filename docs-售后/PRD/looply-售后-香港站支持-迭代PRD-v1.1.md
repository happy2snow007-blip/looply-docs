## 2. 本次需求范围

- 售后服务：无代码改动。
- 售后数据模型：无字段新增或迁移。
- 售后前后台页面：无页面及交互改动。

- ER 图、流程图、原型、邮件模板：无需因香港站另行升级。

## 3. 香港站上线配合

售后模块只需纳入香港站上线联调和回归，确认现有能力在香港配置下正常运行。该工作属于上线验证，不形成新的售后开发需求。

建议最小回归场景：

1. 香港订单申请售后，站点为 HK、金额币种为 HKD。
2. 香港订单命中香港售后政策和香港退货地址。
3. 买家切换站点或修改资料后，已下订单和售后归属不变。
4. 香港订单退款仍按原币种、原渠道、原账户执行。
5. 美国订单继续按 US/USD 处理，不受香港站开放影响。
