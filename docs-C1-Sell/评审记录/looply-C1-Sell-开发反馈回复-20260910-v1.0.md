## 二、逐项回复

### 1. 运营在哪里看数据？

本期只建设一方采集并写入自建数据平台，不新增运营后台报表页面。运营通过数据平台既有查询能力获取数据；本期应支持按时间、C1 页面/步骤、来源、端类型、语言、Market、售卖方式、服务区域结果等维度查询，以回答需求规模、预约漏斗、售卖方式和服务区域四类问题。

数据平台的具体查询界面、SQL/语义层、权限与看板实现由数据团队确定，不属于本 PRD 的页面需求。

### 2. 最终 UI 以什么为准？

以 Figma《1.1-C1业务》为最终 UI 基线，开发按实际呈现的控件和状态对照 Excel。预约流程节点 `3:6738` 已进行需求核对；其余页面和状态尚未完成全量 UI 对照，不得因为文档已有点位就视为 UI 覆盖已验收。

若最终 UI 出现未列出的稳定业务操作，开发在联调前补齐对应 `element_id`、字典行和验收用例；若控件未实际呈现，则从实现覆盖率分母剔除。PC 与 Mobile 复用相同业务事件和统计口径，只有控件确实不同才使用不同 `element_id`。

### 3. C2 公共规范无法取得，如何处理？

已提供《C1 Sell：C2 公共埋点规范引用入口 v1.1》，其中列出 C2 公共实施规则、公共字段 Excel、详细点位 Excel 的原始文件入口和校验信息。C1 不重新设计身份、Session、来源或页面上下文；开发直接复用公共采集层。

但已发现 C2 v1.8 与 v1.9 对 Session 续期、身份扩展字段及部分事件命名存在冲突。该冲突不能由 C1 产品或 C1 开发自行选定。请数据平台确认实际运行的公共基线、SDK/机器契约位置和脱敏样例；确认前可完成 C1 业务点位接入准备，但不新增或改写公共身份和 Session 逻辑。

### 4. PRD 与 Excel 字典不一致，如何处理？

已修订为 PRD v1.2 与 Excel v1.0：

- Excel 的“详细点位”“交互字典”“枚举与验收”承担逐点执行定义；
- PRD 给出事件边界、同源字典索引、业务口径和验收原则；
- 同一 `point_id + variant_id` 的 `interaction_name / action / element_id / page_id / module_id` 必须成组匹配，不可按单一事件名自由拼接；
- 原有点位 ID 均保留，新增场景仅通过 `variant_id` 区分，`variant_id` 是文档定位键，不新增公共上报字段。

本次校验结果：58 个点位 ID、64 行场景定义、45 行交互映射；PRD 与 Excel 的对应组合已逐行核对。全量最终 UI 的实现对照仍是联调前置项。

### 5. 前台提交尝试与后台预约创建是否必须关联？

本期不需要逐条关联，也不要求新增提交尝试 ID。

- 前台提交成功率：以提交接口的明确返回结果为准，用于衡量用户预约流程的接口成功/失败；
- 后台预约创建量：以独立的 `seller_request_created` 事实为准，按唯一 `request_id` 去重；
- 这两个指标分别统计，前者不替代后者，后者也不反推某一次前台提交。

重复提交、Retry 不应重复创建预约，属于业务幂等规则；一方采集记录重复提交拦截和接口结果，后台事实按 `request_id` 去重即可验证预约量不被重复放大。

### 6. GA4 配置和验收由谁负责？

产品已在 PRD 定义：哪些业务事件进入 GA4、参数白名单、隐私禁止项、`business_domain=c1` 的 C1 分析口径、关键事件，以及“可在 GA4 查询到”的业务验收结果。

接入方式、GA4 资源配置、参数注册、调试工具和部署路径由技术团队按现有全站 GA4 方案确定。开发交付时需提供实际可查询的验证结果，证明：C1 可按指定维度分析六类事件；仅接口成功的预约提交为关键事件；GA4 不含受禁止的敏感或业务主键字段；GA4 异常不影响业务提交或一方采集。

### 7. PRD 与 Excel 的版本号不同、是否需要哈希？

版本号不要求相同：PRD 和 Excel 是不同类型的制品，各自独立迭代。本批以文件名和发布清单锁定实际开发输入：PRD v1.2、Excel v1.0、C2 引用附件 v1.1、开发反馈回复 v1.0。

文件 SHA-256 仅用于发布批次的完整性核对，避免取得同名但内容不同的文件；它不是产品业务字段、埋点参数或开发逻辑。若开发/发布流程需要，可据发布清单核对文件哈希。

## 三、仍需技术确认的事项

1. 数据平台确认 C2 当前实际公共基线及 C2 → C1 → C2 的脱敏联调方式；
2. 开发按最终 Figma 完成全部页面、状态和 PC/Mobile 控件对照；
3. 按 PRD 的产品验收结果验证现有全站 GA4 接入是否可支持 C1 查询。

除以上技术确认外，本期产品范围已明确；新增字段、事件或产品页面需求需先回写点位字典和验收用例。
