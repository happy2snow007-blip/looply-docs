## v1.1 详细修订（2026-08-05）

### 拍板决策（D1–D4）

| 代号 | 决策 | 连带影响 |
|---|---|---|
| **D1** | 整单未签收的运营侧代建单缺口 → **本需求不承载**，归售后模块由产品单独排期（`售后/待优化清单.md` 第 38 条 · 38.2）。本 PRD 只在 §三 风险 3 声明为**已知敞口** | 曾评估两个落点（①对售后域提硬性要求 ②放进本期 C 端需求一起做），**产品当日均否决**：不动已交付的 V1.0、也不让 C 端需求背运营端改动。**上线后整单未签收的售后诉求只能走线下客服**，属已接受的过渡状态 |
