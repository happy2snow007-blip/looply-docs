# Looply 营销页面配置与图文专题模板 PRD v0.2

## 一、范围与页面结构

入口统一为「CMS 配置 → 营销页面配置」，管理 Landing 模板和图文专题模板创建的页面。新建时先选择模板，再进入对应配置页；已有页面编辑时直接进入其模板，创建后模板固定。两类已有页面保留原地址。

Landing 模板沿用已有 Landing 配置规则；本文第三至六章定义图文专题模板（Featured Pages），覆盖 PC 和 H5，两端分别配置。

后台页面流转：营销页面列表 → 选择模板 → 新建配置 → 返回列表；营销页面列表 → 编辑已有页面 → 返回列表。配置页采用左侧分区表单、右侧预览；顶部提供「返回列表」，表单底部提供「取消」「保存」。

图文专题模板的 C 端主体顺序为：顶部 Banner → 章节导航 → 引导文案 → 图文商品模块 → 底部引导。网站 Header、Footer 复用网站公共组件。礼物专题的四个主题和商品仅为内容示例，不固化为配置字段或组数。

## 二、营销页面列表与基本信息

### 2.1 营销页面列表

列表页沿用 Landing 页配置的卡片布局、筛选区、表格样式与分页位置；在此基础上保留国家和模板类型筛选，以及模板类型列。

| 区域 | 内容与操作 |
|---|---|
| 筛选 | 所属国家默认 All；模板类型默认全部，可选 Landing 模板、图文专题模板；页面名称支持关键词查询；三项可组合查询 |
| 查询与重置 | 点击查询应用条件；重置将国家恢复 All、模板类型恢复全部，并清空关键词 |
| 列表 | 所属国家、页面名称、模板类型、页面地址、操作；分页展示 |
| 页面地址 | 地址末尾紧邻复制图标，点击复制完整地址并提示结果 |
| 行操作 | 与 Landing 页配置一致，依次展示编辑、投放链接、生效历史；编辑按页面模板打开已有配置 |
| 新建入口 | 新建营销页面，先选择 Landing 模板或图文专题模板；模板卡片仅展示页面结构、适用场景和「使用此模板」入口，选择后进入对应配置表单 |
| 无匹配结果 | 展示空态，保留筛选与新建入口 |

### 2.2 图文专题模板基本信息与地址

| 字段 | 录入与规则 |
|---|---|
| 所属国家 | 选择专题所属国家；用于列表归属与筛选 |
| 页面名称（英文） | 必填，最多 100 个字符；用于后台识别专题，并自动生成地址后缀 |
| 页面地址 | 域名后固定为 `/features/{专题标识}`，不含语言和国家；只读，提供复制图标 |

新建时随英文名称生成并展示地址后缀预览。名称转小写，连续非英文字母、非数字字符转为一个连字符，并去除首尾连字符。首次保存成功后固定专题标识及地址；此后修改名称或国家不改变地址。已有投放短链的专题禁止修改所属国家，前端提示原因、服务端保存时再次校验；无投放短链时可修改国家，并按 §3.4 重新校验 Collection。

空名称、不能生成有效后缀或地址与已有专题重复时，提示原因并阻止保存。路径不包含国家，因此地址在专题之间保持唯一。

示例：`https://www.sand.looply.com/features/gift-guide`。实际域名使用对应环境的网站域名。

### 2.3 投放链接与生效历史

Landing 与图文专题短链均只关联一个营销页面；同时提交两类页面关联时拒绝。创建、查看和修改均校验操作者当前国家与页面所属国家一致。关联页面、国家、基础目标和已创建短码固定；编辑仅允许修改备注与 UTM。服务端按已关联页面生成目标，不接受通用编辑入口改写目标或关联。历史 Landing 短链继续保留原关联、短码和访问地址。

两类模板沿用[《营销承接页 PRD v0.3》](../../docs-Landing页配置/PRD/looply-marketing-landing-PRD-v0.3.md) §2.7–2.8 的同一套后续页面、记录和交互。统一入口继续读取原 Landing 已有短链和历史记录；图文专题按同一数据结构新增记录，不另建数据源。

| 入口 | 页面与交互 |
|---|---|
| 投放链接 | 进入当前营销页面的短链列表；可生成投放链接，配置自定义短码、备注和 UTM 参数；已有短链支持复制、编辑、删除和查看效果 |
| 生效历史 | 进入当前营销页面的版本列表，展示版本、状态、生效时间和操作人；点击查看配置后，在当前页展开该版本的生效配置快照 |

## 三、配置与展示

### 3.1 共用规则

每组包含稳定 UUID。服务端校验 ID 必填、UUID 格式和同一终端内唯一，错误时返回终端、组位置和原因并保留表单。编辑与配置顺序变化保留 ID；新增或复制内容生成新 ID。复制仅指数据复制规则，不新增运营复制按钮。

服务端返回组 ID 和配置顺序；前端完成图文与商品可用性判断后，按最终可见组顺序统一生成连续编号、PC 左右交替和章节导航。商品加载失败、为空或恢复后重新计算；锚点始终使用组 ID。

新建时默认展示顶部 Banner、引导文案、一组图文商品、底部引导的配置区域。章节导航由图文模块自动生成。

各内容模块均选填；整块没有内容时允许保存，C 端不展示且不保留空白占位。模块卡片提供收起／展开，仅改变后台表单的展开状态，不改变前台是否展示。

图文商品模块的图片、标题、副标题、正文和 Collection 可部分填写：图片、任一文案或 Collection 至少有一项时展示该组，并只展示实际配置的内容区域；仅关联 Collection 时直接展示商品区域，不生成空的图文头部。无标题的展示组不生成章节导航项，但仍计入正文展示顺序，后续组的正文编号按全部实际展示组连续生成。

PC／H5 分别维护模块图片、文案、Collection、链接和配色；切换终端保留两端未保存内容。图文商品支持追加一组及删除指定组，新组追加在末尾，各组按配置顺序展示。

### 3.2 顶部 Banner

| 配置项 | 规则 |
|---|---|
| 图片 | 按 PC／H5 分开，当前端按语言分别上传；语言标识与上传区域逐项展示 |
| 跳转链接 | 选填；同一端的语言图片共用此链接，替换或移除图片不清空链接 |

Banner 使用整图，图片中包含文案、装饰和按钮视觉；范围为网站 Header 下方至章节导航上方。已配置图片时展示；已配置链接时点击整图进入对应目标。

Banner 和底部按钮链接均去除首尾空格，仅支持 `http://`、`https://` 或以单个 `/` 开头的站内路径；有效目标在新标签页打开。Banner 没有图片时保留已填写链接但不触发校验和点击，重新上传图片后恢复校验。

### 3.3 引导文案

| 配置项 | 规则 |
|---|---|
| Icon | 上传装饰图片，对应 UI 中红色蝴蝶结；PC／H5 分别配置，同一端共用各语言 |
| 标题 | 展示在 Icon 下方 |
| 正文 | 展示在标题下方 |

按 UI 居中排布，Icon 未填写时不显示图标。

### 3.4 图文商品模块

| 配置项 | 规则 |
|---|---|
| 图片 | PC／H5 分别配置，同一端各语言共用一张图片 |
| 标题 | 模块名称，同时作为章节导航名称 |
| 副标题 | 标题下方的短说明 |
| 正文 | 主题说明 |
| 关联 Collection | 选填；选择已有 Collection，作为商品来源和标题的跳转目标 |

未填写 Collection（缺省、null 或空字符串）统一为未关联，仅对已填写值校验正整数 ID、同一国家及已生效状态；非法关联阻止本次保存并提示对应终端与组。不能直接复用要求 Collection 必填的 Landing 校验。只有图文、刚新增空组、PC／H5 内容均为空都允许保存，基本信息仍须有效。

Collection 下拉仅返回页面所属国家下已生效的 Collection。修改所属国家时，系统重新校验 PC、H5 各组的关联值，并清空不属于新国家或已失效的 Collection；Collection 为选填项，清空后可按纯图文模块继续保存，也可重新选择。Collection 后续商品、价格、库存或顺序变化时，访客新访问或刷新后读取最新数据，无需重新保存专题。

专题所属市场由后台配置的「所属国家」唯一确定，页面地址不携带国家或语言。首次加载按专题记录读取该市场；专题不存在、无权限或基础配置加载失败时不进入编辑态，并提示返回列表重试，不展示空白配置表单。

标题与紧邻标题的小右箭头进入关联 Collection，不配置独立标题链接。未关联 Collection 时仅展示已配置图片和文案，标题不跳转，不显示商品行及集合末尾入口；有标题时仍生成章节导航。

关联 Collection 被停用、为空、加载失败或没有可展示商品时，保留该组已配置的图片和文案，标题文字不可点击，并隐藏标题旁的 Collection 跳转箭头、商品行及 View All 入口；仅配置 Collection 的组在该状态下整组隐藏且不保留空白。Collection 恢复可用后自动恢复上述入口和商品展示，无需重新保存专题配置。

商品范围和排序沿用所关联 Collection；专题内不单独选品或排序。商品卡读取真实商品信息、价格、库存和售罄状态，点击商品进入对应商详。

PC、H5 每组最多展示 20 件商品，按关联 Collection 的顺序取前 20 件。可展示商品不超过 20 件时展示全部；超过 20 件时，在第 20 件之后追加一张 View All 入口卡。入口卡不占商品数量，进入同一 Collection；卡片上的数量显示该集合的实际商品总数。

PC 点击左右箭头时，按当前商品容器一屏的宽度移动；接近末尾时，实际移动距离以剩余内容为限，最后一张卡片右侧贴齐容器右边缘，末屏可与上一屏重复展示部分商品，不因整屏步长在右侧留空。向左移动同样以列表起点为边界。到达首尾后，对应方向不能继续移动。商品总量不足一屏时按实际数量展示，不复制商品补位；内容未溢出时无需翻页。

PC 按图文模块的展示次序交替左右布局：第 1 组图片在左，第 2 组图片在右，依次交替；商品行位于图文下方，通过左右按钮横向浏览。H5 各组均为图片、文案、横向商品行的上下结构，商品可横向滑动。标题箭头、编号、商品卡与末尾入口的视觉使用第七章对应 UI。

### 3.5 章节导航

读取当前端有标题的图文商品模块，按实际展示顺序生成导航项；导航文案复用模块标题及其译文，编号与对应正文模块编号保持一致，点击定位到对应图文模块。模块增删或标题变化时同步更新。无标题的图文模块不生成导航项；没有导航项时整条导航不展示。

PC 导航按 UI 横向排列；H5 内容超出宽度时支持横向浏览。

### 3.6 底部引导

| 配置项 | 规则 |
|---|---|
| Eyebrow text（上方小字） | 底部引导上方的小号文案 |
| Title（下方大字） | 小字下方的主要标题 |
| 按钮文字 | 按钮显示文案 |
| 跳转链接 | 按钮的目标地址 |
| 文案颜色 | 底部引导文案使用的颜色 |
| 背景色 | 底部引导区域的背景色 |
| 按钮文字颜色 | 独立设置按钮文字及箭头颜色 |
| 按钮背景色 | 按钮填充色 |

PC 为左侧文案、右侧按钮，H5 为文案在上、按钮在下。四个颜色合并在「配色」区域横向展示，点击色块选择颜色或输入 HEX 色值。

Eyebrow text、Title 和配色可独立填写。按钮文字与跳转链接成对配置：两项均为空时允许保存且不展示按钮；填写按钮时，两项均须填写，且链接须符合公共链接校验规则，否则提示补齐或修正后再保存。

### 3.7 图片规格

所有图片上传支持 PNG、JPG、WebP、GIF。首期不校验像素宽高，也不设置文件大小上限；下表尺寸仅作为制作建议。图片可上传、替换和移除；读取或上传失败时提示原因并保留原图及其他已填写内容。格式与当前端建议尺寸在模块内统一提示一次，不在各语言上传区域重复提示。

| 图片用途 | PC 建议尺寸 | H5 建议尺寸 | 语言维度 |
|---|---|---|---|
| 顶部 Banner | 1440 × 561 px | 375 × 280 px | 分语言上传 |
| 图文商品图片 | 600 × 300 px | 343 × 172 px | 各语言共用 |
| 引导 Icon | 展示尺寸 27 × 19 px | 展示尺寸 31 × 22 px | 各语言共用 |

Icon 建议使用透明背景图片。

## 四、预览与保存

### 4.1 实时预览与示意效果

右侧提供「实时预览／示意效果」切换，在同一区域展示。

| 模式 | 内容与交互 |
|---|---|
| 实时预览 | 读取正在编辑的终端配置；修改图片、文案、Collection、增删图文组和配色后更新效果；无独立语言切换 |
| 示意效果 | 展示第七章的完整 UI 示例，标注顶部 Banner、章节导航、引导文案、图文商品、底部引导；提供独立 PC／H5 切换 |

切换预览模式或示意终端不修改表单内容。实时预览采用对应终端模板，PC 按页面比例缩放，H5 使用移动端布局，预览区域可滚动查看完整内容。字体、间距、图片比例、商品卡和排版按 UI 还原，不因后台预览容器宽度切换 C 端布局。

### 4.2 保存与返回

点击保存提交基本信息及 PC／H5 全部配置，保存成功后直接发布，当前表单变为已保存状态。编辑过程只影响预览。

保存失败时提示原因、保留编辑内容供重试，线上继续使用上一次成功保存的配置。基本信息与地址校验见 2.2，模块选填规则见 3.1，底部按钮成对校验见 3.6。

保存沿用[《营销承接页 PRD v0.3》](../../docs-Landing页配置/PRD/looply-marketing-landing-PRD-v0.3.md) §2.8：配置与生效历史作为一次提交共同成功；失败或重试不新增重复版本；检测到其他人已保存新版本时阻止覆盖并提示刷新；无权限或记录不存在时阻止提交。单个图文商品模块的数据加载失败仅降级该模块，其他已成功模块继续展示；该模块按公共列表重试机制重新请求，恢复成功后原位展示。

点击顶部「返回列表」或底部「取消」时，无未保存修改则返回列表；存在未保存修改则提示离开将丢失修改，可选择继续编辑或离开。

## 五、多语言与数据依赖

### 5.1 内容归属

配置页直接录入源文案；模块头部不提供多语言编辑入口。

专题动态文案新建翻译资源 `resourceType=marketing_featured_page`，归属 `domain=marketing`、`domainName=营销页面`，翻译中心路径为「CMS／营销页面／图文专题」。资源身份使用稳定专题标识、终端和稳定图文组 ID，不使用排序编号。源语言为英语，目标语言读取所属国家的语言配置；字段映射如下：

| 业务对象 | resourceId | fieldName |
|---|---|---|
| 引导文案 | `{topicId}:{device}:intro` | `title`、`body` |
| 图文商品组 | `{topicId}:{device}:group:{groupId}` | `title`、`subtitle`、`body` |
| 底部引导 | `{topicId}:{device}:footer` | `eyebrow`、`title`、`button_label` |

目标语言动态文案缺失时回退对应英语源文案；当前端、当前语言未配置 Banner 图片时隐藏 Banner。实时预览固定展示英语源文案和英语 Banner，其他语言 Banner 在对应上传区域检查。翻译资源注册、迁移和平台接入属于开发依赖，不代表现有平台已完成配置。

| 内容 | 归属与展示来源 |
|---|---|
| 引导标题、正文；图文标题、副标题、正文；底部 Eyebrow text、Title、按钮文字 | 动态业务内容，进入统一多语言管理，C 端按页面语言展示 |
| 章节导航 | 复用对应模块标题及译文 |
| Banner 图片 | 按终端和语言读取运营上传的图片 |
| 图文图片、引导 Icon | 按终端读取，各语言共用 |
| 商品文案 | 读取商品域对应语言内容 |
| 后台固定标签、提示；商品行末尾固定入口文案 | 静态 UI 文案，使用文案包 |
| 后台页面名称、专题标识、Collection 标识、地址、链接、颜色 | 不翻译 |

### 5.2 依赖边界

| 来源 | 本模块依赖的内容 |
|---|---|
| 国家配置 | 所属国家可选项及专题市场上下文 |
| 专题配置 | 页面基本信息、双端模块内容、关联关系、Banner 语言图片 |
| Collection | 可选择的已有集合、商品范围与顺序、集合实际数量与跳转目标 |
| 商品域／公共商品卡 | 商品展示字段、价格、库存与售罄状态、收藏及商品跳转；收藏点击复用[《Looply 首页 PRD v1.10》](../../docs-首页/PRD/looply-首页-PRD-v1.10.md) §8.2 的公共商品卡行为并阻止冒泡到商详 |
| 多语言管理 | 专题动态文案的译文与语言上下文 |
| 网站公共组件 | Header、Footer 及公共页面行为 |

## 六、数据与埋点

### 6.1 采集范围与上下文

PC／H5 正式专题页覆盖游客和登录用户。后台配置、实时预览和示意效果不计入 C 端访问、曝光与点击数据。

事件携带专题稳定标识、终端、市场／国家、页面语言，以及公共身份、Session、页面实例上下文。模块行为增加稳定模块标识和实际展示位置；图文商品行为增加 Collection；商品行为增加商品标识和组内位置。标题与译文不能代替稳定标识，同一 Collection 或商品出现在不同模块时可区分来源。

身份、Session、页面实例和公共字段沿用[《Looply 一方埋点公共实施规则 v1.8》](../../docs-数据采集与埋点/一方平台开发基线/looply-一方埋点公共实施规则-v1.8.md) §3.1／§4／§5，动作与枚举沿用其 §3.4／§5.3；GA4 商品列表与点击沿用[《Looply GA4 数据分析 PRD v1.10》](../../docs-数据采集与埋点/GA4开发基线/looply-GA4数据分析-PRD-v1.10.md) §3.3／§3.5.2 及当前生产代码中的 `looply_ga4_view_item_list → view_item_list`、`looply_ga4_select_item → select_item` 映射；广告列表沿用 `looply_ads_view_item_list`。开发联调以本 PRD 评审基线对应的代码版本为准，并在提测记录中写明 commit。本章定义专题新增参数和触发条件，不把一方 `item_impression` 与 GA4 `view_item_list` 视为改名前后关系。

沿用现有事件、SDK、上报链路和 GA4，在现有埋点契约中新增专题页上下文类型。公共字段及枚举保持原有含义，专题与组标识使用专用业务字段，不拼入 `content_id`，不按每个专题或组新增公共枚举。字段路径及上下文类型名称由技术方案映射到现有契约。

| 上下文 | 必须表达的信息 | 适用事件 |
|---|---|---|
| 页面级 | 稳定专题 ID、实际展示的配置版本、终端 PC／H5；国家和语言复用公共字段 | 专题页产生的全部事件 |
| 组级 | 稳定组 ID、实际展示位置；已关联时携带 Collection ID | 章节导航、图文标题、View All、组内商品列表、商品曝光和点击 |

页面访问、顶部 Banner、底部按钮不携带组 ID。各组事件携带独立的来源快照，后注册或更新的组不能覆盖其他组。列表实例、曝光去重与点击归因在现有规则基础上增加专题 ID、终端和组 ID；同商品或同 Collection 在不同组分别统计，同一组重复渲染仍按公共规则去重。

| 点击元素 | target_id |
|---|---|
| 章节导航 | 被定位的稳定组 ID |
| 图文标题、View All | 关联 Collection ID |
| Banner、底部按钮 | 目标链接去除查询参数和 fragment 后的地址；站内路径按当前站点补全域名 |
| 商品卡 | 商品 ID，沿用现有商品点击契约 |

本期包含埋点契约、SDK、一方上报、GA4 映射及广告来源链路对专题上下文的必要适配和联调。各平台按自身契约映射来源字段，广告目录使用的商品标识保持不变。商品点击的专题、组和终端来源须沿现有加购、订单归因链路传递，归因优先级和窗口沿用公共规则；不使用页面上最后注册的组替代真实点击来源。

### 6.2 触发矩阵

| 行为 | 事件与触发要求 |
|---|---|
| 访问专题页 | 一方 `page_view`；GA4 使用自动 `page_view`，不补发手动 PV。真实进入可访问专题页时成立；章节锚点定位不新增页面访问 |
| 点击 Banner | 一方 `ui_interaction`：存在有效跳转目标且用户真实点击；记录 Banner 模块与目标 |
| 点击章节导航 | 一方 `ui_interaction`：记录所选稳定图文组 ID；程序定位与滚动高亮变化不算点击 |
| 商品列表加载展示 | 广告 `looply_ads_view_item_list` 在列表 ready 且非空时发送；GA4 通过 `looply_ga4_view_item_list` 发送 `view_item_list`，仅在该组新非空结果首次展示时发送，横向滚动和相同结果重复渲染不重发；两条链路分别记录专题、稳定图文组 ID、Collection 和实际商品列表 |
| 单件商品有效曝光 | 一方 `item_impression`：单件至少 50% 可视，页面可见且窗口有焦点，连续保持 1 秒；在公共页面实例、展示位和商品去重基础上增加稳定图文组 ID，同商品跨组独立判断 |
| 点击商品卡 | 一方 `item_click`；GA4 通过 `looply_ga4_select_item` 发送 `select_item`；记录专题、稳定图文组 ID、Collection、商品位置及可用的前序曝光关联 |
| 点击图文标题／商品行末尾入口 | 一方 `ui_interaction`：区分两个入口，目标均为有效关联 Collection；无可用目标不记录跳转点击 |
| 点击底部按钮 | 一方 `ui_interaction`：存在有效跳转目标且真实点击，记录底部模块与目标 |

商品请求失败或没有商品时不记录列表展示与单商品曝光。一次真实点击仅记录一次，标题文字、箭头与父容器不重复计数。点击成立不依赖目标页加载成功；到达 Collection 或商详后，由目标页记录访问与详情事件，并保留来源专题、模块及前序点击关联。

### 6.3 验收重点

| 验收场景 | 预期 |
|---|---|
| 同商品、同 Collection 出现在两个组 | 两组分别形成列表实例与有效曝光；点击归属实际来源组，后注册组不覆盖前组 |
| 同组重复渲染、横向滚动 | 按公共规则去重，不因重复渲染重复上报 |
| PC／H5 切换或分别访问 | 终端字段正确，列表实例、去重与来源关联不串端；真实曝光才计数 |
| 页面访问、Banner、底部按钮 | 携带页面上下文，组 ID 为空 |
| 章节导航、标题、View All | 目标分别为组 ID、Collection ID、Collection ID；章节定位不新增页面访问 |
| 从组内商品点击后加购和购买 | 沿公共归因规则保留实际专题、组、终端及前序点击关联 |
| 空数据、请求失败、不可点击内容 | 不产生相应曝光或跳转点击；目标页失败不撤销真实点击 |
| 游客、登录用户与各平台联调 | 公共身份规则保持一致，一方／GA4／广告映射可核对，商品目录标识不变 |
| 后台预览、示意效果及其他页面回归 | 预览不产生正式数据；首页、Landing、Collection 原有字段含义和行为保持一致 |

验收同时覆盖：纯图文与双端空内容保存；Collection 非法、跨国家或未生效拒绝；空 Collection 组隐藏及恢复后的连续编号和布局重算；短链双关联、跨国家创建／查看、改目标拒绝及历史 Landing 兼容；组 UUID 缺失、非法、同端重复拒绝，编辑保留 ID、新增生成新 ID。
