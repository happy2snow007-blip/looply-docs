# Looply About 页面竞品调研 v0.1

- 调研日期：2026-08-05
- 调研对象：Rebag、FASHIONPHILE、The RealReal
- 调研范围：官网 About / Our Story 与独立 Authentication 页面
- 使用方式：为 About Looply Web Demo v0.2 提供信息结构与视觉节奏参考

## 一、实际观察

### Rebag

- 页面：<https://www.rebag.com/about-us/>
- 首屏使用全宽商品生活方式图片，品牌名称与一句话定位叠加在图片中央。
- 首屏后先介绍平台与成立背景，再进入差异化能力、卖家服务及业务入口。
- 页面末端分别承接购物与出售转化，商业导向较强。

### FASHIONPHILE

- 页面：<https://www.fashionphile.com/pages/about>
- 首屏使用全宽品牌图片和极短标题 “Our Story”。
- 正文以品牌故事开场，随后用编号承诺解释真实性、服务和价值观。
- 鉴定承诺在 About 页中出现，但详细流程通过独立页面展开：<https://www.fashionphile.com/pages/authenticity>。

### The RealReal

- 页面：<https://www.therealreal.com/about>
- About 入口与 Team、Press、Authenticity 等内容分开，品牌介绍页不承担全部信任证明。
- 独立鉴定页按人员、工具、数据和用户价值拆解复杂证据：<https://www.therealreal.com/authentication>。

## 二、共同模式

1. 用大幅品牌或商品图片建立第一印象，首屏只承载品牌名称、主张或一句话定位。
2. 品牌故事和用户承诺分层表达，不把所有信息压在首屏。
3. 价值观或差异点通常用编号、卡片或分段列表，提高长页扫描效率。
4. 鉴定是核心信任信息，但复杂流程与证明材料通常进入独立 Authentication 页面。
5. 页面末端保留少量明确 CTA，避免同时出现过多方向。

## 三、是否适合 Looply

适合。Looply 当前文案本身已经形成“品牌主张 → Who we are → What We Believe → What You'll Find → Authentication”的完整叙事，可直接映射到竞品共同使用的编辑式长页结构。

主要约束：Looply 当前最终文案较长，若全部居中或连续大段展示，移动端阅读压力较高；需要依靠图文交替、宽窄节奏和编号列表拆分，而不能删改已确认英文内容。

## 四、Demo 采用方案

1. 首屏：全宽编辑图片，叠加 `Authenticated Luxury Resale` 与 Slogan。
2. Who we are：桌面端左右图文，移动端上下排列，完整保留五段英文。
3. What We Believe：三列编辑卡片，移动端改为纵向列表。
4. What You'll Find：五条编号清单，避免做成首页式卖点卡片。
5. Authentication：深色信任模块，以工艺细节图承接完整论据，只保留一个鉴定页 CTA。
6. 不新增购物 CTA，避免超出本次最终文案和页面任务。

## 五、证据缺口与边界

- 本地未找到带明确版本号或更新时间、且可确认是当前最新的 About Looply UI 稿。本 Demo 属于基于最终文案和现有 Looply Web 原型风格制作的概念版，不宣称已与最新 UI 稿视觉对齐。
- Demo 中鉴定数字、AI 能力及 Lifetime Authenticity Guarantee 按用户指定最终文案原样展示；本次调研未验证这些对外口径的证明材料和适用范围。
- Demo 图片来自 Pexels 免费素材，仅用于内部原型；正式上线需替换为已取得品牌授权的 Looply 视觉资产。
