### R01：多语言只有分类，没有足以实现和验收的映射与缺译结果

- **位置**：品牌 PRD 第 137 行（§7 多语言）；Checklist 第 98、110 行；历史 About v0.3 第 183—209 行；项目背景第十六节。
- **场景与影响**：用户在当前西语页面进入新增 Group 或 Sustainability，开发知道正文要进翻译资源，但不知道复用哪张卡片、哪些字段对应哪些展示面、使用哪些目标语种，以及某段译文缺失时呈现英文、留空还是整页回退。旧 `brand_about_page` 的五条体验清单等字段对应旧模块，不能直接代表新三页。固定 UI 也没有明确引用可识别的文案标识集合。
- **建议**：按三页模块补充资源映射或引用已有权威映射，明确业务对象、复用／新建、resourceType、字段与展示面、源／目标语言、缺译兜底，以及静态 UI 的标识归属。表中只写字段与用途，英文正文继续由 Figma 维护。
- **确认性质**：资源是否已注册及字段可否复用交由接入负责人核对；如果目标语种与兜底已有公共确认，直接引用。只有查不到有效公共规则时，才需要产品决定实际用户结果。**不需要逐句文案再确认。**
- **反例检查**：英文用户可正常阅读不代表西语缺译场景闭合；登录状态不改变该缺口。

### R02：品牌三页入口已确定，公共 Footer 仍保留“不接入 About”的当前规则

- **位置**：品牌 PRD 第 25、27 行；`docs/product/looply-Footer-PRD-v0.3.md` 第 11、27、63、220 行及入口表；文档中心对应 Footer v0.3 亦有旧规则。
- **场景与影响**：品牌页开发按新 PRD 接入三页入口，公共 Footer 开发按 v0.3 将 About 视为需求未确认且本期不接入；同一次开发交付会得到两套入口范围，Our Group 与 Sustainability 也尚未进入公共入口表。
- **建议**：以本轮已确认的三页入口同步 Footer 范围、入口表及接入清单，品牌 PRD 引用同步后的公共版本；生产路由按已明确语义目标登记。不要让开发自行从新旧文档判断哪份生效。
- **确认性质**：纯文档同步，不再询问是否保留三页入口。未要求顺带改动 Authenticity、订阅或其他 Footer 能力。
- **分级依据**：有效产品方向已明确，故不因新旧稿冲突机械升级为 P0；但共同交付前应修正，避免遗漏公共入口。

### R03：SBTi、CDP 和 LEED 的打开方式未形成完整验收答案

- **位置**：品牌 PRD 第 29、101、104、124—127、146 行；Demo Sustainability 第 639、647、655、686 行。
