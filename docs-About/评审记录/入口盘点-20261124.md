# 品牌三页入口盘点

日期：2026-11-24。范围：本地三页 Demo 的实际链接、此前读取的 Figma 六画板快照、Footer PRD v0.2、导航栏配置 PRD v1.12、统一埋点需求 v2.1。属于入口盘点，不是正式模拟评审或线上埋点验收。

## 已发现入口

| 来源位置 | 目标 | 埋点覆盖 | 区分方式 |
|---|---|---|---|
| PC 公共 Footer / About Looply | About | 已定义 | footer / footer_navigation / footer_link / about |
| PC 公共 Footer / Our Group | Our Group | 已定义 | footer / footer_navigation / footer_link / our_group |
| PC 公共 Footer / Sustainability | Sustainability | 已定义 | footer / footer_navigation / footer_link / sustainability |
| About / Our Story 集团入口 | Our Group | 已定义 | about_group_link |
| About / 品牌理念入口 | Sustainability | 已定义 | about_sustainability_link |
| Group / Sustainability 图文入口 | Sustainability | 已定义 | group_sustainability_link |
| Group / 底部 About 卡 | About | 已定义 | group_about_link |

前三种是公共入口类型，并非每个承载页面新建一套点位。三页 Demo 每页都有这三项 Footer 链接，共九个实例；加四处正文互跳，共十三个实际站内链接实例。事件的发生页 page_id/page_instance_id 区分用户从哪个页面的 Footer 进入，target_id 区分进入哪一页。正文互跳与 Footer 即使目标相同，仍由 module_id 和 element_id 区分。

## 已核对但未发现的入口

- 三页 Demo Header、Mobile 底部导航没有指向这三页的链接。
- 所读取 Figma PC 顶部导航未展示三页入口；Mobile 使用返回栏，未画出 Footer。不能据 Demo 公共壳推断 Mobile 正式稿有 Footer。
- 导航栏配置 PRD v1.12 未检出 About / Our Group / Sustainability 的命名入口。
- docs/product 与 prototypes 的文本检索发现其他命中主要为历史 About、Footer 和 Privacy Choices 原型，不作为新增当前入口。历史 Footer PRD 只有 About，未包含两张新品牌页；当前三页入口依据是用户指定 Figma。

以上“未发现”仅限已检查制品，不能证明生产站或未提供的移动端个人中心不存在其他入口。

## 非站内点击来源

直接访问、书签、搜索引擎或外部链接进入三页，由公共 page_view 记录到达，使用公共来源信息；没有站内点击时不补造 footer_navigation。来源可能被浏览器隐藏，不能承诺所有外部访问均可精确识别。

## 结论与缺口

已发现的七类入口均有需求定义，没有发现这七类中的漏点；这不等于代码已接入或数据已落库。

生产站全量入口、运营配置中的动态 Banner、未提供的个人中心/菜单画板，以及广告/邮件素材不在此次可核对资料中，未完成覆盖验证。需要在接入验收时对生产页面与配置补查，不凭通用导航规则宣称所有入口均覆盖。

## 补充盘点：Mobile 两个已确认入口

用户于 2026-11-24 指出首页推荐 Feed 和个人中心 Banner 均有 About 入口。上文七类清单遗漏了这两类，应修正为至少九类。两处来源依据是用户明确确认，尚未取得这两个来源页面的当前 UI 截图或运行态证据，不包装成视觉实测。

统一采集 §8.7 已补入 home_feed_about_link 与 account_banner_about_link，发生页分别使用来源页面，目标均为 about。不能用首页顶部 home_banner 规则代替 Feed 内入口，也不能只靠 About 到达事件区分来源。PRD 入口说明同步补齐。

补查当前 Marketing Landing PRD v0.4：主图／Slogan 为可配置链接，配置到 About 时形成条件性入口，已由 landing_navigation 及 landing_hero_link／landing_slogan_link 采集；target_id 按来源契约使用清洗后的目标路径，不强改为 about。当前未读取生效配置，不能认定始终存在固定 Meet Looply 入口。
