## B 类:系统健壮性

**B1 逆向链路**:

| 实体 | 操作 | 下游 | 策略 | 章节 |
|---|---|---|---|---|
| 活动 | 暂停/结束 | C 端展示/试算 | 联动:即时停止生效,恢复原价 | 2.1-4/2.4 |
| 活动 | 结束/删除 | 已产生核销与订单快照 | 保留:不受影响 | 2.2.5 |
| 活动 | 进行中编辑 | C 端价格 | 提示确认+试算拦截+监控增量扫描 | 2.2.2/2.3.4 |
| 商品 | 售出/下架 | 圈选命中 | 联动:动态判定暂不可享,回可售恢复(圈选不删) | 2.8-2 |
| 商品 | 原价变更 | 划线价/降幅 | 联动:触发监控增量扫描 | 三章商品域声明 |
| 优惠码 | 活动暂停/结束 | checkout 校验 | 拦截:码判无效 | 2.6 |
