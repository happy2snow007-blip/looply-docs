1
Header
Nav ▼
Back
Tap Back arrow returns to previous page (PDP or category list). Cart state is preserved.
Title Count
"Cart (N)" where N = total items in cart (including sold-out items). Updates in real-time when items are added or removed.
2
Select All
Core ▼
Select All Toggle
Tap checkbox toggles all available items (non-sold-out). Sold-out items are always disabled. Purple #6432FC when checked.
Auto Sync
If user unchecks any single item, Select All auto-unchecks. When all available items are individually re-checked, Select All auto-checks.
3
Cart Items
Core ▼
Item Layout
Each item: Checkbox + Product image (90×90, rounded 8px) + Info (brand / name / condition badge / price) + × remove button (top-right of info area). Two-line name truncation.
Remove Button
Each item has a × icon at the top-right corner of the info area (16px, gray #9ca3af, tap highlight red #dc2626). Tap removes the item with 0.3s slide-out animation. Provides a direct remove entry without requiring swipe gesture.
Condition Badge
Capsule badge with 3 levels in APP:
· Like New: green #ecfdf5 / #059669
· Very Good: blue #eff6ff / #2563eb
· Good: orange #fff7ed / #ea580c
Price Row
Original price (strikethrough gray) + current price (16px bold) + saved amount "Save $X" (red #dc2626). Consistent with PC format.
失效商品分组
Unavailable Grouping
Sold-out items are separated from available items into a bottom section "Unavailable (N)", visually divided by a 6px gray separator.
Clear All
"Clear All" button (red #dc2626) on the right of the section header. Tap removes all unavailable items at once (0.3s fade-out animation). Section disappears after clearing.
Sold Out 视觉
Sold Out Visual
When another buyer purchases the item while it's in this user's cart:
· Product image: white overlay (60% opacity) + centered red "SOLD OUT" badge (#dc2626 bg, white text)
· Item info area: opacity reduced to 50%
· Stock status line replaced with red "No longer available"
· Checkbox disabled (gray #f3f4f6 background)
Sold Out Calculation
Sold-out items are excluded from bottom bar total (not counted in "N items selected", not included in price). Header "Cart (N)" still includes them in total count.
Sold Out Swipe
Sold-out items still support left-swipe to reveal Save/Delete actions. User can save to wishlist (get notified if restocked) or delete from cart.
Real-time Detection
On page load, API checks stock status for all cart items. If any sold out, a brief Toast notification appears at top: "Some items are no longer available" (3s auto-dismiss).
4
Swipe Actions
Action ▼
Left Swipe
Swipe item left to reveal two action buttons (total 144px): purple "Save" (move to wishlist, #6432FC) + red "Delete" (remove from cart, #dc2626). Threshold: 60px to trigger full reveal.
Auto Close
Tapping anywhere else or swiping another item auto-closes the previously revealed action panel. Only one item's actions visible at a time.
Save Action
Tap "Save" moves item to wishlist. Item exits with slide-out animation (0.3s). Brief Toast: "Moved to Wishlist" (2s). For sold-out items, wishlist entry enables restock notification.
Delete Action
Tap "Delete" removes item. Exit animation: opacity 0 + height collapse (0.4s). Updates bottom bar totals and header count. If last item removed, shows empty cart state.
5
Bottom Checkout Bar
Core ▼
Summary
Shows "N items selected" + total price (equal to subtotal, no tax) of checked available items. Updates in real-time as user toggles checkboxes. Sold-out items excluded. Above the bar: "Free shipping. No extra sales tax added at checkout." note.
Checkout Button
Tap "Checkout" navigates to Checkout page with selected items. Button is disabled (gray #d1d5db) when 0 items selected.
Login Gate
If user is not logged in, tapping Checkout redirects to Login page first, then returns to Checkout after auth.
6
Recommendations
Info ▼
Horizontal Scroll
Cards scroll horizontally. "See All" navigates to full recommendation list page. Algorithm based on cart items' category/brand/price range.
Card Tap
Tap product card navigates to PDP. User can add to cart from PDP and return. Cart auto-refreshes on return.
Add to Cart
Each card has an "Add to Cart" button below the price (outlined style #1a1a1a, rounded 6px). Tap adds item directly to cart; button briefly shows ✓ confirmation (1s then resets). Cart list inserts the new item at top and refreshes checkout summary.
7
Empty Cart State
Edge ▼
Empty Display
When all items removed, cart shows: empty bag icon + "Your cart is empty" + "Continue Shopping" button. Bottom bar hides. Select All bar hides. Recommendations section still visible below.
