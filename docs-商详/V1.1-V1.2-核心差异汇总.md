## 3. 新增功能（本次增量 = 多语言接入）

多语言按三类内容接入，均基于多语言模块 v3.2 的建卡 + 页面聚合 + storage_mode 能力：

### 3.1 第一类：静态 UI 文案（语言包 + 后台可查改）
- 商详页固定 UI 文案由前端语言包实现（storage_mode=`language_pack`）
- 多语言后台额外提供查看/修改面，保存后同步回语言包（同步机制由技术方案定）
- 作为聚合组成员 `page-pdp`（"页面文案"分组）登记

### 3.2 第二类：CMS 配置内容翻译接入（商详页自建自维）
- **新建 4 张翻译卡片**，统一归入"商详页"聚合组（group_code=`pdp`）：

  | resource_type | 字段 | 粒度 | storage_mode |
  |---------------|------|------|--------------|
  | `pdp_certified_authentic` | ca_title / ca_desc / ca_detail | 模板级 | translation_table |
  | `pdp_condition_grade` | grade_name / grade_description | 模板 × 等级 | translation_table |
  | `pdp_condition_display` | display_name | 类目 × 字段 | translation_table |
  | `pdp_description_display` | display_name | 类目 × 属性 | translation_table |

- **接入顺序（硬前置）**：先建卡（migration，写 resource_type + display_name + domain=前端页面 + group_code=pdp + key_type=entity_field + storage_mode）→ 声明聚合组 resource_group=pdp（5 成员 + sort_order）→ 注册 translatable_field_config 字段 → CMS 保存时写入翻译服务触发 AI 翻译
- **未建卡则源文写入被拒绝**（防游离译文）
- 写入时机、参数、异常处理见 PRD §2.2.2

### 3.3 第三类：业务模块内容（商详页只读取）
- 商品标题/描述、品牌名、类目名、属性名/值、质检文本、成色等级 grade 值等，由**商品系统**接入（商品域卡片），商详页只调用翻译服务读取
- 商详页不建卡不写入；resourceType 以商品模块实际建卡为准（联调阶段核对，见风险）

### 3.4 "商详页"聚合组
- group_code=`pdp`，domain=前端页面，5 成员（1 静态文案 + 4 CMS 动态）
- 数据层 5 张独立卡片；多语言后台展示层聚合为**一张聚合卡 + 5 分组子导航**（对应多语言原型 v13）

### 3.5 Fallback / RTL / 术语表
- Fallback 引用多语言 §4.6：有译文→过期译文→英文源文本
- RTL 布局（`language.rtl=true` 镜像布局，前端 CSS `dir="rtl"`）
- 品牌名禁译词由术语表控制，上线前批量导入核心品牌名

## 5. 开发关注重点

1. **多语言 v3.2 三项能力是硬前置**：建卡（migration + 域元数据）、页面聚合（resource_group）、storage_mode 须先于商详多语言上线；未就绪则商详多语言顺延。
2. **CMS 上线 checklist**：4 张卡建卡 → 聚合组 pdp 声明（5 成员 + sort_order）→ 字段注册 → 逐项验证 `(resourceType, resourceId, fieldName)` 可写入/可查得译文。遗漏则保存被拒。
3. **第二类 CMS 保存 = 写入翻译服务触发翻译**：新建/编辑/删除各操作的写入行为见 PRD §2.2.2 写入时机表；翻译服务不可用时异步重试、不阻塞 CMS 保存。
4. **第三类 resourceType 待商品模块对齐**：商品域卡片标识固化后核对 PRD §2.2.1，不得靠名称相似推断。
5. **CMS 原型沿用 V1.1，本期不改**：鉴定认证/成色等级/成色展示名编辑入口**已定不补**"保存后自动翻译"提示（2026-07-23 拍板），CMS 原型保持现状，译文自动生成由 PRD §2.2 说明（属性展示名原型已有提示，保持不动）。
6. **grade 与成色等级体系是两套独立内容**：grade 值（商品域 enum，商详只读）驱动当前等级徽章；成色等级体系（CMS `pdp_condition_grade`）驱动进度条 + Condition Guide。互不打通、各自接入，不存在二选一。
