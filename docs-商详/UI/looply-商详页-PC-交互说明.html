1 Header 顶部导航栏 导航 ▾
Logo
点击跳转首页。Logo 使用品牌图片（logo-new.png），高度 28px。
导航链接
点击跳转对应品类列表页（New Arrivals / Brands / Bags / Jewelry / Electronics）。本期跳转规则写死，默认跳转 www.looply.com。
导航链接 Hover
文字颜色从 #1A1A1A 过渡到 #6B7280（0.2s transition）。
Language 选择器
点击弹出下拉菜单切换语言。当前展示当前语言名称（如 "English ▾"）。默认语言 = 当前 Market 的默认语言，语言列表根据 Market 配置动态获取。切换后整站内容翻译为目标语言。
Currency 选择器
点击弹出下拉菜单切换货币。默认货币 = 当前 Market 的默认货币，货币列表根据 Market 配置动态获取（market_currency + currency）。切换后整站价格按汇率换算为目标货币展示（含尾数适配）。
图标按钮
Account：跳转账户页（未登录跳登录页）
Search：打开搜索 Overlay / 搜索页
Wishlist：跳转收藏列表页
Cart：跳转购物车页（角标展示商品数量，0 时不显示）
Sticky 行为
Header 固定在页面顶部（position: sticky; top: 0; z-index: 100），滚动时始终可见。高度 64px。
数据来源
详见《商详页 PRD V1.0》第 2.4 节「Header 导航栏」。

2 Breadcrumb 面包屑导航 导航 ▾

第一段，点击跳转该品牌的品牌聚合页。
品类链接
第二段，点击跳转该品类的商品列表页。

3 Gallery 商品图片区 核心 ▾
主图悬停缩放
鼠标悬停在主图区域时，图片缓慢放大至 1.08 倍（transition: transform 0.4s ease），光标变为 cursor: zoom-in。移出后恢复原始大小。
点击主图 → Lightbox
点击主图进入全屏灯箱模式（黑色半透明遮罩，图片居中展示）。详见 Module 12。
点击缩略图
点击任意缩略图切换主图。当前选中缩略图有 2px 深色边框 + 透明度从 0.7 恢复为 1。
Prev / Next 圆形按钮
主图下方的左右圆形箭头按钮，点击切换前/后一张图。按钮有 border: 1.5px solid #D1D5DB，hover 时边框变为 #1A1A1A。
收藏按钮
主图右上角心形图标。点击切换收藏状态：未收藏 空心灰色 → 已收藏 实心红色（#EF4444）。hover 时图标变为 #1A1A1A。未登录时触发登录流程。
Sticky 定位
Gallery 区域设置 position: sticky; top: 80px（Header 高度 64px + 16px 间距），当用户滚动右侧信息区时，Gallery 固定在视口不随页面滚动。
数据来源
详见《商详页 PRD V1.0》第 2.6 节「Gallery 图片区」。
边界情况
· 仅 1 张图：隐藏缩略图行和 Prev/Next 按钮
· 图片加载失败：显示灰色占位图 + 品牌 Logo 水印
· 图片数量 > 6：缩略图区域自动换行为两行

4 商品信息区（品牌 / 标题 / 价格） 核心 ▾
品牌名
14px 粗体大写字母。点击跳转该品牌的品牌聚合页（筛选该品牌下所有在售商品）。
价格展示逻辑
有促销价时：划线原价（20px 灰色删除线）+ 现价（28px 黑色粗体）+ Save $差值（14px 红色）
无促销价时：仅展示现价，划线价和 Save 隐藏
币种转换：当用户选择的货币 ≠ listing 定价货币时，所有金额做汇率换算 + 尾数规则适配后再计算 Save。注意：Save = 转换后划线价 − 转换后现价，Save 差值本身不做尾数处理
价格数据源
详见《商详页 PRD V1.0》第 2.7 节「商品信息区」。
标题数据源
详见《商详页 PRD V1.0》第 2.7 节「商品信息区」。
Tax 提示
"No extra sales tax added at checkout." — 12px 灰色，固定文案。按 Market 税务政策可能变化（如含税市场显示 "Includes VAT"）。

5 商品描述 & CTA & 支付方式 核心 ▾
描述展示
PC 端全文展示，不做截断（与 APP 端 2 行截断不同）。14px，行高 1.7，颜色 #1A1A1A。数据来源详见《商详页 PRD V1.0》第 2.8 节。
Add to Cart 按钮
黑色描边次级按钮，展示 "Add to Cart · $价格"。点击加入购物车。反馈动效：按钮文字变为 "Added ✓"，2 秒后恢复原状。
· 若 listing_status = active 但库存已预留/已售出，按钮变灰色 "Sold Out"，不可点击
· 若 listing_status = inactive / draft，页面显示"商品已下架"提示（非按钮状态）
· 若未登录，先触发登录流程
Checkout 按钮
紫色实心主按钮（#6432FC），视觉层级最高。点击直接进入结算流程（跳过购物车，直接结算当前商品）。同样受库存状态约束。
按钮 Hover
Add to Cart：背景从 #fff → #F9FAFB。
Checkout：背景从 #6432FC → #5228D4。两者均有 0.2s transition。
支付方式图标
共 12 个支付图标（AMEX / Apple Pay / Diners / Discover / GPay / JCB / Maestro / MC / PayPal / UnionPay / VISA / Klarna），自动换行。纯展示，不可点击。
数据来源
详见《商详页 PRD V1.0》第 2.9 节「CTA 按钮 & 支付方式」。
边界情况
· 描述为空时：描述段落隐藏，CTA 按钮上移
· Sold Out 时两个按钮均禁用，Checkout 变灰色

7 Description 描述折叠区 信息 ▾
折叠 / 展开
默认展开。行为同 Condition 折叠区。
item # 数据来源
详见《商详页 PRD V1.0》第 2.11 节「Description 描述折叠区」。
属性列表布局
每行一条属性，格式 "Label: Value"。13px，行高 1.8。属性名均通过 attribute_def 获取，走翻译。
属性筛选流程
详见《商详页 PRD V1.0》第 2.11 节「Description 描述折叠区」。
Size Guide（尺寸测量方法）
黑色带下划线文字，点击打开尺寸标注弹窗。展示逻辑分两种模式：
有 SVG 模板时（Template Mode）：
· 后台按末级类目配置 SVG 示意图模板（设计师出图，预留 data-slot 标记位置）
· 前端根据当前商品所属类目查找模板 → 用 SKU 实测值替换 data-slot 占位符 → 拼接单位后渲染标注图
· 单位由前端根据类目适用单位 + 用户 Market 偏好自动处理（如美国市场显示 inch）

无模板时（Fallback）：
· 退化为纯文字列表：属性名: 值（如 Length: 12.2 in, Width: 5.5 in）
· 仅展示 display_group = dimension 的属性
边界情况
· 属性值为空时：该行不展示
· 当前类目未配置尺寸测量方法模板：Size Guide 退化为文字列表
· 当前类目无任何 dimension 属性：隐藏 "Size Guide" 链接
· 属性值带特殊字符：做 HTML 转义

12 Lightbox 灯箱图片查看器 核心 ▾
打开方式
点击 Gallery 主图触发。全屏黑色遮罩（rgba(0,0,0,.9)），图片居中展示（max-width: 90vw, max-height: 90vh），cursor: zoom-out。
关闭方式
三种关闭方式：1) 点击右上角 ✕ 按钮；2) 点击黑色遮罩区域；3) 按 Escape 键。关闭后恢复页面滚动。
Prev / Next 导航
左右圆形半透明按钮（rgba(255,255,255,.12)），hover 时变为 rgba(255,255,255,.25)。点击切换前/后一张图，同步更新 Gallery 缩略图高亮。
键盘导航
Escape：关闭 Lightbox
ArrowLeft (←)：上一张
ArrowRight (→)：下一张
键盘事件仅在 Lightbox 打开时生效。
计数器
底部居中显示 "N / Total"（如 "2 / 6"），颜色 rgba(255,255,255,.6)，13px。每次切换图片同步更新。
Body 锁定
Lightbox 打开时设置 body.style.overflow = 'hidden'，防止背景页面滚动。关闭时恢复。
边界情况
· 仅 1 张图：隐藏 Prev/Next 按钮和计数器
· 第一张图：Prev 按钮 disabled（opacity 0.3），不循环
· 最后一张图：Next 按钮 disabled（opacity 0.3），不循环
· 图片加载慢：显示 loading spinner 占位
