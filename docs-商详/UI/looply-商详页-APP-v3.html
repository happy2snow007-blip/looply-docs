1 Header 导航栏 导航 ▾
返回箭头 (←)
点击返回上一页（浏览器/APP 历史栈回退）。
Logo
点击返回首页。
搜索图标
点击进入搜索页（全屏覆盖，顶部输入框自动聚焦），展示热门搜索词和最近搜索历史。
心形图标
点击跳转Wishlist 页。若未登录，先触发登录流程，登录后进入。
购物袋图标
点击跳转购物车页。角标展示当前购物车商品数量（0 时不显示角标）。
Sticky 行为
Header 在页面滚动时固定在顶部（position: sticky），StatusBar 同理。商详页隐藏底部 TabBar，由 Sticky 底部购买栏替代。
2 Gallery 商品图片区 核心 ▾
左右滑动
在主图区域水平滑动切换图片。滑动距离 > 50px 触发切换，带弹性过渡动画（0.25s ease）。当前图片序号同步更新圆点指示器和缩略图高亮。
点击缩略图
点击任意缩略图切换主图。当前选中缩略图有紫色边框高亮 + 透明度从 0.6 恢复为 1。
点击主图 → Lightbox
点击主图进入全屏灯箱模式（黑色背景，图片可双指缩放）。支持左右滑动切换、底部计数器（如 "2 / 5"）、右上角 ✕ 关闭。
收藏按钮 (♡)
点击切换收藏状态。未收藏：空心灰色 → 已收藏：实心红色 + 缩放弹跳动画。若未登录，触发登录流程。
数据来源
详见《商详页展示逻辑 PRD V1.0》第 2.6 节「Gallery 图片区」。
边界情况
· 仅 1 张图：隐藏圆点、缩略图行
· 图片加载失败：显示灰色占位图 + 品牌 Logo 水印
· 图片数量 > 10：缩略图区域可水平滚动
3 商品信息区（品牌 / 标题 / 价格） 核心 ▾
品牌名
点击跳转该品牌的品牌聚合页（筛选该品牌下所有在售商品）。
价格展示逻辑
有促销价时：划线原价（灰色 16px 删除线）+ 现价（黑色 24px 粗体）+ Save $差值（红色 12px）
无促销价时：仅展示现价，划线价和 Save 隐藏
币种转换：当用户选择的货币 ≠ listing 定价货币时，所有金额做汇率换算 + 尾数规则适配后再计算 Save
价格数据源
详见《商详页展示逻辑 PRD V1.0》第 2.7 节「商品信息区」。
标题数据源
详见《商详页展示逻辑 PRD V1.0》第 2.7 节「商品信息区」。
Tax 提示
"No extra sales tax added at checkout." — 11px 灰色，固定文案。按 Market 税务政策可能变化（如含税市场显示 "Includes VAT"）。
4 商品描述段落 信息 ▾
截断与展开
默认截断 2 行（-webkit-line-clamp: 2），末尾文字渐隐。下方显示 Read more 按钮。
点击展开全文，按钮变为 Show less，再次点击收起。
数据来源
详见《商详页展示逻辑 PRD V1.0》第 2.8 节「商品描述」。
边界情况
· 描述为空时：整个段落区域隐藏（不留空白）
· 文案不足 2 行时：不截断，不显示 Read more 按钮

共 12 个支付图标（AMEX / Apple Pay / Diners / Discover / GPay / JCB / Maestro / MC / PayPal / UnionPay / VISA / Klarna），在 375px 宽度下自动换行为 2 行。

6 Condition 成色折叠区 信任 ▾
折叠/展开
点击标题行切换折叠状态。默认展开（核心二手差异信息，用户最关注）。箭头图标随折叠状态旋转 180°。
Certified Authentic 徽章
折叠区内第一行。绿色实心圆形盾牌 ✓ 图标 (20px) + 带下划线的 "Certified Authentic" 文字。
点击弹出 Bottom Sheet 展示鉴定证书详情：鉴定机构名称、鉴定日期、鉴定编号。
当 product.is_authenticated = false 时隐藏。鉴定机构取 product.authenticator。

详见《商详页展示逻辑 PRD V1.0》第 2.10 节「Condition 成色折叠区」。
部位质检明细
详见《商详页展示逻辑 PRD V1.0》第 2.10 节「Condition 成色折叠区」。
原装配件
详见《商详页展示逻辑 PRD V1.0》第 2.10 节「Condition 成色折叠区」。
7 Description 描述折叠区 信息 ▾
折叠/展开
默认展开。行为同 Condition 折叠区。
属性列表布局
每行：左侧 label（130px 灰色）+ 右侧 value（黑色），行间 1px 分隔线。属性筛选与排序逻辑详见《商详页展示逻辑 PRD V1.0》第 2.11 节。
Size Guide（尺寸测量方法）
紫色带下划线文字，点击打开尺寸标注弹窗（Bottom Sheet）。展示逻辑分两种模式：
有 SVG 模板时（Template Mode）：
· 后台按末级类目配置 SVG 示意图模板（设计师出图，预留 data-slot 标记位置）
· 前端根据当前商品所属类目查找模板 → 用 SKU 实测值替换 data-slot 占位符 → 拼接单位后渲染标注图
· 单位由前端根据类目适用单位 + 用户 Market 偏好自动处理（如美国市场显示 inch）

无模板时（Fallback）：
· 退化为纯文字列表：属性名: 值（如 Length: 12.2 in, Width: 5.5 in）
· 仅展示 display_group = dimension 的属性
边界情况
· 属性数量 > 8 行时：截断为 8 行，底部显示 "Show more attributes" 展开
· 属性值为空时：该行不展示

数据来源

商品卡片
点击整张卡片跳转对应商品的商详页。卡片宽 156px，圆角 12px 图片区。
卡片收藏按钮 (♡)
右上角心形图标 + 收藏数。点击直接收藏/取消收藏（无需进入详情页）。未登录时触发登录流程。
· 无收藏时：只展示空心心形，不显示数字 0
· 已收藏：实心红色心形 + 数字 +1
· 触摸热区：扩大为 44×44px（含 padding）
卡片价格逻辑
有促销价时：现价 (14px 粗体) + 原价划线 (11px) + Save 标签（黑底白字 9px 胶囊）
无促销价时：仅展示现价。
所有金额均做币种转换 + 尾数适配。
数据来源
详见《商详页展示逻辑 PRD V1.0》第 2.13 节「You May Also Like 推荐区」。

社交媒体图标

12 Sticky 底部购买栏 核心 ▾
常驻行为
始终固定在屏幕底部（position: sticky）。商详页隐藏 APP 底部 TabBar，由此栏替代。三栏布局：左侧价格 | Add to Cart | Checkout。
价格展示
左侧列：✓ Verified（绿色认证标记）+ 展示价 $652（粗体 20px）。
展示当前促销价（有促销时）或 listing_price（无促销时）。不重复展示划线价和 Save（上方信息区已有）。
Add to Cart 按钮
黑色描边次级按钮。点击加入购物车。反馈动效：按钮文字变为 "Added ✓"，背景变浅绿色 + 绿色边框，1.5 秒后恢复原状。
· 若商品有多 SKU（如不同尺码），点击后弹出 SKU 选择 Bottom Sheet，选择后再加入
· 若库存为 0（listing_status ≠ active），按钮变灰色 "Sold Out"，不可点击
· 若未登录，先触发登录流程
Checkout 按钮
紫色实心主按钮，视觉层级最高。点击直接进入结算流程（跳过购物车页，直接结算当前商品）。
· 同样受 SKU 选择和库存状态约束
· 未登录时先登录
页面上方 CTA 滚出视口后的行为
Sticky 栏始终可见，无论页面滚动到何处，用户随时可以购买。上方不再有独立 CTA 按钮（与 PC 端的独立 Add to Cart / Checkout 不同）。
