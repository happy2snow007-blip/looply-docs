## 一、来源分类与状态

### 1.1 数据来源分类

| 分类 | 定义 |
|---|---|
| GA4 自动数据 | GA4 自动形成或 GA4 Data API 可直接查询的用户、Session、互动、设备、地域及平台来源数据 |
| Looply 统一事件 | Looply 统一业务事件及一方公共上下文；可按批准范围适配到 GA4 |
| 业务表 | 订单、订单商品、支付、退款、售后、广告花费等权威业务事实 |
| 派生计算 | 基于上述原始事实进行周期去重、比例、Cohort、渠道映射、归因或趋势计算 |
| 当前尚未具备 | 当前没有可证明完整的数据源、稳定关联或正式运行证据 |

### 1.2 当前状态分类

| 状态 | 含义 |
|---|---|
| 已取得 | 最新正式数据副本已有真实结果，并能说明口径 |
| 部分取得 | 只有聚合或部分字段，不能完成标准口径 |
| 方案已覆盖，运行待核 | 采集产品方案已定义事件或字段，但没有完整运行证据 |
| 未接入 | 页面结构存在，但当前数据链路未提供正式结果 |
| 待确认 | 指标定义或产品规则存在冲突，不能冻结 |

## 七、来源一致性结论

1. GA4 当前可以直接支持用户、Session、互动、页面、地域、首次渠道、新客 Cohort 和部分标准事件汇总。
2. 搜索、推荐和站内归因的精确关联依赖 Looply 统一事件中的稳定请求、来源、商品、用户与 Session 信息；GA4 聚合事件不能代替。
3. 订单、支付、退款、售后和广告花费必须读取权威业务表或平台，不应为了报表重复新增用户埋点。
4. 比例、Cohort、趋势、渠道映射和归因属于派生计算；派生结果不得覆盖原始事件、触点和交易事实。
5. 当前页面显示“—”的指标均保持未接入状态；采集方案已定义不等于运行数据已经具备。
